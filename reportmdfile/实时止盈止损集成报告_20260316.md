## 📊 2. 止盈止损配置

### 2.1 默认阈值
```python
# app/trader/position_manager.py

# 止损：-5%
def check_stop_loss(self, code: str, current_price: float) -> bool:
    position = self.get_position(code)
    if position is None:
        return False
    
    avg_cost = position.entry_price
    pnl_rate = (current_price - avg_cost) / avg_cost
    return pnl_rate <= -0.05  # -5%

# 止盈：+15%
def check_take_profit(self, code: str, current_price: float) -> bool:
    position = self.get_position(code)
    if position is None:
        return False
    
    avg_cost = position.entry_price
    pnl_rate = (current_price - avg_cost) / avg_cost
    return pnl_rate >= 0.15  # +15%
```

## ⚠️ 4. 优先级说明

### 止盈止损 > 策略信号

**原因**:
- 止盈止损是风控措施，优先级最高
- 触发后立即平仓，避免亏损扩大或利润回吐
- 触发后跳过策略计算，避免冲突

**流程**:
```python
if 止盈触发 or 止损触发:
    执行平仓
    continue  # 跳过策略计算
else:
    策略计算
    共识评估
    ...
```
