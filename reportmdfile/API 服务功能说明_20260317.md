# FTSeek API 服务 (8899 端口) 功能说明

**检查时间**: 2026-03-17 12:15  
**端口**: 8899  
**协议**: HTTP/HTTPS (FastAPI)

---

## 📋 主要功能

### 1. TradingView Webhook 回调 ✅

**端点**: `POST /api/tradingview/webhook`

**功能**: 接收 TradingView 的策略信号，自动触发交易

**使用场景**:
- TradingView 策略产生买卖信号
- 通过 Webhook 自动推送到 FTSeek
- 自动执行交易

**示例**:
```json
{
  "ticker": "HK.09992",
  "action": "buy",
  "price": 95.50,
  "quantity": 200
}
```

---

### 2. 信号确认/拒绝/推迟 ✅

**端点**:
- `GET /api/confirm?signal_id=xxx` - 确认交易
- `GET /api/reject?signal_id=xxx` - 拒绝交易
- `GET /api/defer?signal_id=xxx` - 推迟交易

**功能**: 钉钉推送按钮回调，人工确认交易

**使用场景**:
- 系统生成交易信号
- 钉钉推送带按钮的消息
- 用户点击确认/拒绝/推迟
- 回调到 API 执行操作

---

### 3. 信号管理 API ✅

**端点**:
- `GET /api/signals` - 获取所有信号
- `POST /api/signal/create` - 创建新信号

**功能**: 查询和管理交易信号

---

### 4. 账户信息查询 ✅

**端点**: `GET /api/account`

**功能**: 查询富途账户资金、持仓等信息

---

### 5. 策略管理 API ✅

**端点**:
- `GET /api/strategies` - 获取所有策略
- `POST /api/strategy/update` - 更新策略参数

**功能**: 查看和修改策略配置

---

### 6. 系统状态监控 ✅

**端点**:

**功能**: 监控系统运行状态

### 7. 风控仪表盘 ✅

**功能**: 策略回测功能

### 9. 参数优化 API ✅

## 💡 必要性评估

### 必须保留 ✅

1. **健康检查** (`/health`)
   - 系统监控必需
   - systemd 和外部监控依赖
   - **重要性**: ⭐⭐⭐⭐⭐

2. **信号确认回调** (`/api/confirm|reject|defer`)
   - 钉钉按钮回调必需
   - 人工确认交易流程核心
   - **重要性**: ⭐⭐⭐⭐⭐

3. **TradingView Webhook** (`/api/tradingview/webhook`)
   - 外部策略信号接入
   - 自动化交易核心
   - **重要性**: ⭐⭐⭐⭐

### 可选保留 ⚪

4. **系统状态** (`/api/status`, `/api/signals`)
   - 调试和监控用
   - 可通过日志替代
   - **重要性**: ⭐⭐⭐

5. **账户查询** (`/api/account`)
   - 查询资金和持仓
   - 可通过富途 API 直接查询
   - **重要性**: ⭐⭐

### 可考虑移除 ❌

6. **策略管理 API**
   - 当前通过配置文件管理
   - 使用频率低
   - **重要性**: ⭐

7. **回测/优化 API**
   - 可通过脚本执行
   - 使用频率低
   - **重要性**: ⭐

8. **认证 API**
   - 当前未启用用户系统
   - 单机使用不需要
   - **重要性**: ⭐

## 🔧 配置方法

### 修改端口

编辑 `/opt/ftseek/FTSeek/app/config.py`:
```python
CALLBACK_PORT = int(os.getenv("CALLBACK_PORT", "8899"))
```

### 禁用 API 服务

编辑 `/opt/ftseek/FTSeek/app/main.py`:
```python
# 注释掉 API 启动代码
# api_thread = threading.Thread(target=run_api, daemon=True)
# api_thread.start()
```

### 限制访问 (推荐)

配置 Nginx 防火墙:
```nginx
location / {
    allow 127.0.0.1;
    allow 192.168.1.0/24;  # 内网
    deny all;
}
```
