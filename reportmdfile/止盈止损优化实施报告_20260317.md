## 📋 新增功能

### 1. ATR 动态止损

**原理**: 根据波动率自动调整止损幅度

```python
# 高波动股票 (ATR=5%)
止损幅度 = ATR × 2.0 = 10%  # 放宽，避免洗盘

# 低波动股票 (ATR=2%)
止损幅度 = ATR × 2.0 = 4%   # 收紧，快速止损
```

**优势**:
- 自适应市场波动
- 高波动：避免洗盘
- 低波动：快速止损

### 2. 时间止损

**规则**:
```
持仓 > 72 小时 且 收益 < 5% → 自动平仓
24 小时内不平仓 (除非止损)
涨势强烈可延长至 96 小时
```

**优势**:
- 避免资金长期占用
- 提高资金周转率
- 强制纪律

### 3. 动态参数切换

**联动市场状态**:
```python
# 每 5 分钟检测市场状态
if market_regime == 'strong_trend_up':
    stop_loss = -8%    # 放宽
    take_profit = +20% # 提高
elif market_regime == 'range_bound':
    stop_loss = -5%    # 收紧
    take_profit = +10% # 降低
```

from app.risk.dynamic_exit_manager import dynamic_exit_manager

# 在_on_consensus 中
def _on_consensus(self, result):

    stop_loss = dynamic_exit_manager.get_stop_loss()
    take_profit = dynamic_exit_manager.get_take_profit()
    
    # 计算 ATR 止损价
    atr = self._get_atr(code)
    atr_stop_price = dynamic_exit_manager.calculate_atr_stop_price(
        entry_price=result.price,

        direction=result.action.value
    )
    
    # 传递给执行器
    signal.extra['stop_loss'] = stop_loss
    signal.extra['take_profit'] = take_profit
    signal.extra['atr_stop_price'] = atr_stop_price

### 2. 在 executor 中使用

```python
from app.risk.dynamic_exit_manager import dynamic_exit_manager

def execute(self, signal, trade_type):
    # 获取止盈止损参数
    stop_loss = dynamic_exit_manager.get_stop_loss()
    take_profit = dynamic_exit_manager.get_take_profit()
    
    # 计算止盈止损价
    if signal.action == 'BUY':
        stop_price = signal.price * (1 + stop_loss)
        take_profit_price = signal.price * (1 + take_profit)
    else:
        stop_price = signal.price * (1 - abs(stop_loss))
        take_profit_price = signal.price * (1 - take_profit)
    
    # 提交订单
    order = self._create_order(
        code=signal.code,
        action=signal.action,
        quantity=signal.quantity,
        stop_loss=stop_price,
        take_profit=take_profit_price
    )
```

### 3. 在 realtime_monitor 中使用

```python
def check_positions(self):
    for position in self.positions:
        # 获取当前市场状态参数
        params = dynamic_exit_manager.get_all_params()
        
        # 检查时间止损
        holding_hours = position.holding_hours
        max_hours = params['time_stop']['max_holding_hours']
        
        if holding_hours > max_hours and position.pnl_pct < 0.05:
            self._close_position(position, reason='时间止损')
        
        # 检查移动止盈
        if position.pnl_pct >= params['trailing_stop']['trigger_profit']:
            # 启用移动止盈
            trailing_price = position.highest_price * (1 - params['trailing_stop']['trail_percent'])
            if position.current_price <= trailing_price:
                self._close_position(position, reason='移动止盈')
```
