### 问题 2: 服务进程检查失败

**现象**: `subprocess.run` 的 `capture_output` 参数在 Python 3.8 不支持

**原因**: Python 3.8 使用 `stdout=subprocess.PIPE, stderr=subprocess.PIPE`

**影响**: 仅影响测试脚本，不影响实际功能

**修复建议**:
```python
# 原代码 (Python 3.7+)
result = subprocess.run(['pgrep', '-f', 'app.main'], capture_output=True, text=True)

# 修复后 (Python 3.8 兼容)
result = subprocess.run(['pgrep', '-f', 'app.main'], 
                       stdout=subprocess.PIPE, 
                       stderr=subprocess.PIPE, 
                       text=True)
```
