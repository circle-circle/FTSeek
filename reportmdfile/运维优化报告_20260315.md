### 1. 日志清理

**问题**: `ftseek.log.1` 达 437MB，磁盘爆满风险

**操作**:
```bash
cd /opt/ftseek/FTSeek/logs
rm -f ftseek.log.1  # 清理 437MB
```

**结果**: ✅ 释放 437MB 磁盘空间

**后续**: cron 配置每日 3:00 自动清理 7 天前日志

---

### 2. 数据库备份机制

**问题**: 无自动备份，数据丢失风险

**操作**:
```bash
# 创建备份目录
mkdir -p /opt/ftseek/FTSeek/backups

# 手动备份
cp /opt/ftseek/FTSeek/data/ftseek.db /opt/ftseek/FTSeek/backups/ftseek_20260315_084043.db

# 配置自动备份 (每日 2:00)
cat > /etc/cron.d/ftseek-tasks << 'EOF'
0 2 * * * root mkdir -p /opt/ftseek/FTSeek/backups && cp /opt/ftseek/FTSeek/data/ftseek.db /opt/ftseek/FTSeek/backups/ftseek_$(date +\%Y\%m\%d).db && find /opt/ftseek/FTSeek/backups -name "*.db" -mtime +30 -delete
EOF
```

**结果**: ✅ 备份机制已建立，保留 30 天

### 3. 固定 API_TOKEN

**问题**: API_TOKEN 临时生成，重启后变化

**操作**:

### 6. 美股订阅禁用

**文件**: `app/config.py`

**修改**:
```python
# 修改前
WATCH_LIST_US = json.loads(os.getenv("WATCH_LIST_US", '["US.AAPL", "US.TSLA", "US.NVDA", "US.MSFT", "US.AMZN"]'))

# 修改后
WATCH_LIST_US = json.loads(os.getenv("WATCH_LIST_US", '[]'))  # 默认禁用
```

**原因**: 美股无行情权限，每次启动都尝试订阅产生警告日志

**结果**: ✅ 启动日志清爽，仅订阅港股
