## 🎯 核心功能

### 1. 市场状态动态参数

**7 种市场状态参数集**:

| 状态 | 冷却时间 | 置信度 | 单仓位 | 总仓位 |
|------|---------|--------|--------|--------|
| **强上涨** | 60 秒 | 0.45 | 25% | 90% |
| **弱上涨** | 90 秒 | 0.50 | 20% | 80% |
| **震荡市** | 180 秒 | 0.60 | 15% | 60% |
| **弱下跌** | 240 秒 | 0.65 | 10% | 40% |
| **强下跌** | 300 秒 | 0.70 | 5% | 20% |
| **高波动** | 300 秒 | 0.70 | 10% | 40% |
| **低波动** | 90 秒 | 0.50 | 20% | 80% |

### 2. 动态参数切换逻辑

```python
# 每 5 分钟检查一次市场状态
if time.time() - last_check > 300:
    # 获取恒指 ADX
    adx = hsi_fetcher.calculate_hsi_adx()
    trend = hsi_fetcher.get_hsi_trend()
    
    # 判断状态
    if adx > 30:
        regime = 'strong_trend_up' if trend == 'up' else 'strong_trend_down'
    elif adx > 20:
        regime = 'weak_trend_up' if trend == 'up' else 'weak_trend_down'
    else:
        regime = 'range_bound'
    
    # 加载对应参数
    params = params_loader.get_params(regime)
```
