## 🔧 配置步骤

### 1. 获取钉钉 Webhook URL

1. 打开钉钉群聊
2. 点击右上角设置 ⚙️
3. 选择 **智能群助手** → **添加机器人**
4. 选择 **自定义** 机器人
5. 设置机器人名称（如：FTSeek 助手）
6. 复制 **Webhook 地址**

**Webhook 格式**:
```
https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxx
```

### 2. 配置加签密钥（推荐）

1. 在机器人设置中启用 **加签**
2. 复制 **SEC** 开头的密钥

**密钥格式**:
```
SECxxxxxxxx
```

## 📝 配置方法

### 方法 1: 编辑.env 文件

```bash
# 编辑配置文件
nano /opt/ftseek/FTSeek/.env

# 添加以下配置（替换为你的实际值）
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN
DINGTALK_SECRET=SECYOUR_SECRET
```

### 方法 2: 使用 echo 命令

```bash
# 添加 Webhook URL
echo "DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN" >> /opt/ftseek/FTSeek/.env

# 添加密钥（可选但推荐）
echo "DINGTALK_SECRET=SECYOUR_SECRET" >> /opt/ftseek/FTSeek/.env
```

### 方法 3: 临时环境变量（测试用）

```bash
# 设置临时环境变量
export DINGTALK_WEBHOOK_URL="https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN"
export DINGTALK_SECRET="SECYOUR_SECRET"

# 测试推送
python3 -c "
from app.risk.dingtalk_alert import DingTalkAlertSender
sender = DingTalkAlertSender()
sender.send_alert('测试消息', 'info')
"
```

## 📊 推送功能说明

### 推送类型

1. **新闻推送** - 定时推送股票相关新闻
2. **信号推送** - 交易信号触发时推送
3. **风控告警** - 风控触发时推送
4. **熔断告警** - 熔断器触发时推送
5. **收盘统计** - 每日收盘后统计

### 推送时机

| 类型 | 时机 | 说明 |
|------|------|------|
| 新闻 | 每小时 | 采集并推送股票相关新闻 |
| 信号 | 实时 | 交易信号触发时 |
| 风控 | 实时 | 风控检查失败时 |
| 熔断 | 实时 | 熔断器触发时 |
| 统计 | 16:30 | 每日收盘后 |

## 🔍 故障排查

### 问题 1: 推送失败

**可能原因**:
- Webhook URL 错误
- 密钥不匹配
- 网络问题

**解决方法**:
```bash
# 检查 URL 格式
echo $DINGTALK_WEBHOOK_URL

# 测试网络
curl -X POST https://oapi.dingtalk.com/robot/send \
  -H 'Content-Type: application/json' \
  -d '{"msgtype":"text","text":{"content":"测试"}}'
```

### 问题 2: 环境变量未生效

**可能原因**:
- .env 文件未加载
- 服务未重启

**解决方法**:
```bash
# 重启服务
systemctl restart ftseek

# 检查服务环境变量
systemctl show ftseek | grep -i dingtalk
```
