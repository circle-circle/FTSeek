### 1. 信号追踪器

**数据结构**:
```python
@dataclass
class SignalRecord:
    signal_id: str
    code: str
    timestamp: str
    strategy: str
    action: str

    confidence: float        # 置信度 (0-1)
```

- ✅ 按日存储到 JSON 文件

### 3. 动态阈值调整

**调整逻辑**:
```python
# 每周评估一次
if days_since_last_adjustment >= 7:
    # 找出最佳置信度区间
    best_bucket = find_best_bucket()
    
    # 计算调整量 (限制±0.05/周)
    adjustment = min(0.05, best_bucket_min - current_threshold)
    
    # 应用新阈值
    new_threshold = current_threshold + adjustment
```
