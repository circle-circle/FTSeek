## 🚨 发现的关键问题

### 问题 1: 持仓表结构不支持止盈止损字段 ⚠️⚠️⚠️

**严重级别**: 🔴 高

**现象**:
```python
TypeError: create_position() got an unexpected keyword argument 'stop_loss'
```

**原因**:
- `position_manager.py` 的 `create_position()` 方法不接受 `stop_loss` 和 `take_profit` 参数
- 数据库表 `positions` 没有 `stop_loss` 和 `take_profit` 字段
- executor.py 中传递了这些参数，但底层不支持

**影响**:
- 动态止盈止损功能无法实际存储到持仓记录
- 实时止盈止损监控无法获取预设的止盈止损价
- 止盈止损追踪日志无法记录

**修复方案**:

1. **扩展数据库表结构**:
```sql
ALTER TABLE positions ADD COLUMN stop_loss REAL;
ALTER TABLE positions ADD COLUMN take_profit REAL;
ALTER TABLE positions ADD COLUMN trailing_stop_enabled INTEGER DEFAULT 0;
ALTER TABLE positions ADD COLUMN trailing_trigger_price REAL;
```

2. **修改 create_position() 方法**:
```python
def create_position(self, code: str, action: str, quantity: int, 
                   entry_price: float, entry_time: str,
                   stop_loss: float = None, take_profit: float = None) -> int:
    cursor.execute('''
        INSERT INTO positions 
        (code, action, quantity, entry_price, entry_time, status, stop_loss, take_profit)
        VALUES (?, ?, ?, ?, ?, 'OPEN', ?, ?)
    ''', (code, action, quantity, entry_price, entry_time, stop_loss, take_profit))
```

3. **修改 Position 数据类**:
```python
@dataclass
class Position:
    id: int
    code: str
    action: str
    quantity: int
    entry_price: float
    entry_time: str
    stop_loss: Optional[float] = None  # 新增
    take_profit: Optional[float] = None  # 新增
    ...
```

**预计修复时间**: 30 分钟

### 风险 8: 移动止盈未实现 🟡 中

**问题**: 配置了移动止盈参数，但无实际追踪逻辑

**影响**:

- 利润回撤不会自动止盈

**建议**:
```python
# 在 realtime_monitor.py 中添加移动止盈检查
def check_trailing_stop(self):
    for position in self.positions:
        params = dynamic_exit_manager.get_trailing_stop_params()
        
        # 检查是否达到触发利润
        if position.pnl_pct >= params['trigger_profit']:
            # 更新最高价
            if position.current_price > position.highest_price:
                position.highest_price = position.current_price
            
            # 计算回撤止盈价
            trailing_price = position.highest_price * (1 - params['trail_percent'])
            
            # 检查是否触发
            if position.current_price <= trailing_price:
                self._close_position(position, reason='移动止盈')
```
