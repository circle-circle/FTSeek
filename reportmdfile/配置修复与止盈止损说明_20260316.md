## 📊 2. 止盈止损逻辑

### 2.1 止盈止损配置

**文件**: `app/trader/position_manager.py`

```python
# 止损：-5%
def check_stop_loss(self, code: str, current_price: float) -> bool:
    position = self.get_position(code)
    if position is None:
        return False
    
    avg_cost = position.entry_price
    pnl_rate = (current_price - avg_cost) / avg_cost
    return pnl_rate <= -0.05  # -5% 止损

# 止盈：+15%
def check_take_profit(self, code: str, current_price: float) -> bool:
    position = self.get_position(code)
    if position is None:
        return False
    
    avg_cost = position.entry_price
    pnl_rate = (current_price - avg_cost) / avg_cost
    return pnl_rate >= 0.15  # +15% 止盈
```

### 2.2 止盈止损价格计算

```python
# 止损价格 = 成本价 × 0.95
def calculate_stop_loss_price(self, avg_cost: float) -> float:
    return round(avg_cost * (1 - 0.05), 2)

# 止盈价格 = 成本价 × 1.15
def calculate_take_profit_price(self, avg_cost: float) -> float:
    return round(avg_cost * (1 + 0.15), 2)
```

## ⚠️ 3. 重复下单风险

### 3.1 当前防护机制

#### ✅ 冷却机制 (SIGNAL_COOLDOWN)
```python
SIGNAL_COOLDOWN = 300  # 5 分钟

def _is_cooled_down(self, code: str) -> bool:
    now = time.time()
    last_time = self._cooldown.get(code, 0)
    if now - last_time < SIGNAL_COOLDOWN:
        return False  # 冷却中
    return True  # 可推送
```

**效果**: 同一股票 5 分钟内只执行 1 次交易

#### ✅ 持仓检查
```python
def _determine_trade_type(self, position, action: SignalAction) -> str:
    if position is None:
        return 'OPEN'  # 无持仓 → 开仓
    
    # 有持仓
    if position.action == 'BUY' and action == SignalAction.SELL:
        return 'CLOSE'  # 多仓 + 卖出信号 → 平仓
    
    if position.action == 'SELL' and action == SignalAction.BUY:
        return 'CLOSE'  # 空仓 + 买入信号 → 平仓
    
    return 'OPEN'  # 同向信号 → 加仓 (暂不处理)
```

**效果**: 
- 无持仓时执行开仓
- 反向信号触发平仓
- 同向信号理论上可加仓 (但当前返回'OPEN'，实际会创建新持仓)

#### ✅ 风控检查
```python
# 五层风控
1. 置信度 ≥ 0.60
2. 单一仓位 < 20%
3. 总仓位 < 80%
4. 每日交易 < 10 次
5. 最大回撤 < 15%
```

**效果**: 防止过度交易

### 3.2 潜在风险

#### 风险 1: 止盈止损未实时触发
**问题**: 当前止盈止损方法存在，但**未在行情回调中调用**

**场景**:
```
13:00 - 开仓 HK.09992 @ HK$100
13:30 - 股价跌至 HK$94 (-6%)
13:35 - 股价反弹至 HK$98
14:00 - 共识触发 SELL 信号

结果：
- 13:30 应触发止损 (-6% < -5%)，但未执行
- 14:00 平仓 @ HK$98，实际亏损 -2%
- 如果实时止损，亏损应为 -6%
```

**影响**: 
- ✅ 不会导致重复下单
- ❌ 但可能扩大亏损

#### 风险 2: 同向信号加仓
**问题**: `_determine_trade_type` 对同向信号返回'OPEN'

**场景**:
```
13:00 - 开仓 HK.09992 BUY 200 股 @ HK$100
13:10 - 再次触发 BUY 信号
13:15 - 冷却未结束，跳过
13:20 - 冷却结束，再次触发 BUY

结果:
- 创建 2 个持仓记录
- 总仓位：400 股
- 可能超过单一仓位限制 (20%)
```

**防护**:
- ✅ 冷却机制 (5 分钟)
- ✅ 风控检查 (仓位限制)
- ⚠️ 但仍可能在冷却期后加仓

#### 风险 3: 震荡市频繁触发
**问题**: 震荡行情中，共识可能频繁触发 BUY/SELL 交替

**场景**:
```
13:00 - BUY 触发 → 开仓
13:05 - 冷却中，跳过
13:10 - SELL 触发 → 平仓 (可能亏损)
13:15 - 冷却中，跳过
13:20 - BUY 触发 → 开仓
...

结果:
- 频繁交易
- 手续费累积
- 可能连续亏损
```

**防护**:
- ✅ 冷却机制 (5 分钟)
- ✅ 置信度检查 (≥0.60)
- ✅ 每日交易限制 (<10 次)
