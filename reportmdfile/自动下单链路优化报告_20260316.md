### 1. 置信度字段添加

**文件**: `app/strategy/consensus_engine.py`

#### 修改内容
```python
@dataclass
class ConsensusResult:
    code: str
    action: SignalAction
    price: float
    score: float
    # ... 其他字段 ...
    votes: List[Vote]
    confidence: float = 0.0    # ✅ 新增：置信度 (0-1, 用于风控检查)
```

#### 置信度计算公式
```python
# 置信度 = 分数比率 (50%) + 策略数量 (50%)
# score/threshold=2.0 时得 1.0, count=8 时得 1.0
confidence = min(1.0, (
    abs(score) / self.threshold * 0.5 +  # 分数贡献 50%
    len(votes) / 8.0 * 0.5               # 策略数贡献 50%
))
```
