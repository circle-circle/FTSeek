## 🔧 核心功能演示

### 1. 订单追踪

```python
from app.trader.order_tracker import get_order_tracker

tracker = get_order_tracker()

# 创建订单
order = tracker.create_order("HK.00700", "BUY", 100, 380.0)

# 更新状态
tracker.update_order(order.order_id, status="partial")

# 添加成交
tracker.add_fill(order.order_id, 380.5, 50)

# 获取统计
stats = tracker.get_statistics()
```

### 2. 成本计算

```python
from app.trader.cost_calculator import get_cost_calculator

calc = get_cost_calculator()

# 买入成本
buy_cost = calc.calculate_buy_cost(380.0, 100)
# 总成本：14.55 港元

# 卖出成本
sell_cost = calc.calculate_sell_cost(385.0, 100)
# 总成本：52.73 港元

# 往返分析
round_trip = calc.calculate_round_trip_cost(380.0, 385.0, 100)
# 净利润：432.73 港元
```

### 3. 回撤控制

```python
from app.risk.drawdown_control import get_drawdown_controller

controller = get_drawdown_controller()

# 更新资产值
state = controller.update_value(950000.0)  # 从 100 万回撤到 95 万

# 检查状态
print(state.status)  # "reduced" (自动减仓)
print(state.current_drawdown)  # 0.05 (5%)

# 检查限制
limits = controller.check_limits()
print(limits['trading_allowed'])  # False (停止交易)
```
