## 🎯 集成到主流程

### 在 data_subscriber.py 中集成

```python
from app.risk.dingtalk_alert import DingTalkAlertSender, DingTalkAlertConfig

# 初始化
config = DingTalkAlertConfig(
    webhook_url=os.getenv('DINGTALK_WEBHOOK_URL'),
    secret=os.getenv('DINGTALK_SECRET')
)
notifier = DingTalkAlertSender(config)

# 在关键节点推送
def _on_consensus(self, result):
    # 推送交易信号
    if trade_result.success:
        message = f"📈 **交易信号**\n\n{code} {action}\n价格：{price}"
        notifier.send_text(message, 'INFO')
```
