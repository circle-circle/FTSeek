```python
class SmartOrderRouter:
    def route_order(self, signal: Signal) -> Order:
        # 检查是否可能超限
        estimated_amount = signal.price * signal.quantity
        
        if estimated_amount > config.MAX_ORDER_AMOUNT * 0.9:
            # 接近限额，使用限价单 (设置 2% 偏移)
            limit_price = signal.price * 1.02  # BUY 场景
            return LimitOrder(price=limit_price, quantity=signal.quantity)
        
        # 检查市场状态
        if self.is_pre_market(signal.code):
            if self.is_hk_stock(signal.code):
                # 港股盘前，拒绝市价单
                return LimitOrder(price=signal.price * 1.01)
        
        # 默认市价单
        return MarketOrder(quantity=signal.quantity)
```

#### Task 4.1: 连续失败熔断
**文件**: `app/risk/circuit_breaker.py` (新建)

**功能**:
- 统计连续订单拒绝次数
- 达到阈值后暂停交易
- 推送告警通知

**逻辑**:
```python
class CircuitBreaker:
    def __init__(self):
        self.consecutive_rejects = 0
        self.last_reject_time = None
        self.pause_until = None
    
    def record_reject(self, reason: str):
        self.consecutive_rejects += 1
        self.last_reject_time = time.time()
        
        if self.consecutive_rejects >= 5:
            # 暂停 10 分钟
            self.pause_until = time.time() + 600
            logger.warning(f"触发熔断：连续{self.consecutive_rejects}次拒绝")
            notifier.send_circuit_breaker_alert(self.consecutive_rejects)
    
    def can_trade(self) -> bool:
        if self.pause_until and time.time() < self.pause_until:
            return False
        
        # 成功交易后重置
        if self.consecutive_rejects > 0:
            self.consecutive_rejects = 0
        
        return True
```
