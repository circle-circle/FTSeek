### 1. 智能订单路由集成

**文件**: `app/trader/executor.py`

**集成代码**:
```python
from app.execution.smart_router import smart_router

# 在_execute_open 中
order = smart_router.route_order(
    code=signal.code,
    action=signal.action.value,
    price=signal.price,
    quantity=qty,
    market_data={'volatility': 0.0}
)

# 根据智能路由结果设置订单类型
if order.order_type.value == 'market':
    order_type = OrderType.MARKET
    price = 0
else:
    order_type = OrderType.NORMAL
    price = order.price

logger.info(f"智能路由：类型={order.order_type.value} "
            f"价格={price:.2f} 偏移={order.offset_pct:.1%} "
            f"原因={order.reason}")
```

**路由逻辑**:
```
订单金额 > 90% 限额 → 限价单 (2% 偏移)
港股盘前时段 → 限价单 (1% 偏移)
碎股交易 → 限价单 (1.5% 偏移)
高波动股票 → 限价单 (2% 偏移)
其他 → 市价单
```

### 2. 订单重试机制集成

**文件**: `app/trader/executor.py`

**集成代码**:
```python
from app.execution.order_retry import order_retry_manager

def _execute_order_with_retry(self, ...):
    # 第一次尝试
    ret, data = trd_ctx.place_order(...)
    
    # 如果失败且可以重试
    if ret != 0 and order_retry_manager.should_retry(temp_order_id):
        # 计算新价格
        new_price = order_retry_manager.get_next_price(...)
        
        # 记录重试
        order_retry_manager.record_retry(...)
        
        # 重试下单 (切换为限价单)
        ret, data = trd_ctx.place_order(price=new_price, ...)
    
    return ret, data
```

**重试逻辑**:
```
市价单失败 → 限价单 (1% 偏移)
限价单未成交 → 调整价格 (+0.5% 每次)
最大重试次数：3 次
重试间隔：5 秒
```
