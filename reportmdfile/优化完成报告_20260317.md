### 2. 逻辑优化

#### 2.1 置信度计算改进
**原公式**:
```python
confidence = 0.5 + (abs_score - threshold) / 10.0
```

**新公式**:
```python
base_confidence = 0.40                    # 基础置信度
score_bonus = min(0.3, (abs_score - threshold) * 0.1)    # 分数增益
strategy_bonus = min(0.2, n_strategies * 0.05)           # 策略数量增益
market_bonus = 0.1 if trending else 0.0                  # 市场状态增益

confidence = base_confidence + score_bonus + strategy_bonus + market_bonus
```

**效果对比**:
- 强信号 (2.5 分，3 策略，趋势市): 0.60 → **0.75** (+25%)
- 中等信号 (1.8 分，2 策略，震荡市): 0.53 → **0.53** (持平)
- 弱信号 (1.5 分，1 策略，趋势市): 0.50 → **0.55** (+10%)

#### 2.2 冷却时间更新逻辑
**原逻辑**: 检查冷却时立即更新时间 (即使交易失败)  
**新逻辑**: 仅在推送成功后更新冷却时间

**效果**: 避免交易失败后无法及时重试
