## 📊 2026-03-16 问题回顾

### 问题 1: 冷却时间过长导致信号丢失

**现象**:
- 多个有效信号被"冷却中"过滤
- 例如：HK.09992 在 14:28:11 触发 BUY (分数 +2.42), 14:29:38 又触发 (分数 +1.70), 都被冷却过滤
- 统计：至少 15+ 次有效信号被跳过

**原因**:
- `SIGNAL_COOLDOWN = 300 秒` (5 分钟)
- 港股交易活跃时段，5 分钟可能错过多次机会

**修复**:
```python
# app/config.py
SIGNAL_COOLDOWN = int(os.getenv("SIGNAL_COOLDOWN", "120"))  # 从 300 秒降至 120 秒
```

**效果**:
- 冷却时间缩短至 2 分钟
- 允许更频繁的信号推送，同时避免过度交易

### 问题 2: 订单金额超限

**现象**:
```
WARNING: 预估金额 HK$55,412.50 超过限额 HK$50,000.00, 拒绝下单
```

**原因**:
- 腾讯/泡泡玛特/中芯国际股价较高 (HK$500-560)
- 每手 200 股，订单金额 HK$100,000+
- 原配置 `MAX_ORDER_AMOUNT = 50000` 不足

**修复**:
```python
# app/config.py
MAX_ORDER_AMOUNT = float(os.getenv("MAX_ORDER_AMOUNT", "120000.0"))  # 从 50000 提升至 120000
```

**效果**:
- 支持 HK$600/股 × 200 股 = HK$120,000 的订单
- 覆盖腾讯/阿里等高价股 1 手交易需求

### 问题 3: 置信度计算不合理

**现象**:
```
WARNING: 风控检查失败：confidence
```

**原因**:
- 原公式过于简单：`confidence = 0.5 + (abs_score - threshold) / 10.0`
- 未考虑策略数量和市场状态
- 置信度普遍偏低 (0.5-0.6 区间)

**修复**:
```python
# app/data_subscriber.py - 改进置信度算法
base_confidence = 0.40  # 基础置信度
score_bonus = min(0.3, (abs_score - threshold) * 0.1)  # 分数增益 (上限 0.3)
strategy_bonus = min(0.2, n_strategies * 0.05)  # 策略数量增益 (上限 0.2)
market_bonus = 0.1 if market_regime == "trending" else 0.0  # 趋势市场增益

confidence = base_confidence + score_bonus + strategy_bonus + market_bonus
confidence = min(0.95, confidence)  # 上限 0.95
confidence = max(0.40, confidence)  # 下限 0.40
```

**示例计算**:
- 分数 +2.5, 3 个策略，趋势市场:
  - 原公式：`0.5 + (2.5-1.5)/10 = 0.60`
  - 新公式：`0.40 + 0.10 + 0.15 + 0.10 = 0.75` ✅

### 问题 4: 冷却时间更新逻辑错误

**现象**:
- 冷却检查在交易执行前，但冷却时间也在交易执行前更新
- 导致即使交易失败，冷却时间也被重置

**修复**:
```python
# app/data_subscriber.py
# 原逻辑：在_is_cooled_down() 中更新冷却时间
# 新逻辑：在推送成功后才更新冷却时间

# 推送成功后
with self._cooldown_lock:
    self._cooldown[code] = time.time()
```

**效果**:
- 只有成功推送的信号才计入冷却
- 避免交易失败后无法及时重试

---

### 问题 5: 风控置信度阈值过高

**现象**:
- 多次交易因 `confidence < 0.60` 被拒绝
- 但实际信号质量良好 (分数 +2.0 以上)

**修复**:
```yaml
# config/risk_config.yaml
risk_limits:
  min_confidence: 0.50  # 从 0.60 降至 0.50
```

**效果**:
- 配合新的置信度计算，更合理的过滤
- 避免过度保守导致错过机会
