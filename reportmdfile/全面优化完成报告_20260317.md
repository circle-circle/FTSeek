```bash

```

### 2. 分析信号质量

```bash
python3 scripts/analyze_signal_quality.py --days 7
```

### 3. 查看熔断状态

```python
from app.risk.circuit_breaker import circuit_breaker
circuit_breaker.print_status()
```

### 4. 查看失败统计

```python
from app.logs.failure_tracker import failure_tracker
```

```python

rec = smart_router.get_order_recommendation('HK.09992', 95.5, 200)

print(f"原因：{rec['reason']}")
```
