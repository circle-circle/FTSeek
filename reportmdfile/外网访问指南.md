## 🔐 安全配置建议

### 当前状态

⚠️ **注意**: 当前服务完全开放，建议配置以下安全措施：

### 1. 配置防火墙 (推荐)

如果后续需要启用防火墙，开放 8899 端口：

```bash
# 使用 firewalld (CentOS/RHEL)
sudo firewall-cmd --permanent --add-port=8899/tcp
sudo firewall-cmd --reload

# 使用 ufw (Ubuntu/Debian)
sudo ufw allow 8899/tcp
sudo ufw enable

# 使用 iptables
sudo iptables -A INPUT -p tcp --dport 8899 -j ACCEPT
```

### 2. 限制访问 IP (可选)

如果只允许特定 IP 访问：

```bash
# iptables 示例 (只允许特定 IP)
sudo iptables -A INPUT -p tcp --dport 8899 -s 你的 IP 地址 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 8899 -j DROP
```

### 3. 配置 HTTPS (强烈推荐)

生产环境建议配置 HTTPS：

**使用 Nginx 反向代理**:

```nginx
server {
    listen 443 ssl;
    server_name 39.97.58.4;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://127.0.0.1:8899;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

**使用 Let's Encrypt 免费证书**:
```bash
# 安装 certbot
sudo yum install certbot python3-certbot-nginx -y

# 获取证书
sudo certbot --nginx -d 你的域名
```

### 4. 修改 API Token (推荐)

生成新的安全 Token:

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

然后在 `app/config.py` 或环境变量中更新 `API_TOKEN`。

### 自动重启配置

使用 systemd 管理服务：

```bash
# 创建 systemd 服务文件
cat > /etc/systemd/system/ftseek.service << 'EOF'
[Unit]
Description=FTSeek Quantitative Trading System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ftseek/FTSeek
Environment="API_TOKEN=5a8f072c2cba9db1579dd829214a38112fdcddefe089d4ba58e05742097dd272"
ExecStart=/usr/bin/python3.8 -m app.main
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 重新加载 systemd
systemctl daemon-reload

# 启用并启动服务
systemctl enable ftseek
systemctl start ftseek

# 查看状态
systemctl status ftseek
```

```bash

```

3. 检查云服务器安全组:
   - 登录云服务商控制台
