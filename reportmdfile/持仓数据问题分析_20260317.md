## 🔧 技术说明

### 当前架构

```
富途模拟账户 ←→ FTSeek 系统 ←→ 本地数据库
     ↓              ↓              ↓
 实际持仓      交易执行      记录持仓
```

**问题**: 本地数据库的持仓是 FTSeek 自己记录的，不是从富途同步的

**原因**: 
- 系统设计为自主记录交易
- 未实现与富途持仓同步
- 测试时创建了测试数据

### 正确流程

```
交易信号 → 风控检查 → 富途下单 → 富途持仓变化
                                    ↓
                              同步到本地数据库
```
