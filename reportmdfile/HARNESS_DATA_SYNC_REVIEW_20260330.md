### 2.2 为什么多 5 条记录？

#### 可能原因 1: 重复导入 ⚠️

**分析**:
- 第一批导入：8 条
- 第二批导入：11 条
- 合计：19 条
- 实际：14 条
- **重复**: 5 条

**可能场景**:
```
第一批导入了 09:48-10:07 的 8 条
第二批导入了 10:32-11:14 的 11 条
但第二批可能包含了第一批的部分记录
```

#### 可能原因 2: 截图识别错误 ⚠️

**问题**:
- 截图时间范围重叠
- 某些交易被重复识别
- 买卖配对被重复计算

#### 可能原因 3: 富途 App 显示逻辑 🟡

**富途显示规则**:
- 可能按"配对交易"显示 (1 买 +1 卖 = 1 条)
- 数据库按"成交记录"存储 (1 买 +1 卖 = 2 条)

**计算差异**:
```
富途：7 对配对 = 7 条显示
数据库：7 买 + 7 卖 = 14 条记录
+ 5 条未配对 = 19 条
```

```sql
-- 检查重复
SELECT code, action, quantity, entry_price, entry_time, COUNT(*) as cnt
FROM trades
WHERE date(entry_time) = date('now')
GROUP BY code, action, quantity, entry_price, entry_time
HAVING cnt > 1;

-- 删除重复 (保留一条)
DELETE FROM trades
WHERE id IN (
    SELECT id FROM (
        SELECT id,
               ROW_NUMBER() OVER (
                   PARTITION BY code, action, quantity, entry_price, entry_time
                   ORDER BY id
               ) as rn
        FROM trades
        WHERE date(entry_time) = date('now')
    ) WHERE rn > 1
);
```
