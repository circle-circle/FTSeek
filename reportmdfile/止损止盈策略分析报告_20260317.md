#### 2. 引入 ATR 动态止损

**方案**: 根据波动率调整止损幅度

```python
def calculate_atr_stop(entry_price, atr, direction='BUY'):
    """
    ATR 止损 = 入场价 ± (ATR × 乘数)
    """
    atr_multiplier = 2.0  # 可配置
    
    if direction == 'BUY':
        stop_price = entry_price - (atr * atr_multiplier)
    else:
        stop_price = entry_price + (atr * atr_multiplier)
    
    # 确保止损幅度在合理范围 (5%-10%)
    stop_distance = abs(entry_price - stop_price) / entry_price
    stop_distance = max(0.05, min(0.10, stop_distance))
    
    return stop_price
```

**优势**:
- 高波动股票：止损放宽 (避免洗盘)
- 低波动股票：止损收紧 (快速止损)
- 自适应市场变化
