### 问题 1: 订单金额限制

**现象**: 腾讯控股交易被拒绝
```
WARNING: 预估金额 HK$55412.50 超过限额 HK$50000.00, 拒绝下单
```

**原因**:
- 当前配置：`MAX_ORDER_AMOUNT = 50000 HKD`
- 腾讯股价：~HK$550-560
- 默认数量：`DEFAULT_ORDER_QTY_HK = 100 股`
- 预估金额：550 × 100 = **HK$55,000** (超限 10%)

**解决方案** (任选其一):

#### 方案 A: 提高订单限额 (推荐)
```bash
# 编辑 .env 文件
echo "MAX_ORDER_AMOUNT=60000.0" >> /opt/ftseek/FTSeek/.env

# 重启服务
systemctl restart ftseek
```

#### 方案 B: 降低下单数量
```bash
# 编辑 .env 文件
echo "DEFAULT_ORDER_QTY_HK=80" >> /opt/ftseek/FTSeek/.env

# 重启服务
systemctl restart ftseek
```

### 问题 2: 信号置信度未传递

**现象**: 风控检查失败
```
WARNING: 风控检查失败：confidence
```

**原因**:
- 风控要求：`min_confidence = 0.60`
- 信号生成时：未设置 `extra['confidence']` 字段
- 风控检查：`confidence = 0.0` → 失败

**解决方案**:

需要在共识信号生成时添加置信度计算。置信度可基于：
1. 加权分数绝对值 (分数越高越可信)
2. 参与投票的策略数量 (越多越可信)
3. 市场状态 (趋势市场比震荡市场更可信)

**建议置信度公式**:
```python
confidence = min(1.0, abs(score) / 5.0 * strategy_count / 8.0)
```
