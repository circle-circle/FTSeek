## 二、三大问题深度归因

### 问题1：HK.00981 重复交易（日内2笔）

**时间线还原：**
```
10:29  开仓 HK.00981 @ 75.90  (共识: bb+rsi+vol)
13:10  平仓 HK.00981 @ 78.20  (分批止盈) → 盈利 +2.30/股
15:04  再次开仓 HK.00981 @ 77.35 (共识: rsi+bb+vol)  ← 问题所在
15:49  止损 HK.00981 @ 76.70  → 亏损 -0.65/股
```

**根因分析：**

| 层级 | 现状 | 问题 |
|------|------|------|
| 策略层 | 共识引擎在15:04再次产生BUY信号 | 策略不知道上午已交易过 |
| 风控层 | 无单股日内交易次数限制 | `max_symbol_trades_per_day` 未配置 |
| 执行层 | MANUAL模式，无自动拦截 | 即便有规则也不会生效 |

**策略行为解读：**
- 上午信号：`bb_factor + rsi_factor + vol_factor` → BUY（正确，涨了3%）
- 下午信号：`rsi_factor + bb_factor + vol_factor` → BUY（错误，追高在77.35）
- **同一批策略因子，同一只股票，日内重复触发**

**本质问题：策略无"记忆"能力**
- 共识引擎不检查今日是否已对00981执行过交易
- 无止盈后冷却机制（盈利后立即反向开仓）
- 无日内价格位置感知（77.35接近当日高点）


**时间线：**
```
14:08  HK.09988 开仓
14:16  HK.09992 开仓  (间隔8分钟)
14:26  HK.01810 开仓  (间隔10分钟)

15:04  HK.00981 二次开仓 (间隔33分钟)
15:33  HK.01211 开仓  (间隔29分钟)
```

**根因分析：**

1. **无全局开仓速率控制**
   - 5分钟内连续开仓3笔（09988→09992→01810）
   - 系统不感知"已经开了太多仓"

2. **尾盘恐慌性平仓**
   ```
   15:45  HK.09988 平仓
   15:46  HK.01810 平仓
   15:48  HK.02020 平仓
   15:49  HK.00388 平仓
   15:49  HK.09992 平仓
   15:51  HK.00981 平仓
   ```
   - 6笔集中在15:45-15:51（6分钟内）
   - 典型"不知道怎么办就全部平掉"行为

3. **策略同质化**
   - 所有信号都是 `bb_factor + rsi_factor + vol_factor` 组合
   - 三个因子同时触发多只股票 → 集中开仓
