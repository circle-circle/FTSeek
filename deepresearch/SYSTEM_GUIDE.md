## 一、系统总览

### 1.1 整体流程

FTSeek-US Deep Research 是一套**全链路、多角色协作**的量化+主观投研体系。整体流程分为四个阶段：

```
┌──────────────────────────────────────────────────────────────────────┐
│                    FTSeek-US Deep Research 全链路                     │
│                                                                      │
│  ┌─────────────┐    ┌──────────────┐    ┌─────────────┐    ┌───────┐ │
│  │ 第一阶段     │    │ 第二阶段      │    │ 第三阶段     │    │第四阶段│ │
│  │ 市场扫描     │ →  │ 个股深度研究   │ →  │ 多空辩论     │ →  │ 决策  │ │
│  │ Market Scan  │    │ Deep Research │    │ + 风险博弈   │    │ +执行 │ │
│  └─────────────┘    └──────────────┘    └─────────────┘    └───────┘ │
│        │                   │                    │               │     │
│   多渠道采集           四分析师并行          三方风险博弈      组合经理 │
│   质量闸过滤           独立出报告           激进/中性/保守    最终裁决 │
│   四信号打分           证据强度标注          压力测试          量化触发│
│   Top5 排序            数据完整性           仓位修正          交易计划│
└──────────────────────────────────────────────────────────────────────┘
```

### 1.2 设计哲学

| 原则 | 含义 |
|------|------|
| **多角色对抗** | 模拟真实投研团队：分析师→研究员→交易员→风控→组合经理，每个角色独立视角、相互制衡 |
| **证据强度标注** | 每条结论必须标注「高/中高/中/低-中/低」，杜绝无根据断言 |
| **数据完整性透明** | 每项数据标注「成功/降级/缺失」，绝不编造缺失数据 |
| **对抗性辩论** | 多头与空头独立论证，再经三方风险辩论压力测试，防止确认偏误 |
| **可追溯性** | 所有价位、指标、结论均可追溯到具体数据源和计算脚本 |

## 二、第一阶段：市场扫描与目标股筛选（Market Scan）

### 2.1 多渠道数据采集

市场扫描从**四个独立渠道**同时采集原始候选池：

| 渠道 | 数据源 | 典型规模 | 作用 |
|------|--------|----------|------|
| **Most Active**（最活跃） | FMP marketPerformance | ~50 只 | 捕捉资金关注度最高的标的 |
| **Biggest Gainers**（最大涨幅） | FMP marketPerformance | ~50 只 | 捕捉正向异动 |
| **Biggest Losers**（最大跌幅） | FMP marketPerformance | ~50 只 | 捕捉负向异动/超卖机会 |
| **StockTwits Trending** | StockTwits API | ~29 只 | 捕捉散户社交热度 |

**跨渠道去重**：同一标的出现在多个渠道（如 MU 同时出现在 most-active + sentiment），说明市场关注度叠加，会在打分时获得多渠道加成。

### 2.2 质量闸过滤（Quality Gate）

原始候选池（通常 150+ 只）需经过**多层过滤**：

#### 第一层：预筛剔除（免拉 profile，低成本过滤）

```
原始候选 ~180 只
    │
    ├── 剔除：股价 <$5 仙股（ADTX/GDC/OBAI/IVDA…占绝大多数）
    ├── 剔除：杠杆/反向 ETF（SOXS/SOXL/TZA/TQQQ/BITO/SPDN…）
    └── 剔除：宽基/商品基金
```

#### 第二层：过闸剔除（拉取 profile 后过滤）

```
预筛后候选
    │
    └── 剔除：市值 < $2B（如 RXT $1.6B、OSS $490M、EOSE $1.83B）
        → 流动性可能达标但市值不足，保守剔除
```

#### 特殊标记

- **When-issued 临时证券**（如 HONAV：Honeywell Aerospace 分拆）→ 不打分、仅记录
- **已分析过的标的**（如 SPCX、MU、INTC 在近 3-7 天内有研报）→ 标注「复用」+ 计算 delta

#### 战报示例（2026-06-16 扫描）

```
原始候选：~180 只
    ↓ 预筛剔除（仙股+杠杆ETF+基金）
    ↓ 过闸剔除（市值<$2B：4 只小盘 AI/cloud 剔除）
    ↓ 过闸 + 打分：17 只（Top5 + 候补 12）
```

### 2.3 四信号打分体系

过闸标的按**四个独立信号维度**打分，每个维度输出「分数 + 方向 + 强度」：

| 信号维度 | 评估内容 | 打分要点 |
|----------|----------|----------|
| **Catalyst（催化剂）** | 是否有离散事件驱动 | M&A确认=8；index纳入=7；做空报告=7；无催化=N/A |
| **Momentum（动量）** | 价格趋势与量价结构 | 放量破位=7-9；缩量微调=3-5；方向↑/↓+量比 |
| **Sentiment（情绪）** | 社交热度与多空比 | 偏多极端拥挤=7；分歧偏空=5；正常=5 |
| **Value（价值）** | 回撤深度+板块相对强度 | 回撤40%+板块绿=10；回撤18%=3；做空破位 override=2 |

#### 综合分与排序

- 综合分 = 四信号加权合成
- Top5 进入深度研究队列
- 候补行记录但暂不深入

#### Value Override 机制

当机械打分产生误导时，人工 override：

| 案例 | 机械 value 分 | Override 后 | 原因 |
|------|---------------|-------------|------|
| NFLX | 10（回撤41%+板块绿盘） | 10 但标注「虚高」 | 深回撤无催化 = falling knife，非买点 |
| GIL | 机械高分 | Override → 2 | 做空报告破位，非错杀 |
| FOXA | 机械中分 | Override → 5 | M&A 事件重定价，非纯错杀 |

### 2.4 输出格式

```
Top5 排序表：
| # | Ticker | 综合 | 渠道(数) | catalyst | momentum | sentiment | value | 一句话 | handoff |

候补行：
- MGNI 6.0 ·sentiment· CTV adtech read-through...
- SNAP 5.94 ·most-active+sentiment· 深回撤 value 无催化...

质量闸战报：
- 原始候选数量 / 剔除明细 / 过闸数量

数据完整性表：
- 每个渠道的数据源、状态（✅/⚠️/❌）、备注
```

## 三、第二阶段：个股深度研究（Deep Research）

通过扫描筛选出的目标股进入**四分析师并行研究**阶段。每个分析师独立出报告，互不干扰。

### 3.1 市场分析师（技术面）

#### 指标选择框架

从默认 8 个技术指标中选取 7 个（剔除同质指标），30 日窗口：

| 指标 | 类型 | 作用 | 选取理由 |
|------|------|------|----------|
| `close_10_ema` | 趋势·短 | 短期趋势/入场节奏 | 捕捉近期反弹/回调节奏 |
| `close_50_sma` | 趋势·中 | 中期趋势 | 判断修复行情是否成立 |
| `close_200_sma` | 趋势·长 | 长期趋势基准 | 界定大级别多空 |
| `macd` | 动量 | 动量交叉/强弱 | 度量动能持续性 |
| `rsi` | 动量 | 超买超卖 | 与 MACD 互补，防追高 |
| `atr` | 波动 | 止损尺度 | 跳空后波动制度变化关键 |
| `vwma` | 量价 | 量价趋势确认 | 验证反弹是否有量支撑 |
| ~~`boll`~~ | ~~波动带~~ | ~~未选~~ | 脚本仅出中轨，与均线组重复 |

#### 分析输出结构

```
1. 趋势判断（长/中/短 三层）
   - 长期：200 SMA 方向 + 价格相对位置
   - 中期：50 SMA 方向 + 价格穿越状态
   - 短期：10 EMA + VWMA + 近期摆动结构

2. 动量状态
   - MACD 正值/负值 + 趋势（加速/减速/走平）
   - RSI 区间 + 与近期极值的关系

3. 波动评估
   - ATR 绝对值 + 占现价百分比
   - 与近期 ATR 对比（扩张/收缩）

4. 关键价位（全部出自 OHLCV 实测 + 脚本计算）
   - 阻力：R1/R2 + 长期压制位
   - 支撑：S1/S2/S3 + 均线叠加位

5. 结论 + 指标汇总表
```

#### 实例：HOOD 技术面结论

> "技术面短中期偏多、长期偏空的修复行情：量价确认的反弹结构完好（站上 50 SMA/VWMA），但动量降温 + ATR 高企 + 94.40 上方未突破，方向判断为震荡偏多。守住 84 一线偏多看 94.40 突破；跌破 79 区修复结构破坏。"

### 3.3 情绪分析师

#### 双源采集

| 源 | 方法 | 数据 |
|------|------|------|
| **StockTwits API** | 公开 API 近 24h 帖子 | Bullish/Bearish 计数、watchlist 人数、帖子密度 |
| **Reddit RSS** | reddit_rss.py 近一月帖子 | 多子板覆盖（wsb/stocks/investing/个股板） |

#### 评估维度

```
1. 方向：多头/空头比例、主要多头叙事、空头/抱怨主题
2. 拥挤度：
   - 正常（热度中等，未达 meme 刷屏）
   - 拥挤（高热 + 密集发帖 + 期权高 IV）
   - 极端拥挤（反向警示意义强）
3. 证据强度：样本量 + 时效性
4. 含义：是买入兴趣的确认？还是反向指标？
```

#### 实例：MU 情绪判断

> "散户情绪偏多但拥挤，多头由'AI 内存超级周期'叙事支撑且关注度极高（watchlist 20万）；风险点是分歧正在抬头——相对 SNDK 跑输的失望 + 期权高 IV/有人主动 fade。拥挤+高 IV 意味着反向风险升高，宜作确认信号打折、不宜单凭社交热度追多。"

### 3.4 基本面分析师

#### 关键财务指标表

| 指标 | 数值 | 期间 | 来源 |
|------|------|------|------|
| 总营收 | $23.86B（+196% YoY） | FQ2 2026 | SEC 8-K |
| 毛利率 | non-GAAP 74.9% | FQ2 2026 | 公司 IR |
| EPS | $12.20 non-GAAP | FQ2 2026 | SEC 8-K |
| FCF | $6.9B（季度纪录） | FQ2 2026 | 公司 IR |
| 现金 | $16.7B | FQ2 末 | SEC 8-K |

#### 分析维度

```
1. 增长与盈利质量
   - 营收增速趋势、EPS miss/beat、盈利弹性
2. 收入结构与驱动
   - 收入分项增速、核心依赖度、多元化进展
3. 资产负债与现金流
   - 现金储备、净入金、资本结构
4. 估值水位
   - TTM P/E vs Forward P/E vs 行业中位数
   - 第三方估值站判断（GuruFocus GF Value 等）
5. 分析师评级/目标价
   - 逐条动作（带日期+机构，最可靠）
   - 共识均值（滞后，仅背景参考）
```

#### 目标价采集纪律

```
优先级：带日期的逐条动作 > 聚合站共识均值

原因：聚合站共识混入大量旧估值（如 MU 在 Q2 财报前的旧目标价），
严重滞后于最新市场定价。

示例（MU 2026-06-13）：
  逐条动作：7+ 家 6 月调价全部落 $900–$1,750（簇中枢 ~$1,050–$1,250）
  共识均值：$717–$838（滞后，不可作为定价锚）
```

## 四、第三阶段：多空辩论与风险博弈

### 4.1 多空辩论（Bull vs Bear）

四份分析师报告冻结后，分别由**多头研究员**和**空头研究员**进行对抗性论证。

#### 多头论证结构

```
1. 核心多头论点（3-4 条，每条带证据强度）
   - 例（HOOD）：增长引擎换挡——事件合约+320%、净利息+24%、Gold+36%
   - 例（MU）：盈利兑现而非叙事炒作——Q2营收+196%、毛利率74.9%创纪录

2. 预防性反驳（提前回应空头最可能的攻击点）
   - 例（HOOD）："估值40x太贵"→ 利空已在2-4月-44%回撤中定价

3. 承认的主要风险（诚实标注）
   - 例（MU）：全部多头依赖6-24财报兑现~81%毛利率指引
```

#### 空头论证结构

```
1. 核心空头论点（3-4 条，每条带证据强度）
   - 例（HOOD）：估值-增长剪刀差——forward P/E 37-44x 对上 Q1 双 miss
   - 例（MU）：估值全押6-24财报兑现指引斜率，前瞻PE是机械年化外推

2. 预防性反驳（提前回应多头最可能的辩护）
   - 例（HOOD）：多头必谈Trump Accounts催化，但已被三日+27%快速定价

3. 承认的主要支撑（诚实标注多头的优势）
   - 例（MU）：质地确为一档——毛利率/FCF/净现金三线创纪录
```

### 4.2 研究经理裁决

研究经理评估辩论质量，输出：

```
1. 辩论评估
   - 最强多头论据 + 证据强度
   - 最强空头论据 + 证据强度
   - 最弱论据（双方）
   - 裁决理由

2. 投资计划
   - 建仓节奏（分批 + 触发条件）
   - 风控触发（量化价位 + 事件触发）
   - 目标/风险比
```

### 4.3 风险辩论（三方博弈）

交易员计划出具后，由**三个不同风险偏好**的风险分析师进行压力测试：

#### 激进派（Aggressive）

- 核心问题：「计划过于保守在哪里？」
- 寻找被低估的赔率、被过度打折的确定性
- 提出具体的激进修改方案 + 明示代价

```
示例（HOOD）：
  "第二批79-80大概率永远不成交。50SMA已拐头上行、5月运营数据加速。
   修改：首批加到1/2；加仓触发上移至S1带84.10-84.49。
   代价：均价抬高约3-5%，止损仍为日收盘<79。"
```

#### 中性派（Neutral）

- 核心问题：「结构是否有可观测的缺陷？」
- 寻找触发价位与数据真值的偏差、结构性矛盾
- 提出校准建议

```
示例（HOOD）：
  "第二批加仓区与止损线几乎重叠是结构性缺陷——
   挂单距79止损仅0-1元(<0.2 ATR)，成交即贴脸止损。
   建议上移至80.5-81.5，且6/17 FOMC落地前仅执行半量。"
```

#### 保守派（Conservative）

- 核心问题：「最坏情形是什么？」
- 量化尾部风险（跳空缺口、FOMC 冲击、连环触发）
- 提出防守加固方案

```
示例（MU）：
  "6-24财报gap-down二元缺口：IV 121%、ATR 73.66已定价±7-10%跳空；
   财报盘后跳空会直接穿透$949与$854两道止损——收盘价判定形同虚设。
   加固：事件前仓位上限降到1/2；买6-24到期put对冲尾部。"
```

## 五、第四阶段：最终决策与交易执行

### 5.1 组合经理最终裁决

组合经理综合所有分析、辩论、风险压力测试，输出最终决策：

```
最终评级：买入/持有/卖出 + 仓位策略描述

风险辩论裁决：
  - 采纳哪些修正建议 + 理由
  - 拒绝哪些建议 + 理由

仓位动作（量化、可执行）：
  1. 第一批：价位区间 + 限价条件
  2. 第二批：触发条件 + 时间约束
  3. 第三批：确认信号 + 事件前提
  4. Sizing：单位风险折算比例 + 上限约束

风控触发（量化收盘价判定）：
  - 止损：价位 + 连续条件
  - 降级触发：事件 + 价位
  - 升级触发：突破确认条件
```

### 5.2 分批建仓策略（核心模式）

系统产出的交易计划遵循**严格的分批纪律**：

```
┌─────────────────────────────────────────────────────────────┐
│                    分批建仓三段法                              │
│                                                             │
│  第一批（底仓）  │  第二批（加仓）    │  第三批（确认仓）      │
│  1/3 仓位       │  1/3 仓位         │  1/3 仓位              │
│  现价区吸纳      │  回踩支撑确认      │  突破/事件后兑现        │
│  限价 ≤ X       │  收盘站稳 Y 不破   │  收盘放量 > Z + 事件落地│
│                                                             │
│  ════════════════  红线纪律  ════════════════                │
│  · 事件前 ≤ 1/2、保留 ≥ 1/3 弹药                            │
│  · 绝不裸多满仓进二元事件（财报/FOMC）                        │
│  · 止损用收盘价判定，防盘中假突破                              │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 风控触发体系

```
硬止损（清仓级）：
  - 日收盘 < 关键支撑位（如 50SMA / swing low）
  - 或连续两日收盘 < 支撑位（防假突破）

软止损（减仓级）：
  - 事件冲击（FOMC 放鹰）+ 跌破第一支撑 → 先减半
  - Boll 中轨破位 → 中间预警、停加仓

降级触发（评级下调）：
  - 财报核心指标不及指引（如毛利率 < 预期）
  - 估值锚塌陷（如从 forward PE 塌回 TTM PE）

升级触发（仓位提升）：
  - 站稳长期均线（如 200 SMA）→ 解除「不满仓」约束
  - 财报超预期 + 放量突破 → 加仓至目标仓位
```

### 5.4 实例：HOOD 最终交易计划

| 批次 | 仓位 | 触发条件 | 约束 |
|------|------|----------|------|
| 第一批 | 1/3 | 限价 ≤$87（参考收盘$86.36） | 即时建底仓 |
| 第二批 | 1/3 | $80.5–81.5 支撑带 | 6/17 FOMC 落地后再挂 |
| 第三批 | 1/3 | 日收盘放量 >$94.40 | FOMC 已落地后执行 |

**FOMC 纪律**：放鹰且收盘 <84.1 → 先减半
**升级触发**：收盘站稳 200 SMA 102.96 → 解除「不满仓」约束

### 6.2 证据强度体系

所有结论都必须标注证据强度，形成可追溯的证据链：

| 等级 | 含义 | 典型场景 |
|------|------|----------|
| **高** | 可验证的事实数据 | SEC 8-K 财报、OHLCV 实测、本地脚本计算 |
| **中高** | 多源交叉验证的信息 | 多家投行集体调价、公司 IR + 新闻确认 |
| **中** | 单源但可信的信息 | WebSearch 单一来源、分析师单一研报 |
| **低-中** | 有参考但噪声大 | Reddit RSS 无赞数、StockTwits 小样本 |
| **低** | 弱信号，仅做参考 | 单一社交帖子、未证实传闻 |

### 6.3 对抗性验证（Adversarial Verification）

系统的核心创新之一是**多层对抗性验证**：

```
第一层：多空辩论
  多头研究员 vs 空头研究员
  → 各自寻找最强论据 + 预防性反驳对方
  → 防止单边叙事的确认偏误

第二层：风险三方博弈
  激进派 vs 中性派 vs 保守派
  → 从不同风险偏好压力测试交易计划
  → 防止仓位/止损的结构性缺陷

第三层：组合经理裁决
  综合所有观点，明确采纳/拒绝的理由
  → 最终决策不是折中，而是有理有据的取舍
```

### 6.4 可追溯性设计

每个数据点都可追溯到具体来源：

```

  "现价 $86.36（2026-06-10 收盘）"

情绪数据：
  "StockTwits 25 条，Bullish 14/Bearish 4"
  → StockTwits API 2026-06-10 22:30 – 06-11 01:31 UTC
```

### 7.3 口径声明与互证纪律

```
1. 价格口径：
   - IBKR = 单交易所口径（如 NASDAQ 3-7M 股/日）
   - FMP = 合并口径（如 avg 29.2M 股/日）
   - 不得跨口径比较

2. 成交量口径：
   - Futu = 美股合并成交量口径
   - 标注 qfq 前复权

3. 目标价口径：
   - 带日期逐条动作 > 聚合站共识均值
   - 共识均值标注「滞后，仅背景参考」

4. 盘中 vs 收盘：
   - 盘中数据标注「partial-day，非收盘 finals」
   - 指标锚定最近完整收盘 bar
   - 盘中数字标注「参考价，非确认收盘」
```

### 7.4 PLAN_GATED 处理

当 FMP API 因套餐限制（PLAN_GATED）无法获取数据时：

```
1. 不重试（避免浪费 API 调用）
2. 降级到替代源（SEC 8-K / WebSearch / 公司 IR）
3. 在数据完整性表中明确标注「降级到 X 源」
4. 结论中标注降级的证据强度影响
```

## 九、策略总结与适用边界

### 9.1 策略特征

| 特征 | 描述 |
|------|------|
| **风格** | 中短线事件驱动 + 趋势跟踪 |
| **持仓周期** | 数日到数周（事件驱动型可更短） |
| **标的偏好** | 美股中大盘（市值 ≥ $2B）、有催化或动量 |
| **仓位管理** | 严格分批（三段法）、事件前留弹药 |
| **风控纪律** | 量化止损（收盘价判定）、事件触发降级 |
| **决策方式** | 多角色对抗 + 证据强度标注 + 可追溯 |

### 9.2 适用场景

```
✅ 最适合：
  · 有明确催化剂的事件驱动（M&A、index纳入、财报、产品发布）
  · 深回撤后的修复行情（需量价确认）
  · 高波动标的的趋势跟踪（ATR 定仓位/止损）
  · 板块轮动中的相对强势股

⚠️ 需要谨慎：
  · 无催化的深回撤 falling knife（value 机械虚高）
  · 做空报告破位（需先核实指控真伪）
  · 二元事件前的高仓位（财报/FOMC 缺口风险）
  · 极端拥挤的情绪（反向风险升高）

❌ 不适用：
  · 仙股/微盘股（市值 < $2B，流动性风险）
  · 杠杆/反向 ETF（非个股基本面分析对象）
  · 长线价值投资（系统设计偏中短线）
  · 无数据覆盖的标的（数据完整性是硬约束）
```

### 9.3 系统局限与风险提示

```
1. 数据时效性：
   - 盘中数据有 15 分钟延迟，非实时盘口
   - 部分数据源受 PLAN_GATED 限制需降级
   - 社交情绪采样窗口短（StockTwits 25条/数小时）

2. 模型局限：
   - 技术指标为 30 日窗口，长周期形态可能遗漏
   - 基本面依赖公开信息，未核对完整 10-Q/10-K
   - 前瞻估值为机械年化外推，非完整 DCF

3. 执行风险：
   - 高 ATR 标的的盘中假突破/假跌破
   - 盘后财报缺口的跳空穿越止损
   - FOMC 等宏观事件的板块 beta 冲击

4. 本报告仅供研究参考，不构成投资建议。
```
