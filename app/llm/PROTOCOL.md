# FTSeek Agent 交互协议

## 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                    FTSeek 系统                          │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  🌅 盘前 (08:00)                                        │
│  ┌─────────────────────────────────────────────┐       │
│  │  1. FTSeek 写入请求到 ~/.hermes/ftseek/      │       │
│  │  2. 包含：昨日复盘 + 新闻 + 记忆上下文       │       │
│  └─────────────────────────────────────────────┘       │
│                          ↓                              │
│  🤖 Hermes Agent (本地运行)                             │
│  ┌─────────────────────────────────────────────┐       │
│  │  1. 读取请求文件                             │       │
│  │  2. 利用 session 历史 + memory               │       │
│  │  3. 生成作战计划                             │       │
│  │  4. 写入 ~/.hermes/ftseek/plan.json          │       │
│  └─────────────────────────────────────────────┘       │
│                          ↓                              │
│  🌆 盘后 (16:30)                                        │
│  ┌─────────────────────────────────────────────┐       │
│  │  1. FTSeek 写入交易记录                      │       │
│  │  2. Hermes 读取并生成归因报告                │       │
│  │  3. 更新记忆 (教训/策略调整)                 │       │
│  └─────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────┘
```

## 文件协议

### 请求目录
`~/.hermes/ftseek/requests/`

### 响应目录  
`~/.hermes/ftseek/responses/`

### 记忆文件
`~/.hermes/ftseek/memory.json`

## 核心目标

**稳定赚钱** - 所有决策围绕这个核心：
1. 保本第一
2. 控制回撤
3. 持续改进
4. 不追求暴利，追求稳定
