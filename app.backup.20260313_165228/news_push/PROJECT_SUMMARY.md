## 🔧 技术实现

### 1. 数据采集层 (collector.py)

**核心类**: `NewsCollector`, `ServiceClient`

**功能**:
- 多源 RSS 解析（feedparser）
- API 调用（requests）
- 统一 HTTP 客户端（缓存、熔断、去重）
- 情绪分析（关键词匹配）
- 股票匹配（别名映射）

**数据源**:
| 类型 | 来源 | 状态 |
|------|------|------|
| 快讯 | 财联社、BlockBeats | ⚠️ API 需代理 |
| 财经 | CNBC、WSJ、新浪财经 | ✅ |
| 宏观 | 美联储、SEC | ⚠️ 需特殊处理 |
| RSS | 华尔街见闻等 | ✅ |

### 2. 规则引擎层 (rule_engine.py)

**核心类**: `RuleEngine`, `RuleResult`

**评估流程**:
1. 分类开关检查（硬性条件）
2. 关键词过滤（必须包含/必须排除）
3. 股票匹配（加分项，50% 权重）
4. 来源优先级（加分项，30% 权重）
5. 情绪分析（加分项，20% 权重）

**评分阈值**:
- 普通新闻：0.4
- 快讯/监控股票：0.3

### 3. 频率控制层 (rate_limiter.py)

**核心类**: `RateLimiter`, `PushRecord`

**限流策略**:
- 每小时最多 N 条（默认 5）
- 每日最多 N 条（默认 30）
- 冷却时间（默认 300 秒）
- 合并窗口（60 秒内消息合并摘要）

**持久化**:
- 状态文件：`data/news_push_state.json`
- 自动清理过期记录

### 4. Qwen 分析层 (qwen_analyzer.py)

**核心类**: `QwenAnalyzer`, `AnalysisResult`

**分析维度**:
- 智能摘要（30 字以内）
- 情绪分析（positive/negative/neutral）
- 影响评估（high/medium/low）
- 关键点提取（3-5 个）
- 操作建议（关注/观望/回避）

**降级策略**:
- API 不可用时自动降级为规则分析
- 缓存分析结果（减少 API 调用）

### 5. 钉钉推送层 (notifier.py)

**核心类**: `NewsNotifier`

**消息格式**:
- Markdown 渲染
- 来源图标标识
- 情绪/影响程度图标
- 相关股票显示
- 原文链接

**限流集成**:
- 尊重钉钉 20 条/分钟限制
- 与频率控制器协同

### 6. 主服务 (service.py)

**核心类**: `NewsPushService`

**运行模式**:
- 单次执行：`service.run_once()`
- 持续运行：`service.start(interval=60)`

**统计信息**:
- 总采集数
- 总推送数
- 总过滤数
- 最后运行时间

## 💡 使用建议

### 推荐配置
- 采集间隔：60 秒
- 每小时推送：5 条
- 冷却时间：300 秒
- 时间窗口：9:00-22:00
- 周末推送：关闭

### 监控股票
建议监控 5-10 只核心股票：
- 港股：腾讯、阿里、美团、小米
- 美股：苹果、特斯拉、英伟达、微软

### 关键词优化
根据实际推送效果调整关键词列表：
- 增加高价值关键词
- 排除低质量新闻
