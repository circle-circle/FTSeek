## 🔍 问题诊断与解决

### 问题 1: 共识阈值过高
```
症状: 信号产生但无法触发交易
原因: CONSENSUS_THRESHOLD = 1.5, price_break 权重 0.5, 分数 0.5 < 1.5
解决: 降低至 0.4
文件: app/config.py
```

### 问题 2: 熔断器方法缺失
```
症状: AttributeError: 'CircuitBreaker' object has no attribute 'is_paused'
原因: ConsensusEngine 调用 is_paused() 但未定义
解决: 添加 is_paused() 方法
文件: app/risk/circuit_breaker.py
```

### 问题 3: 碎股交易失败
```
症状: 订单失败，不足1手数量的碎股
原因: 下单数量 100 股 < 1手 (200股)
解决: 调整 DEFAULT_ORDER_QTY_HK = 200
文件: app/config.py
```

### 问题 4: trd_side 处理错误
```
症状: 'str' object has no attribute 'value'
原因: trd_side.value 访问错误
解决: 改为 trd_side == TrdSide.BUY
文件: app/trader/executor.py
```

### 问题 5: 推送格式错误
```
症状: 'ConsensusResult' object has no attribute 'strategy_scores'
原因: 钉钉推送格式化代码不兼容
解决: 添加兼容处理
文件: app/notifier/dingtalk.py
```
