## 二、核心问题：盈亏比失衡

### 数学证明

假设胜率 50%，盈亏比 0.85:1：

```
期望收益 = 50% × 5.2% - 50% × 6.1% = -0.45%
```

**结论**: 即使 50% 胜率，长期也会亏损。

### 盈亏比要求

| 胜率 | 所需盈亏比 |
|------|------------|
| 40% | ≥ 1.5:1 |
| 50% | ≥ 1.2:1 |
| 60% | ≥ 0.8:1 |
| 70% | ≥ 0.5:1 |

**建议目标**: 盈亏比 ≥ **1.5:1**

## 三、针对小资金高频的建议

### 1. 止损策略优化

| 策略 | 当前 | 建议 | 原因 |
|------|------|------|------|
| 固定止损 | -6.1% | **-3%** | 小资金单笔风险控制在总资金1%以内 |
| 日内止损 | -1.5% | **-1.5%** ✅ | 合理，保持 |
| 保本止损 | 未启用 | **盈利2%启用** | 保护利润不回撤 |

### 2. 止盈策略优化

| 策略 | 当前 | 建议 | 原因 |
|------|------|------|------|
| 固定止盈 | +5.2% | **+4.5%** | 提高胜率，降低触发门槛 |
| 分批止盈 | 未启用 | **+2%平50%** | 快速落袋一半，锁定部分利润 |
| 移动止盈 | 未启用 | **盈利2.5%后启用** | 保护盈利 |

### 3. 优化后参数

```yaml
# 推荐配置 (小资金高频)
stop_loss: -0.03           # 止损 -3%
take_profit: 0.045         # 止盈 +4.5%

# 盈亏比: 1.5:1

# 保本止损
breakeven_stop:
  enabled: true
  trigger_profit: 0.02     # 盈利 2% 后启用
  stop_level: 0.00         # 止损上移到成本价

# 分批止盈
partial_take_profit:
  enabled: true
  levels:
    - target: 0.02         # +2% 时平仓 50%
      ratio: 0.50
    - target: 0.045        # +4.5% 时平仓剩余
      ratio: 1.00

# 移动止盈
trailing_stop:
  enabled: true
  trigger_profit: 0.025    # 达到 +2.5% 后启用
  trail_percent: 0.015     # 回撤 1.5% 触发

# 日内止损
intraday_stop:
  enabled: true
  stop_percent: 0.015      # 日内亏损 1.5% 触发
```
