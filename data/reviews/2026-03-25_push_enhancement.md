## 改进方案

### 1. 软止损预警机制 (新增)

**概念**: 当亏损达到止损线的 80% 时，发送预警并考虑提前止损

```python
# 在 data_subscriber.py 的止损检查中添加
def _check_soft_stop(self, code: str, current_price: float, position) -> bool:
    """软止损检查：亏损达到止损线的80%时预警"""
    if not position.stop_loss:
        return False
    
    entry_price = position.entry_price
    stop_loss_price = position.stop_loss
    
    # 计算当前亏损比例
    pnl_rate = (current_price - entry_price) / entry_price
    stop_rate = (stop_loss_price - entry_price) / entry_price
    
    # 软止损阈值：止损线的 80%
    soft_threshold = stop_rate * 0.8
    
    if pnl_rate <= soft_threshold:
        logger.warning(
            f"[软止损预警] {code} 亏损 {abs(pnl_rate):.2%} "
            f"接近止损线 {abs(stop_rate):.2%}，建议提前止损"
        )
        return True
    
    return False
```

### 3. ATR 动态止损 (新增)

**原理**: 根据市场波动率动态调整止损距离

```python
def _calculate_atr_stop(self, code: str, entry_price: float) -> float:
    """计算 ATR 动态止损"""
    atr_pct = self._get_atr_percent(code)  # 从多周期K线获取
    multiplier = 1.5  # ATR 倍数
    
    # 高波动时放宽止损
    if atr_pct > 0.03:  # 波动率 > 3%
        multiplier = 2.0
    # 低波动时收紧止损
    elif atr_pct < 0.015:  # 波动率 < 1.5%
        multiplier = 1.2
    
    stop_distance = atr_pct * multiplier
    stop_price = entry_price * (1 - stop_distance)
    
    logger.info(
        f"[ATR止损] {code} ATR={atr_pct:.2%} "
        f"倍数={multiplier} 止损距离={stop_distance:.2%}"
    )
    
    return stop_price
```
