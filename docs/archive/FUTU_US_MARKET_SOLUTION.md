## 三、富途行情权限说明

### 权限类型
| 市场 | 权限名称 | 是否必需 | 费用 |
|------|----------|----------|------|
| 港股 | 港股实时行情 | 是 | 可能免费 |
| 美股 | 美股实时行情 | 是 | 可能收费 |
| A 股  | A 股实时行情 | 是 | 可能收费 |

### 权限级别
1. **延时行情** (免费) - 15 分钟延迟
2. **实时行情** (可能收费) - 实时数据
3. **深度行情** (收费) - Level 2 数据

### 免费获取方式
1. **开户入金**: 首次入金可能赠送
2. **交易活跃**: 月交易次数达标可能赠送
3. **持有股票**: 持有特定股票可能赠送
4. **促销活动**: 关注富途官方活动

### 文件位置
- `scripts/us_stock_monitor.py` - 监控脚本
- `scripts/test_us_monitor.py` - 测试脚本

### 功能
1. ✅ 通过富途接口获取美股实时价格
2. ✅ 定期查询监控股票池
3. ✅ 计算止损止盈价格
4. ✅ 钉钉推送告警

### 配置
```python
# 持仓成本 (根据实际持仓修改)
POSITIONS = {
    "AAPL": {"cost": 170.0, "qty": 100},
    "MSFT": {"cost": 400.0, "qty": 50},
    "NVDA": {"cost": 800.0, "qty": 30},
}

# 止损止盈
STOP_LOSS_RATIO = 0.10        # -10%
TAKE_PROFIT_1_RATIO = 0.15    # +15%
TAKE_PROFIT_2_RATIO = 0.25    # +25%
TAKE_PROFIT_3_RATIO = 0.40    # +40%

# 查询间隔
QUERY_INTERVAL = 300  # 5 分钟
```

### 使用方法
```bash

python3.8 scripts/us_stock_monitor.py

# 后台运行
nohup python3.8 scripts/us_stock_monitor.py > logs/monitor.log 2>&1 &
```

## 七、决策建议

### 推荐方案：开通富途美股行情权限

**理由**:
1. **数据质量**: 实时、准确、可靠
2. **集成便利**: 与现有 FTSeek 项目无缝集成

- 可能有免费试用期

- 预算有限
