**Phase 2: 动态权重计算** (每月调整一次)

```python
def calculate_dynamic_weights(model_accuracy):
    """基于历史准确率计算动态权重"""
    total_correct = sum(m["correct"] for m in model_accuracy.values())
    total = sum(m["total"] for m in model_accuracy.values())
    
    if total == 0:
        return get_default_weights()  # 返回默认权重
    
    weights = {}
    for model, stats in model_accuracy.items():
        if stats["total"] > 0:
            accuracy = stats["correct"] / stats["total"]
            weights[model] = accuracy
        else:
            weights[model] = 0.25  # 默认权重
    
    # 归一化
    total_weight = sum(weights.values())
    return {k: v/total_weight for k, v in weights.items()}
```
