## 二、核心设计决策

### 1. 信号评分系统 (从布尔值→评分值)

**设计理由**:
- 现有系统：满足条件就开仓，无信号强弱区分
- 新系统：0-100 分评分，区分信号质量

**评分阈值**:
```
< 50 分：不交易
50-70 分：小仓位 (25%)
> 70 分：正常仓位 (50-100%)
```

**8 个评分因子**:
| 因子 | 权重 | 说明 |
|------|------|------|
| 趋势确认 | 20% | 均线/突破确认 |
| 成交量 | 15% | 量比>1.5 |
| 波动率适配 | 10% | ATR 在合理范围 |
| 大盘同向 | 15% | 标普/纳指同向 |
| 历史表现 | 10% | 近 20 次胜率 |
| 新闻情绪 | 10% | 情绪分析得分 |
| 市场状态适配 | 10% | 策略适配当前 regime |
| 风险收益比 | 10% | 预估盈亏比 |

### 2. 四级熔断系统

**设计理由**:
- 单一熔断器不够灵活
- 需要分级响应不同级别风险

| 级别 | 触发条件 | 响应 |
|------|----------|------|
| 策略级 | 连续 5 笔亏损 | 暂停该策略 30 分钟 |
| 品种级 | 5 分钟波动>5% | 暂停该品种交易 |
| 账户级 | 日内回撤>3% | 暂停开新仓 (Soft Stop) |
| 系统级 | 行情断流>60 秒 | 暂停所有交易 |

### 3. 三段式风控

**预交易风控** (下单前):
- 单笔最大亏损/仓位检查
- 单品种/单方向敞口
- 账户杠杆上限
- 日内交易次数限制
- 流动性/滑点检查

**持仓中风控** (实时):
- 浮盈回撤监控
- 浮亏扩大监控
- 波动率上升监控
- 风险暴露超限

**交易后风控** (成交后):
- 实际成交价 vs 预期
- 持仓更新验证
- 风险限额重算

### 4. 组合式止盈止损

**7 种退出方式** (优先级从高到低):
1. `hard_stop` - 账户级/风险级必须立即执行
2. `structure_stop` - 市场结构破坏
3. `volatility_stop` - 异常波动
4. `time_stop` - 时间止损 (72 小时)
5. `trailing_stop` - 移动止损 (ATR×2)
6. `scale_out` - 分批止盈 (30%/30%/40%)
7. `target_hit` - 目标位达成

### 5. 订单状态机

**10 种状态**:
```
CREATED → VALIDATED → SENT → ACKED → PARTIALLY_FILLED → FILLED
                         ↓
                    REJECTED / CANCELED / EXPIRED / UNKNOWN
```

**幂等机制**:
- 每笔订单唯一 `client_order_id`
- 防止重复下单
- 支持断线重连后状态恢复

### 6. 统一事件流

**所有交易动作都写入事件日志**:
```python
events = [
    "signal_generated", "signal_rejected",
    "order_submitted", "order_filled",
    "position_updated", "stop_loss_triggered",
    "risk_blocked", "alert_sent",
]
```

**支持**:
- 按时间范围回放
- 持仓生命周期追踪
- 审计和归因分析

## 三、多 Agent 协作

### Agent 角色

| Agent | 职责 | 模型 |
|-------|------|------|
| **Main** | 总协调器，接收信号→分发引擎 | Qwen3.5-Plus |
| **Decision** | 信号生成 + 评分 + 市场状态 | DeepSeek-Chat |
| **Risk** | 风控检查 + 熔断判定 | GLM-5 |
| **Execution** | 订单路由 + 执行优化 | Qwen3.5-Plus |
| **Observability** | 监控告警 + 失败分析 | Qwen3.5-Plus |

### 协作流程

```
1. Main Agent 接收行情/策略触发
       ↓
2. Decision Agent 生成信号评分
       ↓
3. Risk Agent 预交易风控检查
       ↓
4. Execution Agent 执行订单
       ↓
5. Observability Agent 记录事件 + 监控
       ↓
6. Risk Agent 持仓中监控 (持续)
       ↓
7. Execution Agent 退出执行 (止盈止损)
       ↓
8. Observability Agent 归因分析
```

## 四、数据模型

### 核心数据类

1. **SignalScore** - 信号评分
   - direction, strength (0-100), confidence
   - expected_horizon, market_regime, risk_reward

2. **Order** - 订单
   - 完整生命周期状态
   - 幂等 ID (client_order_id)

3. **Position** - 持仓
   - 入场/出场信息
   - 止损止盈配置
   - 归因数据

4. **TradeEvent** - 交易事件
   - 统一事件流
   - 支持回放

5. **FailureRecord** - 失败记录
   - 4 类失败分类
   - 恢复状态追踪
