# 战略路线图:退出驱动型交易系统

> 活文档 — 随每阶段进展持续更新。最后更新:2026-07-22
> 定位:这是系统的**主线战略文档**。所有 RFC/ADR/proposal 都应服从本文档确立的战略基石。

## 一、战略共识(2026-07-22 确立)

### 系统定位
**耐心埋伏 + 关键时刻爆发型系统**:平时靠退出纪律不亏死,把子弹省下来,等明确风口来了能抓住。不追求每天赢,不追求完美预测,接受股市的不确定性,只要能持续迭代、并在关键机会上不缺席。

### 五条贯穿原则(不可违背)
1. **LLM 定位 = 信息收集员 + 情报评估员,不是方向预言家。** 方向由退出纪律和人工重大判断兜底,不对 LLM 方向预测抱过高期望。
2. **退出是核心赚钱引擎。** 承认入场约等于随机,靠"截断亏损 + 让利润奔跑"赚钱。一切优先级围绕退出纪律。
3. **需要盘中时机/纪律的决策全部交给代码,不留人工插手口子。** 理由:操盘者自认"心理偏 A(舍不得砍)、无盘中纪律",机器的意义就是替"理智的自己"执行 B(该砍就砍)。
4. **自动交易全程不停机,边跑边修。** 所有改进在活链路上迭代,用真实表现暴露问题再针对性修复。绝不为"重构完美"停机。
5. **新规则先 shadow 后实盘。** 任何新退出/入场规则先 record-only 攒证据,统计判分优于基线才实盘化。

### 人工手动单的定位
保留能力,但**不作强制要求、不投入重点资源**。仅在盘前/盘后、信息明确、不需抢时机的重大利空利多机会上,由冷静的操盘者手动决策。真正持续迭代完善的是**自动交易链路**。

## 二、决策依据:7月交易数据解剖(2026-07-22)

样本:2026-07-01 至今,97 笔已平仓 PLAYBOOK_SIM 单(7月前为测试数据,已排除)。

### 硬结论(可信度高)
- **方向预测无 edge:** 整体胜率 45.4%,二项检验 p=0.42,95%CI 35.5%~55.3% 横跨 50% —— 统计上与抛硬币不可区分。LONG 精确 50/50。
- **盈利来自退出,不来自方向:** 净利 +$178.9 全部由退出端锁利贡献 —— SL_TRAIL_LOCK(16笔100%胜,+$420)+ EOD_FORCE_CLOSE(+$363)+ 1笔 TAKE_PROFIT(+$247)。
- **最大出血口 = TIME_EXIT:** 17 笔全亏,净 **-$464**。若堵上此漏洞,7月盈利从 +$179 → 约 +$643。根因:系统"会锁利、不会止损",靠"拖到6小时超时"兜底,而拖到超时的单已亏透(ORCL 为典型)。
- **LLM 置信度是反向指标:** 置信度≥0.75 的单胜率仅 34.3%(vs <0.6 档 51.9%)。**不可依据置信度加仓。**

### 参考结论(样本不足,未达显著)
- 持仓周期:4-24h 最赚(+$580,盈亏比2.24),1-4h 是死亡地带(-$341),<1h 稳定微赚(+$101)。
- 机会类型:趋势动量类唯一净正且样本够(n=22,+$248);事件驱动、板块轮动净负。(分类基于中文 thesis 启发式,缺结构化字段,不严谨。)
- Cohort:A 组(+$320)显著优于 B 组(-$141),但定义差异待查。

## 三、分阶段行动计划

状态标记:⬜ 未开始 / 🔄 进行中 / ✅ 通过验收 / ⏸ 暂停

### 阶段一:止血(1-2 周)—— 状态:🔄
**目标:** 消灭 TIME_EXIT 出血口和 1-4h 死亡地带,从"微赚"拉到"稳赚小钱"。

**动作:**
1. 🔄 **修 TIME_EXIT 止损逻辑(最高优先级)** —— 引入"方向未在合理时间兑现即认赔"的主动止损,替代"拖6小时"。用 time_to_mfe/mae + early_tight/TIME_EXIT 反事实 shadow 数据定阈值,不拍脑袋。
   - **17笔逐笔深挖(2026-07-22):** 平均 MFE 峰值仅 0.17%,14/17 笔 MFE<0.3%(方向几乎从未兑现);MAE 普遍 0.5~2.7%(浮亏持续扩大)。典型:AMD 拖87.3h/MFE=0/亏$161,ORCL 6h/MFE0.03%/MAE2.74%。**结论:这些不是"慢热赢家被误杀",是"入场即错却硬扛数小时"的死单。**
   - **铁律信号:** 入场后 30~60min 内 MFE 摸不到 0.3% → 极大概率死单,应认赔而非等超时。
   - **修复方案(先shadow):** "早期方向证伪止损" = 入场后 X 分钟(候选30/60)若 MFE 从未达 Y%(候选0.3/0.5)→ 主动止损。复用现有 early_tight shadow 框架。
   - **数据缺口:** 历史17笔 time_to_mfe 为空(该字段今日才加),精确阈值需等新数据(今起积累)判分。
2. ⬜ 排查 1-4h 死亡地带(-$341),与第1项联动。
3. ⬜ 高置信度不放大仓位(置信度反指问题)。
4. ⬜ 清理脏数据源(mae_pct 57/97 缺失、ghost close 11笔 -$142)。

**验收门槛(通过才进阶段二):**
- TIME_EXIT 类净亏损收窄到接近 0 或转正(先 shadow 反事实验证,再实盘)。
- 连续 2 周(≥10 交易日)净期望为正,无单日巨亏(> 单笔正常止损 3 倍)。

### 阶段二:打磨验证(2-4 周)—— 状态:⬜
**目标:** 证明"退出驱动"的正期望可复现、非运气。样本从 97 → 200+。

**动作:**
1. ⬜ 补齐结构化"机会类型"字段(事件/趋势/板块/其他),替代中文文本瞎猜。
2. ⬜ 趋势动量类重点观察攒样本,暂不 all-in。
3. ⬜ 退出参数 shadow 判分(early_tight / MFE门变体 / TIME_EXIT 反事实)跑满2周后择优实盘化。
4. ⬜ cohort A/B 差异深挖。

**验收门槛(通过才进阶段三):**
- 样本 ≥ 200 笔,整体正期望,盈亏比稳定 > 1.3。
- 最大回撤可量化、可控(定一个可承受的百分比上限)。
- 至少一类机会/一个参数组,shadow 判分统计上优于基线。

### 阶段三:小仓位实盘(数据达标后)—— 状态:⬜
**目标:** 用最小仓位验证纸面优势在真钱环境(滑点/成交/心理)下是否成立。

**动作:**
1. ⬜ 上真钱硬门槛(全满足才开):阶段二验收通过 + acb/preflight fail_mode=closed(已做)+ 实盘启动断言(已做)+ 单日/单笔亏损硬上限锁死。
2. ⬜ 最小仓位起步,滑点/成交质量单独跟踪(slippage_report)。
3. ⬜ 人工轨接入(非重点):重大利空利多推送 + 人工手动单,须先解决 ①谁判定"重大" ②人工单与自动单持仓隔离(is_playbook_open_position 不可绕过)。

**验收门槛(才准逐步加仓):**
- 实盘小仓位连续 N 周正期望,滑点未吃掉纸面优势。
- 回撤表现与模拟盘一致。
