## 二、回测系统设计

### 2.1 系统架构

```
┌─────────────────────────────────────────────────────┐
│                  回测引擎 V2                         │
├─────────────────────────────────────────────────────┤
│  数据层          │  DataLoader                      │
│  ├── K线数据     │  SQLite / CSV / API              │
│  └── 历史信号    │  signal_records/*.json           │
├─────────────────────────────────────────────────────┤
│  策略层          │  BacktestStrategy                │
│  ├── price_break │  价格突破策略                     │
│  ├── rsi         │  RSI 超买超卖策略                 │
│  ├── ma_cross    │  均线交叉策略                     │
│  └── fusion_v2   │  融合策略 (可扩展)                │
├─────────────────────────────────────────────────────┤
│  执行层          │  BacktestEngine                  │
│  ├── 信号生成    │  generate_signals()              │
│  ├── 订单模拟    │  滑点 + 佣金                      │
│  └── 仓位管理    │  max_positions + position_size   │
├─────────────────────────────────────────────────────┤
│  评估层          │  BacktestResult                  │
│  ├── 绩效指标    │  Sharpe / Calmar / MDD           │
│  ├── 交易统计    │  Win Rate / Profit Factor        │
│  └── 资金曲线    │  equity_curve                    │
└─────────────────────────────────────────────────────┘
```

## 三、优化建议

### 3.1 短期修复 (已完成)

| 问题 | 修复 | 影响 |
|------|------|------|
| TrdSide 未定义 | 文件顶部统一导入 | +14 信号可执行 |
| RetryReason 错误 | 正确导入方式 | +8 信号可执行 |
| 价格精度 | 添加 _round_hk_price | +6 信号可执行 |
| 碎股限制 | 修正每手股数配置 | +6 信号可执行 |
| .value 错误 | 兼容处理 | +4 信号可执行 |

**预期执行率**: 0% → **86%+**

### 3.2 中期优化

1. **信号质量提升**
   - 提高共识阈值: 0.4 → 0.6 (减少弱信号)
   - 添加趋势过滤: ADX > 25 时才开仓
   - 置信度校准: 历史数据验证置信度与胜率关系

2. **风控增强**
   - 动态止损: 根据波动率调整止损幅度
   - 分批止盈: 2% 平 50%, 4% 平剩余
   - 日内止损: -1.5% 强制平仓

3. **执行优化**
   - 智能路由: 根据流动性选择订单类型
   - 重试机制: 失败后自动调整价格重试
   - 碎股处理: 自动调整为整手

### 3.3 长期规划

1. **多策略融合**
   - 技术面: price_break + rsi + ma_cross
   - 情绪面: 新闻情绪分析
   - AI 面置信号过滤

2. **自适应参数**
   - 市场状态识别: 趋势/震荡
   - 参数动态调整: 根据市场状态切换参数
   - 在线学习: 实时优化权重

3. **组合优化**
   - 多标的分散: 降低单一标的风险
   - 相关性管理: 避免同向持仓
   - 资金管理: 凯利公式 / 风险平价
