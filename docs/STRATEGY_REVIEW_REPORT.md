# FTSeek 策略组合审查报告

**报告日期**: 2026-04-06
**审查范围**: 信号混乱、组合冲突、质量低效问题

---

## 一、审查背景

检查当前策略组合是否存在：
1. 信号混乱 - 多策略产生冲突信号
2. 组合冲突 - 功能重叠的策略同时启用
3. 质量低效 - 配置参数不合理导致信号质量下降

---

## 二、发现的问题

### 2.1【严重】fusion_v2 与 confluence_v2 信号冲突

**问题描述**:
- `fusion_v2` 和 `confluence_v2` 同时启用
- 两者都产生融合信号，导致：
  - 同一标的可能收到两个融合策略的不同信号
  - 权重计算混乱 (两个融合策略权重相近)
  - 共识引擎无法有效区分信号来源

**配置对比**:
```yaml
# confluence_v2 (纯技术因子融合)
enabled: true
enabled_factors: [rsi, macd, bollinger, supertrend, ma_cross, volume]

# fusion_v2 (技术 + 情绪融合)
enabled: true  # ⚠️ 冲突
technical_weight: 0.5
sentiment_weight: 0.5
```

**影响**:
- 信号重复投票：confluence_v2 和 fusion_v2 可能同时产生 BUY 信号
- 权重失真：两个融合策略权重叠加，导致技术信号过度加权
- 决策混乱：当两个策略给出相反信号时，共识引擎无法有效仲裁

---

### 2.2【中等】共识阈值配置偏低

**问题描述**:
- 配置文件中 `consensus.threshold = 1.1`
- 代码默认值为 `1.5`
- 阈值过低导致：
  - 更容易达成"共识"，但信号质量下降
  - 可能触发低置信度交易
  - 增加误判率

**配置对比**:
```yaml
# 配置文件
consensus:
  threshold: 1.1  # ⚠️ 偏低

# 代码默认值 (consensus_engine.py)
CONSENSUS_THRESHOLD = 1.5
```

**影响**:
- 阈值 1.1 意味着 confluence_v2(1.5) 单独即可触发交易
- 失去了"多策略共识"的意义
- 可能增加亏损交易比例

---

### 2.3【轻微】sentiment_ai 权重不一致

**问题描述**:
- 代码中基准权重：`0.5`
- 配置文件中权重：`0.8`
- 差异导致配置管理混乱

**配置对比**:
```python
# consensus_engine.py
DEFAULT_BASE_WEIGHTS = {
    "confluence_v2": 1.5,
    "supertrend":    1.0,
    "sentiment_ai":  0.5,  # 代码默认值
}
```

```yaml
# config.yaml
strategy:
  weights:
    sentiment_ai: 0.8  # ⚠️ 与代码不一致
```

**影响**:
- 配置管理不清晰
- 不利于后续维护和调试

---

## 三、已执行的修复

### 3.1 禁用 fusion_v2

**修改文件**: `config/config.yaml`

```yaml
# 修改前
fusion_v2:
  enabled: true

# 修改后
fusion_v2:
  enabled: false  # ✓ 已禁用，避免与 confluence_v2 冲突
```

**理由**:
- confluence_v2 已包含 6 个技术因子，功能完整
- fusion_v2 的"技术 + 情绪"融合功能与 sentiment_ai 独立策略重叠
- 禁用后信号来源更清晰，避免融合策略之间的冲突

---

### 3.2 提高共识阈值至 1.5

**修改文件**: `config/config.yaml`

```yaml
# 修改前
consensus:
  threshold: 1.1

# 修改后
consensus:
  threshold: 1.5  # ✓ 与代码默认值一致
```

**理由**:
- 阈值 1.5 需要至少 2 个策略确认才能触发交易
- 符合"多策略共识"的设计理念
- 过滤低质量信号，提高交易胜率

---

### 3.3 统一 sentiment_ai 权重

**修改文件**: `config/config.yaml`

```yaml
# 修改前
weights:
  sentiment_ai: 0.8

# 修改后
weights:
  sentiment_ai: 0.5  # ✓ 与代码默认值一致
```

**理由**:
- 配置与代码保持一致
- sentiment_ai 作为辅助确认策略，权重不宜过高
- 0.5 的权重足以影响决策，但不会主导

## 四、修复后的策略组合

### 4.1 策略架构

```
┌─────────────────────────────────────────────────────────┐
│  主力策略：confluence_v2 (权重 1.5)                       │
│  - RSI (超买超卖)                                        │
│  - MACD (趋势跟踪)                                       │
│  - Bollinger Bands (均值回归)                            │
│  - SuperTrend (趋势跟踪)                                 │
│  - MA Cross (均线交叉)                                   │
│  - Volume (成交量确认)                                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  趋势策略：supertrend (权重 1.0)                          │
│  - 纯趋势跟踪，在强趋势行情中表现优异                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  情绪策略：sentiment_ai (权重 0.5)                        │
│  - AI 新闻情绪分析                                        │
│  - 辅助确认，提供基本面视角                               │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  增强策略：open_close_effect (独立触发)                    │
│  - 开盘/收盘效应                                          │
│  - 捕捉日内特定时段的交易机会                             │
└─────────────────────────────────────────────────────────┘
```

### 4.2 共识引擎参数

| 参数 | 值 | 说明 |
|------|-----|------|
| threshold | 1.5 | 触发交易所需的加权分数 |
| min_strategies | 2 | 最少需要的策略数量 |
| window_seconds | 90 | 信号收集窗口 (秒) |
| adx_trend | 25 | ADX 高于此值判定为趋势市 |
| adx_range | 20 | ADX 低于此值判定为震荡市 |

### 4.3 权重分配

| 策略 | 权重 | 角色 | 信号类型 |
|------|------|------|----------|
| confluence_v2 | 1.5 | 主力 | 技术因子融合 |
| supertrend | 1.0 | 趋势 | 纯趋势跟踪 |
| sentiment_ai | 0.5 | 辅助 | AI 情绪确认 |
| **总计** | **3.0** | - | - |

**触发条件**:
- **BUY**: 加权和 ≥ 1.5 (例如：confluence_v2 BUY + supertrend BUY = 2.5 ≥ 1.5 ✓)
- **SELL**: 加权和 ≤ -1.5
- **HOLD**: -1.5 < 加权和 < 1.5

## 六、后续建议

### 6.1 定期审查策略表现

建议每周审查以下指标：
- 各策略触发次数
- 各策略胜率
- 各策略平均盈亏
- 共识信号 vs 单一信号表现

### 6.2 动态权重调整

根据策略表现，考虑：
- 每季度回顾权重配置
- 对连续表现优异的策略适当提高权重
- 对连续表现不佳的策略降低权重或暂停使用

### 6.3 监控信号质量

设置告警规则：
- 单日信号数 > 10 次 → 检查阈值是否过低
- 单一策略触发占比 > 70% → 检查策略配置
- 共识达成率 < 30% → 检查策略分歧原因
