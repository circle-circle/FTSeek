## 一、三个问题与预注册判据

### Q1 该不该切实盘（GO / NO-GO）

**全部满足才 GO**（数据窗：2026-07-24 新基线起，PLAYBOOK 口径）：

| # | 判据 | 阈值 | 数据源 |
|---|---|---|---|
| G1 | 每笔期望值 | ≥ $0，**连续 4 周**（周度不回负） | exit_scorecard（=OKR KR1 强化版） |
| G2 | Profit Factor | ≥ 1.3（终裁窗整体） | exit_scorecard |
| G3 | 样本量 | ≥ 150 笔已平仓（新基线后） | trade_records |
| G4 | 存活 | 最大回撤 <5% 且无连续 5 笔亏损（=OKR KR4） | drawdown/scorecard |
| G5 | 杀赢家比例 | ≤ 15%（=OKR KR2） | exit_scorecard |

任一不满足 → NO-GO，进入 Q3 赛道裁决。**不设"接近达标酌情放行"条款。**

### Q2 如何切（GO 之后的实盘机制，预注册）

1. 首期资金 = 总可投资金的 **5~10%**，且单笔风险沿用 sim 参数（不因"实盘了"而加仓——OKR 铁律：期望未稳前禁止放大）；
2. 三门/触发门/风控/回滚开关全部原样带入，`PLAYBOOK_LIVE` 与 sim 同一套代码路径（已具备）；
3. 实盘前两周为"对照期"：live 与 sim 并跑，逐笔对比滑点/成交率/PnL 偏差，偏差 >30% 即暂停回检；
4. 硬约束沿用：PDT、-2% 停新仓、-3% 全平熔断、单日亏损线；
5. 首月只做 GO 判据达标的那条赛道，不混跑。
