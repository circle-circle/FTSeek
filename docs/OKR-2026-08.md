# OKR: DA-FTSeek 链路达到"正期望且可存活" (2026-07-14 → 2026-08-31)

> 上一轮 (OKR-2026-07) 结算: MISSED。根因不是预测不准 (信号持到收盘 50.8% 偏正),
> 而是**退出纪律漏血** (退出把赢家砍成亏损, R:R 1.07 < 盈亏平衡 1.29 → 负期望)。
> 本轮换 KPI: 不追胜率/收益数字, 只追**每笔期望值**。收益是期望转正后的自然结果。

## 🎯 Objective
**让 DA-FTSeek 链路的成交结构达到正期望值,并在此过程中先活着。**
重心在 **FTSeek 退出侧**(信号已够用);DA 侧只做"倾斜到已验证的因子"这一件次要事。

---

## 📊 Key Results

判分工具统一为 `scripts/exit_scorecard.py`。**样本口径: `date ≥ 2026-07-11`**(单脑收敛 + 黑名单停用后的干净窗口)。

### KR1 (核心): 每笔期望值 ≥ $0
- 目标: `exit_scorecard` 的 `expectancy_per_trade ≥ 0`,基于 **≥ 40 笔**干净样本。
- 基线 (污染窗口): **−$10.57/笔**。
- 含义: 只要这个 ≥0,就是"活着 + 靠积累"的正循环起点。

### KR2 (漏血): 退出杀赢家比例 ≤ 15%
- 目标: `killed_winners / (pos_win + pos_loss) ≤ 15%`(收盘为正的单子里,被退出做成亏损的占比)。
- 基线: **8/31 ≈ 26%**。
- 这是最直接的漏血点;把它压下去,胜率会自然从 41% 回升向 51%。

### KR3 (赔付): R:R ≥ 盈亏平衡线
- 目标: `exit_scorecard` 的 `rr_gap ≥ 0`(即 avg_win/avg_loss ≥ (1−胜率)/胜率)。
- 基线: R:R 1.07 vs 盈亏平衡 1.29,**缺口 −0.22**。
- 手段: 让赢家跑 / 砍输家更快 —— **不是**放大仓位。

### KR4 (存活): 最大回撤 < 5% 且无连续 5 笔亏损
- 先活着是前提。触及即触发"停手复盘",不硬扛。

### KR5 (诊断,非门禁): confidence 与方向 edge 观察
- 剥离 confidence 加权后(见 Guardrail 3),随干净样本积累观察 Playbook IC 是否转正。
- BUY / SHORT 分别对齐 SPY 当天基准的超额命中率(避免把大盘漂移当 edge)。
- 仅观察,不作为达标门禁。

## 🔄 每周迭代循环 (治"不知道怎么调")

**每周五盘后,只做这四步,不多做:**
```
1. 跑 scripts/exit_scorecard.py            → 拿到 期望值 / 杀赢家数 / R:R 缺口
2. 只问一个问题: 赢家还在被砍吗? R:R 离盈亏平衡还差多少?
3. 只改一个退出参数 (其余全冻结)           → 如止损放宽 / 移动止损延后 / 止盈上移
4. 下周同一张表对比: 变好→保留, 变差→回滚
```
**铁律: 一次一个变量、一个指标、可回滚。** 同时动多个参数 = 又迷路。

## 🚧 Guardrails (取代上一轮的危险对策)

1. **期望值转正前,禁止**用增加 `position_size` / 放大 R:R 去追收益 —— 负期望下加仓 = 加速亏损。收益不是旋钮,是结果。
2. **一次只改一个退出参数**,用 `exit_scorecard` 判分,变差立即回滚。
3. **`confidence_sizing` 保持关闭(拍平为 1.0)**,直到 KR5 显示 IC 校准为正 —— 当前 confidence 反向,按它加仓有害。
4. **保持 Paper。** 未通过毕业门禁(期望≥0 + KR2/KR3 达标 + 存活)绝不接 live broker;切换沿用 OKR-SPEC.md 的 Paper→Live 人工签字门禁 + `_submit_order` 风控层。
5. **DA 侧克制。** 只做"往已验证因子(如 `insider_cluster_buy`,贝叶斯胜率下界 0.55)倾斜、砍掉纯掷硬币因子";不重设计因子体系,除非 KR5 显示信号整体无预测力。
