## 🔒 模拟盘保护机制

### 环境变量配置

```bash
# .env 文件
FORCE_SIMULATE_MODE=true      # 强制模拟盘
REAL_TRADING_LOCKED=true      # 实盘锁定
MIN_SIMULATE_DAYS=14          # 最少模拟天数
MIN_SIMULATE_TRADES=100       # 最少交易数
TARGET_WIN_RATE=0.55          # 目标胜率
TARGET_PROFIT_FACTOR=1.5      # 目标盈亏比
```

### 代码保护

```python
# opend_executor.py
force_simulate = os.getenv('FORCE_SIMULATE_MODE', 'true').lower() == 'true'
real_locked = os.getenv('REAL_TRADING_LOCKED', 'true').lower() == 'true'

if force_simulate or real_locked:
    self.simulate = True  # 强制模拟盘
    logger.warning("⚠️ 强制模拟盘模式已启用")
```
