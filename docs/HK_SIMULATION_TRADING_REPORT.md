## 📖 数据访问

**API 端点**:
```bash
# 获取所有持仓
curl "http://39.97.58.4:8899/api/simulation/positions?token=xxx"

# 获取所有交易
curl "http://39.97.58.4:8899/api/simulation/trades?token=xxx"

# 过滤港股 (客户端)
curl "http://39.97.58.4:8899/api/simulation/trades?token=xxx" | \
python3 -c "import sys,json; d=json.load(sys.stdin); \
print('港股交易:', [t for t in d['data'] if t['code'].startswith('HK.')])"
```

**数据库查询**:
```sql
-- 港股持仓
SELECT code, quantity, avg_cost, current_price 
FROM simulation_positions 
WHERE code LIKE 'HK.%';

-- 港股交易
SELECT code, action, entry_price, quantity, entry_time 
FROM simulation_trades 
WHERE code LIKE 'HK.%' 
ORDER BY entry_time DESC;
```
