# 美股监控器使用指南

> 基于 FTSeek 框架的美股中长线投资自动止损止盈系统  
> 最后更新：2026-03-24

---

## 📋 功能概述

**适用场景**:
- ✅ 中长线投资 (持有数天到数周)
- ✅ 自动止损止盈执行
- ✅ 跨时段监控 (美美股夜间交易)
- ✅ 低频检查 (降低 API 调用)

**不适用场景**:
- ❌ 高频交易/日内交易 (请使用实时订阅)
- ❌ 需要毫秒级响应的策略

## 🚀 快速开始

### 1. 配置监控股票

编辑 `/opt/ftseek/FTSeek/config/us_stock_config.yaml`:

```yaml
individual_stocks:
  US.AAPL:
    name: Apple Inc.
    enabled: true
    stop_loss: -0.10           # 止损 -10%
    take_profit: 0.20          # 止盈 +20%
  
  US.NVDA:
    name: NVIDIA Corp.
    enabled: true
    stop_loss: -0.12
    take_profit: 0.25
```

### 2. 配置 Cron 定时任务

```bash
crontab -e
```

添加以下任务:

```bash
# 美东交易时段 (北京时间 21:30-次日 04:00) - 每 5 分钟检查
*/5 21-23 * * * cd /opt/ftseek/FTSeek && /usr/bin/python3.8 scripts/us_stock_monitor_cron.py >> logs/us_monitor.log 2>&1
*/5 0-3 * * * cd /opt/ftseek/FTSeek && /usr/bin/python3.8 scripts/us_stock_monitor_cron.py >> logs/us_monitor.log 2>&1

# 美东非交易时段 - 每 15 分钟检查
*/15 4-20 * * * cd /opt/ftseek/FTSeek && /usr/bin/python3.8 scripts/us_stock_monitor_cron.py >> logs/us_monitor.log 2>&1
```

### 3. 验证配置

```bash
# 测试运行
cd /opt/ftseek/FTSeek
python3.8 scripts/us_stock_monitor_cron.py

# 查看日志
tail -f logs/us_monitor.log
```

## 📊 核心功能

### 1. 自动止损止盈

**止损逻辑**:
```
当前盈亏 ≤ 止损线 → 自动平仓
示例：止损 -8%，买入价$100，股价≤$92 时触发
```

**止盈逻辑**:
```
当前盈亏 ≥ 止盈线 → 自动平仓
示例：止盈 +15%，买入价$100，股价≥$115 时触发
```

### 2. 追踪止盈 (Trailing Stop)

**工作原理**:
1. 当盈利达到 `trailing_trigger` (默认 10%) 时启用
2. 记录持仓期间的最高价 (峰值)
3. 当从峰值回撤 `trailing_percent` (默认 5%) 时触发

**示例**:
```
买入价：$100
峰值价：$120 (盈利 20%)
回撤 5%: $120 × 0.95 = $114
触发价：$114 (仍盈利 14%)
```

### 3. 钉钉推送通知

**触发时推送**:
```
🎯 美股交易提醒

📈 标的：US.NVDA
🔔 事件：止盈触发
💰 盈亏：✅ +15.23%
💵 入场：$120.50
💵 出场：$138.85
⏰ 时间：2026-03-24 22:35:15
```

## 🔧 配置说明

### 全局配置 (us_stock_config.yaml)

```yaml
monitor:
  check_interval: 300          # 正常时段 5 分钟
  night_interval: 900          # 夜间 15 分钟
  dingtalk_enabled: true       # 启用钉钉推送
  push_on_trigger: true        # 触发时推送

defaults:
  stop_loss: -0.08             # 默认止损 -8%
  take_profit: 0.15            # 默认止盈 +15%
  trailing_stop:
    enabled: true
    trigger: 0.10              # 盈利 10% 启用追踪
    percent: 0.05              # 回撤 5% 触发
```

### 个股配置

```yaml
individual_stocks:
  US.TSLA:
    stop_loss: -0.15           # 特斯拉波动大，放宽止损
    take_profit: 0.30          # 止盈 30%
    trailing_stop:
      trigger: 0.20            # 盈利 20% 启用追踪
      percent: 0.10            # 回撤 10% 触发
```

## 📝 与港股实时订阅的对比

| 特性 | 港股实时订阅 | 美股定期监控 |
|------|-------------|-------------|
| **数据频率** | 实时 (1 分钟 K 线) | 定期 (5-15 分钟) |
| **API 调用** | 持续订阅 | 按需查询 |
| **适用策略** | 短线/日内 | 中长线 |
| **资源占用** | 高 (持续连接) | 低 (间歇查询) |
| **触发延迟** | <1 分钟 | 5-15 分钟 |
| **交易时段** | 港股 9:30-16:00 | 美股 21:30-04:00 |

## ⚠️ 注意事项

### 1. 富途 API 限制

- 行情查询频率：建议≥5 分钟/次
- 快照数据：默认 1 秒延迟 (免费账户)
- 实时数据：需要开通 LV1/LV2 行情

### 2. 交易风险

- **T+1 制度**: 当日买入次日才能卖出
- **夜间流动性**: 非美东时段流动性较差
- **财报季**: 波动加剧，建议调整止损参数
- **汇率风险**: 美元/人民币汇率波动

### 3. 建议配置

**保守型** (稳健投资):
```yaml
stop_loss: -0.08      # 止损 8%
take_profit: 0.15     # 止盈 15%
check_interval: 300   # 5 分钟检查
```

**激进型** (高波动标的):
```yaml
stop_loss: -0.15      # 止损 15%
take_profit: 0.30     # 止盈 30%
trailing_stop:
  trigger: 0.20       # 盈利 20% 启用追踪
  percent: 0.10       # 回撤 10% 触发
```

## 📞 故障排查

### 问题 1: 无法连接富途 API

```
错误：Connection refused
解决:
1. 确认 FutuOpenD 运行中：ps aux | grep OpenD
2. 检查端口：netstat -tlnp | grep 11111
3. 重启 OpenD: systemctl restart futuopend
```

### 问题 2: 钉钉推送失败

```
错误：DingTalk API error
解决:
1. 检查 .env 配置：DINGTALK_WEBHOOK
2. 测试推送：python3.8 scripts/test_dingtalk.py
3. 检查网络：curl $DINGTALK_WEBHOOK
```

### 问题 3: 止损止盈未触发

```
排查步骤:
1. 查看持仓：python3.8 scripts/check_positions.py
2. 手动查询股价：python3.8 scripts/us_stock_monitor_cron.py
3. 检查日志：grep "检查" logs/us_monitor.log
```
