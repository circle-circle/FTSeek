# 附录 B: Shadow A/B 验证落地方案

**目标**: 用低风险 shadow 实验验证"取消盈利仓 EOD 强平 → 持有到 ~T+5" 是否提升 IC→PnL 转化。不改实盘。

## B.1 队列 (Cohort) 分配

- 入口: 信号生成/入场时 (`trade_records.metadata_json`), 按 `hash(f"{symbol}-{trade_date}") % 2` 分配:
  - **Cohort A (对照)**: 现有行为 — EOD 强制全平 (PRE_CLOSE_EXIT / ORB_EOD_EXIT)。
  - **Cohort B (试验)**: 盈利且未触发止损的仓位 **跳过 EOD 平仓**, 持有过夜, 到 T+5 或趋势破坏退出。
- 字段: `metadata_json.cohort ∈ {"A","B"}` + `metadata_json.cohort_max_hold_days` (B 设 5)。

## B.2 试验组 (B) 退出规则变更

在三条退出路径的 EOD 判断处加 cohort 分支 (示例改 `pipeline.py:1128`):

```python
# 规则4: 盘末退出
cohort = meta.get("cohort", "A")
if not exit_reason and 0 <= minutes_to_close <= 8 and minutes_from_open > 0:
    if cohort == "B" and profit_pct > 0 and days_held < meta.get("cohort_max_hold_days", 5):
        # B 组: 盈利仓跳过 EOD 平仓, 持有过夜 (仍受 overnight_loss_stop / SL 约束)
        pass
    else:
        exit_reason = "PRE_CLOSE_EXIT"
        exit_price = current_price
# B 组新增: T+5 max-hold 强制退出
if cohort == "B" and not exit_reason and days_held >= meta.get("cohort_max_hold_days", 5):
    exit_reason = "MAX_HOLD_T5"
    exit_price = current_price
```

- 仍保留: ATR 止损 (规则1, 优先级最高) + overnight_loss_stop_pct 0.03 + earnings_guard (财报前减仓 50%)。
- ORB (`orb/exits.py:130`) 与 position_exit_monitor 的 pre_close 同理加分支。

## B.3 度量 (从 trade_records 直接取, 无需新表)

```sql
SELECT
  json_extract(metadata_json,'$.cohort') cohort,
  COUNT(*) n,
  ROUND(AVG(pnl_pct),2) avg_pnl_pct,
  ROUND(SUM(realized_pnl),0) sum_pnl,
  ROUND(AVG(holding_hours),1) avg_hold_h,
  SUM(CASE WHEN pnl_pct>0 THEN 1 ELSE 0 END)*100.0/COUNT(*) win_rate_pct
FROM trade_records
WHERE exit_time IS NOT NULL AND exit_time!=''
GROUP BY json_extract(metadata_json,'$.cohort');
```

关键指标: (1) B 组平均 PnL > A 组; (2) B 组 win_rate ≥ A 组; (3) B 组 holding 中位数向 1-5 天迁移; (4) B 组是否吃隔夜跳空 (`MAX_HOLD_T5` vs overnight SL 比例)。

## B.4 决策门禁 (decision gate)

跑满 **2 周 或 每组 ≥ 50 笔** 后评估:
- **PASS**: B 组 sum_pnl > A 组 且 win_rate 不降 → 推广 (主线 EOD 强平改为盈利仓可选过夜)。
- **FAIL**: B 组因隔夜跳空亏损 → 信号/持仓周期确实不匹配, 回到日内但需另寻 alpha。
- **INCONCLUSIVE**: 延长到 4 周 / 100 笔。

## B.5 风险与缓解

| 风险 | 缓解 |
|---|---|
| 隔夜跳空 | overnight_loss_stop_pct 0.03 + 仅盈利仓过夜 (亏损仓仍 EOD 处理) |
| PDT 规则 | 当前 shadow 阶段无 PDT 约束; 上实盘前复核 |
| B 组样本不足 | MAIN_PIPELINE 188 + ORB 11 是主力, 优先在这两组分流 |
| cohort 分配偏差 | hash 分配, symbol 维度均衡 |

## B.6 注意事项

- **这是策略决策, 不是 bug 修复**。EOD 强平是日内的有意设计, 改它涉及隔夜风险, 需充分 shadow 验证后再推广。
- 不要在生产 exit_policy 直接改; 先在 shadow 监控 (`monitor_playbook_shadow_exits` / ORB shadow) 做 A/B。
- 与附录 A 的 IC 结论配套: 若 B 组 PASS, 即证明"信号是周级 alpha 被日内壳困住"的假设。
