## 一、优化内容

### 1.1 推送逻辑优化

**优化前**:
```python
# 仅在有交易时推送
if report['summary']['total_trades'] > 0:
    notifier.send_text(markdown_text)
```

**优化后**:
```python
# 无论有无交易都推送 (每日必推)
try:
    notifier = get_notifier()
    if notifier:
        notifier.send_text(markdown_text)
        logger.info("[盘后复盘] 已推送钉钉")
    else:
        logger.warning("[盘后复盘] 钉钉通知器未初始化")
except Exception as e:
    logger.error(f"[盘后复盘] 钉钉推送失败: {e}", exc_info=True)
```

**优化收益**:
- ✅ 用户每天都能收到复盘报告，确认系统运行正常
- ✅ 无交易时也能知晓，避免"今天系统是否工作"的疑虑
- ✅ 形成固定的每日反馈闭环

- ⚠️ `50%-59%`: 黄色警告 (勉强及格)
