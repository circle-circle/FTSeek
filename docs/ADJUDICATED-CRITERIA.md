## 使用规则

1. 新方案提案时, 先 `grep` 本字典; 命中编号直接引用, 格式 `[判据 A3]`
2. 判据到期未裁决 = 治理缺口 (同控制环路台账, 周检应可见)
3. 本字典只收**已终裁**判据; 进行中/待裁的留在各 DEB, 不预收录
4. 判据被推翻时: 本行改状态为"已推翻→指向新判据", 不删行 (留痕)
