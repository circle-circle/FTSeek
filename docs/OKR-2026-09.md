# OKR: 模拟链路"让证据可用 + 预注册找 edge"（2026-08-24 → 2026-09-30）

> 上一轮 `OKR-2026-08.md` 于 2026-08-23 **提前结算为 SUPERSEDED**（非 MISSED）。
> 根因（DEB-20260823 §二~§四，Hermes 独立复核全部精确复现）：
> ① 毛期望精确为零（n=321，t=+0.03，95%CI [−6.51,+6.70]），全部净亏损 = 费用（−$4.54/笔）；
> ② 旧 KR1"每笔期望 ≥ $0"需 n≈1386 才可测，8.7 个月内不可得——**是尺子测不出，不是努力不够**；
> ③ 每周退出调参循环 7 周 7 个参数版本（每窗 46 笔/7.1 天），MDE ±$40/笔追 $5-10 效应 = 过拟合机器；
> ④ pooled 显著性因同日聚类（67 信号/日）系统性夸大约 8 倍，头条 IC +0.1265 系子集选择产物（全表重算按日聚类真值 t=0.62）。
> **用户裁决（2026-08-23）**：前期都是学费，不 STOP；延续打磨模拟交易链路；**没有打标（毕业）前严格不切实盘**；更新更贴合实际的目标。本 OKR 即该裁决的落地。
> **8/31 终裁作废**——以预注册毕业判据取代固定日期裁决（不卡日期，数据说话）。

## 🎯 Objective
**让模拟链路产出统计上可用的证据，并用修好的尺子预注册裁决一个入场侧假设。**
- 模拟交易**照常进行**（~46 笔/周），为单一参数版本窗口积累样本——打磨的对象从"退出参数"转为"测量装置 + 入场侧"。
- 杠杆转移依据：退出调参已被证明数学上不能改变毛期望（最优停止定理，7月胜率 51.6%→8月 59.0% 而毛利 −$0.5 是实证）；唯一可能产生利润的是入场侧事前 edge > 10bps 费用线（DEB §8.3）。
- **打标前严格不切实盘**：四锁 + 毕业门禁 + 用户签字三重闸，见 KR4。

## 📊 Key Results

### KR1（修尺子）：全部统计输出符合测量标准 — 第 1-2 周
- a) 所有 IC/记分牌输出**按日聚类值与 pooled 值成对**；任何 t 值必须标注聚类口径。
- b) 撤下 `signal.ic_t1=+0.1265` 头条（子集选择产物），`okr_latest.json` 头条改按日聚类 IC。
- c) 记分牌增加 **MDE 列**；不带 MDE 的结论不予采信（宪章第 9 律，本轮立）。
- d) **停用 confidence-based playbook IC 作为毕业判据**——它在测量常量（confidence 自 08-14 恒=70，对常量做 Spearman 无意义；现值 −0.32 纯属并列值处理 artifact）。
- 判分：脚本输出格式核查 + 落档。二元，无歧义。

### KR2（参数冻结）：9 月退出参数 config_version 唯一值数 = 1 — 全月
- **废止**"每周五改一个退出参数"循环（OKR-2026-08 §每周迭代循环，§三证明其输出与掷硬币不可区分且带选择方向）。
- `config/playbook_horizon.yaml` 退出段冻结；例外通道仅限 P0 bug（须 DEB 落档 + 用户知会）。
- 价值：~46 笔/周 × 5.5 周 ≈ **250 笔单版本样本** = 系统历史上第一个统计可用窗口（此前 7 个窗口全被换参切碎）。
- 诚实披露：n=250 仍测不出 +$10/笔（需 283），但 MDE 收缩到 ±$8.4 量级，足以对"毛期望=0"做首次有功效的确认/证伪——这是此后任何退出结论的先决条件。
- 判分：`SELECT config_version, COUNT(*) FROM trade_records WHERE trade_date>='2026-08-24' AND source_type='PLAYBOOK_SIM' GROUP BY 1` → 唯一值数 = 1（换版即 KR2 破）。
  - **勘误（2026-09-03 复盘批 · 判分口径修正，判据意图未改）**：上式查的是 `trade_records.config_version` **列** = 配置档案版本（实测恒 `v2`，n=92）→ 唯一值数永远 = 1，**KR2 按字面永远"达成"= 结构性假绿**。退出参数哈希在 `metadata_json.config_version`（`exit-*`，`app/playbook/config.py:188` 生成）。**正确判分式**：
    `SELECT COALESCE(json_extract(metadata_json,'$.config_version'),'(null)') v, COUNT(*) FROM trade_records WHERE trade_date>='2026-08-24' AND source_type='PLAYBOOK_SIM' GROUP BY 1` → 唯一值数 = 1。
    实测（2026-09-03 09:35 CST）：`exit-7f5263af3cfd` 58 笔 / `exit-2623be9c8879` 21 / `exit-f837b002896d` 12（另 1 行无哈希），`exit-de49b1299290` 自 9/3 夜起 → **唯一值数 = 3（今晚起 4），按本 KR 原文"换版即 KR2 破"已破**。同病灶也在日级守卫 `scripts/daily_invariant_check.py::_check_config_freeze`（原先只查列 → 恒 `ok`，换版当天不告警），已同批修为两维（档案列 + 退出哈希）并接 `data/config_freeze_baseline.json` 豁免清单对账；周六周检 `ops/hermes/ftseek_weekly_checkpoint.py:67` 一直读对（故此前只有周检看得见分裂）。
  - **待用户裁决（不得擅自结算）**：4 版均经 DEB + 用户裁走豁免通道，但 `config_freeze_baseline.json` 自身注记写明"改本文件=改判据，须先改 OKR/DEB"，而本 OKR 变更记录此前零行 → 判据与事实分叉，9/30 结算将自评失真。二选一：**(a)** 修订 KR2 为按 cohort 分段判分 + 明写变更预算（如每月 ≤1 次且必须影子先行）；**(b)** 宣布 9/3 起硬冻结至 9/30 — 算术上仍可行：19 交易日（9/7 劳动节休市）× 11.3 笔/日 ≈ **215 笔单版本样本**，接近本 KR 的 250 目标，是项目史上第一个统计可用窗口；若继续每 1-2 天换版，9 月样本与 8 月同样作废。详见 `docs/reviews/REVIEW-20260903-postmarket-chain-and-ruler-audit.md` §四.2 与判据字典 C1 行。

### KR3（找 edge）：预注册入场侧假设，只许一个 — 第 2-4 周
- 只许**一个**假设进入检验（防止七路并发改动重演）。候选池（9 月开跑会预注册其一，用户裁决）：regime 门禁细化 / 方向×涨幅证伪门扩展 / 量能门。
- 判据（**预注册，期间禁改阈值**，宪章第 6 律）：按日聚类 t>2 + MDE 覆盖声称效应 + 样本外窗口验证。
- 若证伪 → 如实记录，**不立即换下一个假设**（防链式 fishing）；下一步 10 月开跑会裁决。
- 诚实先验：已在 440 候选 / 1,813 信号 / 4,057 快照上找过，全为零——本 KR 的期望产出是**干净的证伪或确认**，不是"必须找到 edge"。

### KR4（实盘硬门）：四锁零松动 + 毕业门禁重定义 — 全月
- 四锁保持（2026-08-23 实测全闭）：`AUTO_TRADE_ACCOUNT=sim` / `ALLOW_REAL_TRADING=false` / `execute_mode: futu_simulate` / 毕业门禁 fail-close（实测 `graduated=False`）。
- **毕业门禁重定义**：现判据（confidence IC>0.05）无效（测常量，当前恒 false 系巧合安全），须基于 KR1 修好的尺子重新定义，新判据**预注册 + 用户批准**后才生效。生效前门禁保持现状不动（fail-close = 安全）。
- 周六 09:05 周检增加"四锁状态"项（第 1 周落只读脚本）。
- **"没有打标前严格不切实盘"= 用户明令**：预注册毕业判据通过 + 用户签字之前，任何切实盘请求默认拒绝。

### KR5（成本意识，非门禁）：学费明码标价
- ~46 笔/周 × $4.54 ≈ **$210/周** = 延续模拟的显性成本。用户已裁"前期都是学费"，接受此成本换取单版本样本。
- 约束：数据量优先 ≠ 烧费用——禁止加仓/提频换样本；禁止追盈亏数字（继承 OKR-2026-08 guardrail 1）。

## 🚧 Guardrails（继承 + 新增）
1. 禁止用仓位/频率追盈亏（继承）。
2. **参数冻结期禁止改退出参数**（除 P0 bug + DEB 落档）。

5. 阈值预注册（宪章第 6 律）：KR3 判据写死在预注册时刻，期末之前不得改动。
