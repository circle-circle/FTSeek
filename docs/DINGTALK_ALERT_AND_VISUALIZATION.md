## 🚀 使用方式

### 访问可视化大屏

**URL**: `http://你的服务器 IP:8899/risk/dashboard`

例如：
```
http://aitz.cc:8899/risk/dashboard
```

### 配置钉钉通知

钉钉通知已自动集成，无需额外配置。

警报会在以下情况触发：
- 持仓距离止损<2% (CRITICAL)
- 持仓距离止损<4% (WARNING)
- 持仓亏损>5% (WARNING)
- 总回撤>10% (CRITICAL)
- 持仓集中度>30% (WARNING)
- 总仓位>90% (WARNING)

## 📊 大屏功能详解

### 1. 风险评分卡片

显示综合风险评分 (0-100) 和风险等级：

| 分数范围 | 等级 | 颜色 |
|----------|------|------|
| 0-40 | LOW | 🟢 绿色 |
| 40-60 | MEDIUM | 🟡 黄色 |
| 60-80 | HIGH | 🟠 橙色 |
| 80-100 | CRITICAL | 🔴 红色 |

### 2. 核心指标

- **总资金** - 当前总资金
- **总仓位** - 已用资金比例
- **当前回撤** - 从峰值回撤百分比
- **胜率** - 盈利交易占比

### 3. 持仓风险

每个持仓显示：
- 市值
- 未实现盈亏
- 止损距离
- 风险等级 (LOW/MEDIUM/HIGH)

### 4. 最近警报

显示最近 5 条警报，包括：
- 警报级别
- 警报类型
- 警报内容
- 时间戳

## 🔧 自定义配置

### 修改警报阈值

编辑 `app/risk/realtime_monitor.py`:

```python
# 预警阈值
self.stop_loss_warning_threshold = 0.02      # 2%
self.large_loss_threshold = -0.05            # 5%
self.concentration_threshold = 0.30          # 30%
self.drawdown_warning_threshold = 0.10       # 10%
```

### 修改刷新频率

编辑 `app/static/risk_dashboard.html`:

```javascript
// 修改倒计时数字
countdown = 5;  // 改为其他秒数
```

### 修改钉钉@用户

编辑 `app/risk/dingtalk_alert.py`:

```python
dingtalk_alert_sender = DingTalkAlertSender(
    DingTalkAlertConfig(
        webhook_url=url,
        secret=sec,
        at_all=True,           # @所有人
        at_users=["user1"],    # @指定用户
    )
)
```

## ⚠️ 注意事项

### 1. 钉钉通知

- 确保钉钉机器人已配置
- Webhook URL 和 Secret 必须正确
- CRITICAL 警报会@所有人，谨慎使用

### 2. 可视化大屏

- 需要浏览器支持 ES6
- 建议全屏显示 (F11)
- 自动刷新会消耗少量流量

### 3. 性能

- 默认 5 秒刷新一次
- 高频刷新会增加服务器负载
- 建议不要低于 3 秒
