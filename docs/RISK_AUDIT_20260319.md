## 🔴 严重风险 (立即处理)

### 1. 多进程冲突

**发现**: 3个FTSeek进程同时运行

```
PID 180306: 运行 1小时21分
PID 180349: 运行 1小时20分  
PID 181086: 运行 1小时3分
```

**影响**:
- 信号重复处理
- 交易重复执行
- 数据库写入冲突
- 富途API订阅冲突
- 内存浪费

**解决方案**:
```bash
# 停止所有旧进程
pkill -f "app.main"

# 确认停止
ps aux | grep "app.main"

# 重新启动单个实例
cd /opt/ftseek/FTSeek && bash start.sh
```
