# RFC-177 盘前报价可信度闸 + 隔夜出场三条不变量

- 日期: 2026-10-30
- 类型: L1 (记录侧新增判据 + 成文不变量; 默认不改任何交易动作)
- 归属: `scripts/premarket_exit_shadow.py`
- 关联: RFC-174 (断连判据与数据面缺口分离)、RFC-175 (EXT sync_status 口径)、RFC-176 (日K单键缓存) —— 三者的推理与实测见各自 commit message
- 用户裁决: 2026-10-30「确认」(阈值宽档 10%/2%、P1 直接做、把"盘前亏损侧不平仓"写成不变量)

## 1. 缘起

2026-10-29 盘后复核发现隔夜仓的亏损几乎全部由开盘跳空构成 (12 笔 OVERNIGHT_GAP_STOP,
Σ-3,828, 0% 胜率), 且 12/12 是 LONG、11/12 在开盘 20 分钟内入场、12/12 入场日收盘即水下。
讨论"要不要加盘前止损"时, 需要一个能回答两件事的实测:

1. 盘前止损 (亏损侧) 是否真的省损失?
2. 盘前兑现 (利润侧, 现役已在跑) 是否真的有收益?

## 2. 证据

数据源 A: `trade_records` (A10 口径: `trade_date>=2026-07-01` ∧ `data_quality∈(clean,real)` ∧ 非 POSITION_SYNC/MANUAL), 已平 721 笔。
数据源 B: `data/premarket_exit_shadow.jsonl` (2026-09-16→10-29, 17,440 行, 165 个持仓-日), 含每 tick 的
`executable_price` / `effective_sl` / `spread_pct` / `quote_age_seconds`。

### 2.1 盘前止损 (亏损侧) = 负收益, 不采纳

对"盘前 executable 价对穿 effective_SL"的持仓-日, 假设当刻按现价平, 与实际结局对比:

| 口径 | n | 反事实 Σ | 实际 Σ | Δ | 误杀 |
|---|---|---|---|---|---|
| 全样本 | 35 | -5,960 | -1,337 | **-4,623** | 26 |
| 剔除 1 笔垃圾价 (ADSK 2026-10-20 04:02, \|cf\|>50%名义) | 34 | -2,694 | -1,341 | **-1,353** | 25 |

只有 9 笔盘前平更优, 合计 +264。触发时点: 08:00-09:29 22 笔 / 04:00-04:30 6 笔 / 04:30-05:30 5 笔 / 05:30-08:00 2 笔。
与 2026-09-17 的 60 交易日回放 (sl_only -1.176%, 三方案最差) 同向。

### 2.2 盘前兑现 (利润侧) = 正收益, 保留

28 笔盘前平仓 Σ+371 (全胜); 取可结算 19 笔 (剔除 1 笔脏日K) 做反事实:

| 方案 | Σ |
|---|---|
| 实际: 盘前触发即平 | **+323** |
| 若等 09:30 开盘平 | -263 (Δ+586) |
| 若持到当日收盘平 | -208 (Δ+531) |

### 2.3 垃圾价实锤

ADSK 2026-10-20 04:02 ET 的 executable 打印使持有仓"浮亏 -56%", 当日实际 +4.2 出场。
同一份数据里 04:00-04:30 的触发占 6/35 —— 开窗 30 分钟的盘前报价噪声最大。

## 3. 判据 (本批落地)

`quote_implausible_adverse(executable, prev_close, spread_pct, direction)`:

- 只判**对持仓方向不利**: `adverse = (px - prev_close)/prev_close*100*sign < 0`
- 双条件同时成立才算脏: `adverse <= -EXT_QUOTE_SANE_MAX_ADVERSE_DEV_PCT (默认10)` ∧ `spread_pct >= EXT_QUOTE_SANE_MAX_SPREAD_PCT (默认2)`
- 顺序跳空 (+12%) 永不判脏 —— 那是兑现机会, 挡它有害无益
- 任一输入缺失 → fail-open (不挡): 数据不全不是证据

现状: `EXT_QUOTE_SANE_ENFORCE=false` (默认) ⇒ **只落行不决策**, 新增三列
`quote_implausible` / `quote_implausible_reason` / `quote_sane_enforce`。
转硬后该 tick 走既有 `no_executable_quote` 分支 (不新开路径)。

预注册判据 (转硬前提): 连续 ≥5 交易日 ∧ 命中 ≥5 次 ∧ 命中行里"若不挡则会产生平仓"的 ≥1 次 ∧
误挡 (真实跳空被挡且事后证明该平) = 0 → 提请转硬。回滚: env 保持 false。

## 4. 隔夜出场三条不变量 (成文, 防止下轮被重复提案复活)

1. **盘前不做止损执行。** 亏损侧只记录 (`hold_no_stop`), 09:30 起交 RTH 全链。
   依据: §2.1 (n=35 无偏重放 Δ-1,353) + 2026-09-17 回放 (sl_only 最差) + 2026-08-21 AMZN 误杀回滚。
2. **隔夜不设深度闸/夜数闸。** 八种变体的反事实 Δ 全为负 (当日收盘全平 -2,332 / 水下就砍 -2,092 /
   LONG 不留夜 -1,460 / 限 1 夜 -824 / 限 2 夜 -469 / 限 3 夜 -441 / 深水闸 <-2% -352 / <-3% -87+0)。
   限夜数尤其注意: 隔夜仓在当日收盘价附近往往是局部低点, 次日盘中反弹给出更好的实际退出价。
3. **隔夜跳空不可用止损参数治理。** 12 笔 gap stop 平均亏幅 -5.67%, 成交价由开盘决定。
   "不大亏损"只能来自 (a) 入场质量 (12/12 入场日即水下) 与 (b) 名义敞口, 不是 SL 松紧。

任何复活尝试必须: 先在本不变量之上声明基线 → 给出可复算的反事实 Δ → 预注册判据 → 影子先行。
