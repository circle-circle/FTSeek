## 3. ADF 判别力实测 (本次加严的实证依据)

复用生产 `adf()` 函数 (未改动生产代码) 跑替代世界 (n=29, lag=1, 500 次):

| 喂给 ADF 的序列 | 判「平稳(5%)」通过率 |
|---|---|
| 真实序列整体**下移 $1000/天** (注定巨亏) | **100%** (t 逐位不变: −5.4599) |
| 真实序列**取反号** (等幅反号策略) | 100% |
| 真实序列**打乱日期顺序** | 100% |
| 恒亏 **$50/天** ± $1 | 88.0% |
| 等方差纯噪声 (均值 −$17.8/日) | 86.8% |
| 亏损**逐日加深** (−100→−200) | **0%** |
| 随机游走 (累计抖动) | 2.8% |

⇒ ADF 只抓「水平系统性漂移/随机游走」, 对**均值大小与正负完全无感**。
本序列还结构性地必然通过: 出场日归集 (每笔只落一次) + SL 封顶 (单笔有界 −$387~+$444) + 日间 lag-1 自相关 **−0.07** ≈ 独立 ⇒ 平稳性近乎同义反复。

## 4. 提议方案 (已落地)

**原则: 不新造第三套门槛 — 门槛数字全部取自 RFC-077 (唯一数字源); 判据只作周检早期预警, 实盘化仍以 RFC-077 六道门禁为准。**

| # | 判据 | 口径 | 本次读数 |
|---|------|------|---------|
| c1 | OOS ≥15 日 | 不变 | 29 ✅ |
| c2 | 日净均值 > 0 **∧ t ≥ 2** | 同 RFC-077 G1 (「净 bps 按日等权 t > 2」); df<5 用 df 校正临界 (12.706/4.303/3.182/2.776), 不看 2.0 | +0.86 (t=+0.01, df=28) ❌ |
| c3 | 毛均值 t > 1 (供给端) | 不变 | +70.41 (t=+1.22) ✅ |
| c4 | ADF 平稳 (5%, lag=1) | 保留为**体检项**, 报告明写「仅证伪水平漂移 + 通过 ≠ 有 edge」, 并附其余阶 (lag0/2/3) 判定 | t=−4.11 ✅ (其余阶: lag0 平稳/lag2 边缘/lag3 非平稳) |
| c5 | **成本覆盖**: 净 bps (按日等权) − 活体滑点 30bps > 0 | 同 RFC-077 G2 (30bps 为活体保守值) | +0.09 − 30 = **−29.91bps** ❌ |

配套呈报 (均 record-only):
- **净留存行**: 毛/费/净 每笔 + 费吃掉毛利百分比;
- **MDE 行**: n 日 / sd → 80% 功效可分辨 ±$X/日, 并判「当前日均落在噪声内 ⇔ 与 0 不可分辨」(本次 ±$174 vs +$0.86);
- **高费率笔告警**: 往返费用/名义 > 1% 的笔 (按费率降序, 本次 US.CTNT 9.15% / US.GIPR 2.04%, 费用合计 $552.12);
- **多阶 ADF 保守侧总结行**: 各阶一致平稳 / 各阶一致非平稳 / ⚠️ lag 依赖 (以最保守一档为准), 防读者只带走最先出现的 lag;
- **未达标项列举**: `未达标 — 不建议讨论实盘化 (未达标项: 日净均值显著性, 成本覆盖)`。

**本次结论翻转**: 旧口径「四项全满足」→ 新口径 **未达标** (日净均值显著性 + 成本覆盖)。

## 6. 风险与缓解

| 风险 | 缓解 (已落地) |
|------|--------------|
| 自投递脚本抛异常 = 整条消息消失 | `per_trade_rows()` 表结构不符时降级 `[]`; `adf()` 对奇异矩阵/负方差返回 NaN (不抛); `mean_t()` 零方差返回 ±inf; NaN 一律 **fail-close** (判据按不满足计) 且文案写「不可检」; 测试以 `-W error::RuntimeWarning` 跑, 保证投递文本无警告噪音 |
| 加严后的门长期不过 → 读者改读 «习惯性忽略» | 每次推送都列「未达标项」, 是早期预警而非裁决; 权威口径仍在 RFC-077, 本条不承担放行职责 |
| 门槛被当成新判据源 (第三套并行) | 常量处注明「与 RFC-077 G1/G2 同档, 不新造」; 报告抬头明写「实盘化以 RFC-077 六道门禁为准」 |
| 名义额/费用列缺失 ⇒ c5 误报通过 | c5 在无数据时判 ❌ + 文案「降级: 按不满足计」(只少报不误报) |
