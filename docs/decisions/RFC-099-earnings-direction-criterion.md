# RFC-099 财报日方向判据: 幅度定方向, 财报好坏不定方向

- **状态**: **生效中** (判据已定 + 影子攒样中; **不写任何执行代码**)
- **日期**: 2026-09-23 (用户提问「对于财报日 如何选择做多还是做空?」→ 「盘前和盘后 富途app和接口可以执行做空, 按建议执行」)
- **相关**: RFC-097 (判据②换口径 + 涨幅带) · RFC-098 (RTH fade 影子) · `scripts/earnings_direction_check.py` (判据实证) · `scripts/earnings_direction_path_shadow.py` (攒样器)

## 1. 问题

财报日到底该做多还是做空? 现役系统实际怎么定?

## 2. 现役实读 (2026-09-23)

| 通道 | 方向怎么来 | 原文 |
| --- | --- | --- |
| 盘前 / 盘后 (财报票通道) | **没有方向分支** | 唯一下单口 `place_order(..., trd_side=TrdSide.BUY)`（`extended_hours_entry_executor.py:2595`）; 全文 **0 处** `SELL_SHORT/TrdSide.SELL` |
| 盘中 (RTH) | DA(LLM) 逐单产出 BUY/SHORT/SKIP + 置信度 | DA 上下文里财报只以「**还有 N 天发财报**」的风险形式出现 (`app/playbook/pipeline.py:2886-2889`), **不含刚发布的超预期幅度** |

⇒ 盘前/盘后的**隐式规则** = 「beat + 当日涨 +0.5%~+2%」才做多; 其余(跌的 / 涨过头的 / 不及预期的)**一律跳过**,
既不做多也不做空 ⇒ 一半供给(且实证更厚的那一半)被放弃。

## 3. 实证: 「财报好坏定方向」被否掉

`scripts/earnings_direction_check.py`（118 条超预期财报事件, 2026-08-28..09-22）:

| 检验 | 读数 |
| --- | --- |
| 超预期幅度 vs 报告日涨跌 | **Pearson r = −0.006**（零相关）|
| 超预期票当日上涨占比 | **47%**（低于抛硬币 50%, 中位 −0.33%）|
| 分档上涨占比 (beat 0-5% / 5-20% / ≥20%) | 50% / **38%** / 52%（**不单调**）|
| ≥20% 档次日跳空 | 中位 +1.14% 但 P10 −3.67% / P90 +23.35% ⇒ 离散过大, 不作判据 |
| miss(不及预期) 票的路径 | **数据集里根本没有**（通道只喂 beat）|

⇒ **不得**采用「beat⇒做多 / miss⇒做空」这类教科书规则 (§8 列为禁项)。

## 4. 判据 (预注册): 幅度定方向

| 形态 | 动作 | 实证依据 |
| --- | --- | --- |
| 跳空 **≥ +3.0%** | **SHORT** | +$75.80/笔, 胜 65% (n=26, `scripts/rth_fade_replay.py`) |
| **+0.5% ≤ 跳空 ≤ +2.0%** | **LONG** | +$23.09/笔 (n=19, 延长时段回放) |
| 其它 | **不做**（只记录） | 无证据 |
| 保护臂结论 (同批票同日) | 该族**不要止盈**; 若挂保险止损要**宽**(−3.5%); **不要日内熔断** | `scripts/rth_fade_protection_arms.py` |

一句话: **财报决定「有没有事件可交易」, 幅度决定「做哪一边」**。

- **用户确认 (2026-09-23, 平台侧)**: 富途 App 与接口**可以**在盘前/盘后执行做空 (我方此前把它当"未证实项")。

- **落地形态 = 复用同一条链, 不新开链路**（用户 2026-09-23 追问「为什么还要单独写?」⇒ 答案是本就不该单独写）:
  代码已落 (`scripts/extended_hours_entry_executor.py`, 2026-09-23 `07dd9559e`), 方向耦合只 4 处参数化:
  ① 下单口 `trd_side` ② 落库 `direction` (open_positions + trade_records) ③ 带判据 ④ SL 方向;
  其余全部**共用**: 价/市值/换手/价差/深度/费用/漂移闸 · 档位 · 仓位算法 · 日内帽/在仓帽 · 在途单门 ·
  券商对账 · 成交等待与撤单 · 孤儿单 · 09:25 收口 · 离场窗 · **退出链**（`_dir_sign` 早已支持 SHORT）。
  进下单口前**券源逐票预检**（`max_sell_short≥1` + `is_short_permit`, 与探针同一方法）⇒ 券源不足
  `skip=short_borrow_unavailable`, **绝不裸卖**。
  开关: `EXT_ENTRY_ALLOW_SHORT` 默认 **false**（实测 OFF ⇒ 空侧不可达、`place_order` 恒 BUY、生产行为 byte 级不变）。
- **另一条现成的空侧出口**: **RTH 空头通道**（已存在且在成交: 35 笔净 +$229 / 胜 77%, 8/25 起）——
  空侧**不依赖** ETH 成交能力, 探针失败也不阻塞这条路。
- **碰撞审查 (已过)**: 禁追线对 SHORT 的语义是价格**下限**、违例=**低卖** ⇒ 高价做空不碰撞
  (`app/playbook/entry_routing.py:chase_cap_violated`); `premarket_invalidation` 与 `short_chase_ban_shadow` 均为 record-only。

## 6. 攒样与转正门槛

- 攒样器: `scripts/earnings_direction_path_shadow.py`（**全量**财报事件 beat+miss, 零下单,
  逐条记 超预期幅度 / 前收 / RTH 开高低收 / 跳空 / **计划方向** / 虚拟净额; 幂等落盘）

- **转正门槛 (需另立 RFC 裁决)**: 每方向 **≥30 笔** 且 每方向 **净/笔 > 0**; 单方向样本不足 ⇒ 该方向不上
- 可见性: 影子看板段13 ④「财报全量路径(beat+miss)」逐日呈报

## 7. 停采 / 回滚

- 停采: 连续 10 个交易日无新增事件（喂数方故障）; 或两方向均 净/笔 ≤ 0 ⇒ 停采并归档台账
- 回滚: 删 cron 行 + 删脚本（台账 jsonl 保留供分析）

## 8. 明确禁项（防止以后有人再提一遍）

1. **禁**「beat ⇒ 做多 / miss ⇒ 做空」教科书规则（§3 已否）
2. **禁**用超预期**幅度大小**排序选股（r≈0）
3. **禁**在延长时段对亏损侧做止损（2026-09-17 用户令; 止损职责在盘中）
4. **禁**该族止盈（保护臂实测提前锁盈把大赢家砍掉）

### 9.2 探针修订（预注册判据的变更，全部在此留痕）
1. **修订 #1（首跑即口径）**：挂价 = ask ⇒ 只证「能下单」，不证「能成交」。**已否**。
2. **修订 #2**：新增 `--fill-check` ⇒ 挂 **bid 侧 marketable 价**；其余判据（SIM-only / 窗内 / 1 股 / `remark=eth_probe` / 价格帽 / 成交即买回）不变。
3. **修订 #3**：fill-check 模式改**按价差最窄选标**且要求价差 ≤1%（无合格 ⇒ `no_liquid_candidate`，不下一张注定不成交的单）；**日额度 2 → 3**（#1 挂 ask 不成交、#2 标的无流动性、#3 才拿到成交证据 ⇒ 三次是取得该证据的最小次数）；三次全部为 1 股 SIM 单且零残留。

### 9.3 空侧闭环（离线端到端钉，scratch 临时库、零生产写入）
生产函数 `_write_open_position(side="SHORT")` ⇒ `open_positions` / `trade_records` 双表 `direction=SHORT`、`initial_sl=210.0`（entry 200 ⇒ **止损在上方**）、metadata 带 `direction/stop_loss`；退出链 `_load_open_positions()` 读回 `direction=SHORT`、`_dir_sign("SHORT")==-1`；平仓方向 `LONG→SELL / 否则→BUY`（`app/execution/exit_lifecycle.py`）⇒ **8/8 通**。

## 10. 空侧开关的回滚判据（写死，2026-09-23 用户批「需要」）

**开着的条件（已满足）**：§9.1 成交实证成立 —— 券商受理（`8200483`）+ **真成交**（`8200516` FILLED_ALL，dealt=1.0）+ 建空仓（`qty=-1 / position_side=SHORT`）+ 平回零残留。探针复跑若反向（挂 bid 侧且价差 ≤1% 仍 `dealt=0`）⇒ 立即回滚。

**回滚触发（任一命中，不辩论）**：
1. **券源/合规类异常**：出现 `short_borrow_unavailable` 之外的券商拒单、或任何**裸卖**迹象（无 `max_sell_short≥1` 却下单）。
2. **止损失效**：空侧成交仓出现**无 SL 或 SL 在下方**（应为 entry×(1−STOP_PCT/100)，在上方）—— 属方向耦合回归，先关开关再修。
3. **尾部超限**：单日空侧净额 ≤ −$400（与 RTH fade 预注册同口径）**且**连续 3 个这样的一天。
4. **观测停摆**：`研究臂拒绝细分` / `闸计数` / dry 臂 `direction` 字段连续 2 个交易日缺失（可见性契约破坏 = 不能判断在发生什么，等于盲跑）。

**回滚动作（一个词，零代码）**：`.env.us` 的 `EXT_ENTRY_ALLOW_SHORT=false` ⇒ 下一轮 tick 生效（本链 cron 每轮新进程，**无需重启**）；同时把 `scripts/probe_eth_short_open.py` 维持可用（探针不受该开关影响）以便复核。
