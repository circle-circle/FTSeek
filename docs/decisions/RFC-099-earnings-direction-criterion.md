# RFC-099 财报日方向判据: 幅度定方向, 财报好坏不定方向

- **状态**: **生效中** (判据已定 + 影子攒样中; **不写任何执行代码**)
- **日期**: 2026-09-23 (用户提问「对于财报日 如何选择做多还是做空?」→ 「盘前和盘后 富途app和接口可以执行做空, 按建议执行」)
- **相关**: RFC-097 (判据②换口径 + 涨幅带) · RFC-098 (RTH fade 影子) · `scripts/earnings_direction_check.py` (判据实证) · `scripts/earnings_direction_path_shadow.py` (攒样器)

## 1. 问题

财报日到底该做多还是做空? 现役系统实际怎么定?

## 2. 现役实读 (2026-09-23)

| 通道 | 方向怎么来 | 原文 |
| --- | --- | --- |
| 盘前 / 盘后 (财报票通道) | **没有方向分支** | 唯一下单口 `place_order(..., trd_side=TrdSide.BUY)`（`extended_hours_entry_executor.py:2595`）; 全文 **0 处** `SELL_SHORT/TrdSide.SELL` |
| 盘中 (RTH) | DA(LLM) 逐单产出 BUY/SHORT/SKIP + 置信度 | DA 上下文里财报只以「**还有 N 天发财报**」的风险形式出现 (`app/playbook/pipeline.py:2886-2889`), **不含刚发布的超预期幅度** |

⇒ 盘前/盘后的**隐式规则** = 「beat + 当日涨 +0.5%~+2%」才做多; 其余(跌的 / 涨过头的 / 不及预期的)**一律跳过**,
既不做多也不做空 ⇒ 一半供给(且实证更厚的那一半)被放弃。

## 3. 实证: 「财报好坏定方向」被否掉

`scripts/earnings_direction_check.py`（118 条超预期财报事件, 2026-08-28..09-22）:

| 检验 | 读数 |
| --- | --- |
| 超预期幅度 vs 报告日涨跌 | **Pearson r = −0.006**（零相关）|
| 超预期票当日上涨占比 | **47%**（低于抛硬币 50%, 中位 −0.33%）|
| 分档上涨占比 (beat 0-5% / 5-20% / ≥20%) | 50% / **38%** / 52%（**不单调**）|
| ≥20% 档次日跳空 | 中位 +1.14% 但 P10 −3.67% / P90 +23.35% ⇒ 离散过大, 不作判据 |
| miss(不及预期) 票的路径 | **数据集里根本没有**（通道只喂 beat）|

⇒ **不得**采用「beat⇒做多 / miss⇒做空」这类教科书规则 (§8 列为禁项)。

## 4. 判据 (预注册): 幅度定方向

| 形态 | 动作 | 实证依据 |
| --- | --- | --- |
| 跳空 **≥ +3.0%** | **SHORT** | +$75.80/笔, 胜 65% (n=26, `scripts/rth_fade_replay.py`) |
| **+0.5% ≤ 跳空 ≤ +2.0%** | **LONG** | +$23.09/笔 (n=19, 延长时段回放) |
| 其它 | **不做**（只记录） | 无证据 |
| 保护臂结论 (同批票同日) | 该族**不要止盈**; 若挂保险止损要**宽**(−3.5%); **不要日内熔断** | `scripts/rth_fade_protection_arms.py` |

一句话: **财报决定「有没有事件可交易」, 幅度决定「做哪一边」**。
