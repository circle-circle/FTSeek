## 一、假设（唯一，防七路并发）

**H-KR3-1**: 入场前方向已兑现（同向已动 ≥1%）的指令，其净期望显著低于其余人群——
即"追已动行情"入场是 MFE=0/SL_INITIAL 亏损族的可事前识别子集。

- 动机: KR2 窗口亏损高度集中（SL_INITIAL 8 笔 −$1069 = 总亏损 134%，全部 MFE≈0）；
  9/1 V 型日 3 笔误杀（AMD/LLY/SAIC）均为开盘下探被扫。若入场时刻可观测的
  "方向已动幅度"能预先分离该族，则入场侧存在可裁决的 edge（或干净证伪）。
- 与候选池的对应: "方向×涨幅证伪门扩展"（以入场前涨幅为证伪维度的门禁）。

## 二、特征与冻结阈值（预注册时刻写死）

```
entry_runup_pct = 前日收盘 → 入场价 的方向同向已动幅度
  LONG : (entry_price / prev_close − 1) × 100     正 = 入场前已上涨
  SHORT: (prev_close / entry_price − 1) × 100     正 = 入场前已下跌
would_block = entry_runup_pct ≥ +1.0%
```

- **阈值 1.0% 冻结理由**: 高波动桶（3–5% ATR，人群主体）日内噪声的 1/3–1/4 量级；
  低于此幅度不构成"方向已兑现"的声称。期间禁改（含"看起来更好的" 0.8/1.5 等）。
- `prev_close` = 入场日前一交易日日 K 收盘（采集器口径，`MarketDataRouter.get_daily_bars`）。

## 三、判据（冻结，期末裁决用）

对预注册时刻 → 2026-09-30 全部 PLAYBOOK_SIM 已执行入场：

1. **主判据**: would-block 子集 vs 其余人群，单均净期望差异，**按日聚类**双样本
   t > 2（pooled 值不得单独采信，宪章第 9 律；任何 t 必须标注聚类口径）。
2. **MDE 覆盖**: 记分输出必带 MDE 列；声称效应 < MDE → 判"不可测"，不判确认。
3. **样本外**: 窗口最后 2 周 vs 之前窗口，方向一致性（防窗内过拟合）。
4. **次级端点**: would-block 子集 MFE=0 率是否显著更高（参考，不作主判据）。
5. **样本量诚实**: would-block 子集 n < 30 → 不裁决，延长观察（同 OKR n≥30 标尺）。

- **确认** → 10 月 OKR 立案实施为入场门（新 DEB + 用户裁决，影子转正流程）。
- **证伪** → 如实记录，**不立即换下一个假设**（防链式 fishing，OKR KR3 明令）。

## 四、诚实先验（预注册时点的已知事实）

- KR2 窗口 8 笔 SL_INITIAL 的入场锚点偏离 |anchor_dev| 大多 ≤1.3%（仅 AFRM −4.82%）——
  现有数据**没有**明显的"追涨"签名。本预注册先验偏弱，期望产出更可能是干净证伪。
  证伪同样是 KR3 达标（产出是证据，不是盈利）。
- 代理人口事实（DEB-20260831 §8.8）: 95% 流走代理 ATR，规则 0.5 实际语义 ≈ 0.5×SL 距离；
  本假设检验的是入场侧过滤，与退出侧正交，不受该口径影响。
