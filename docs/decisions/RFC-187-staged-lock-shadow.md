|---|---|---|---|---|---|
| <0.4% | 203 | 26.0% | 1.0% | −1.347% | 大亏（入场即错族） |
| **0.4–0.8%** | **288** | **36.9%** | **85.8%（247笔）** | **+0.074%** | **−0.045%** |
| 0.8–1.5% | 169 | 21.7% | 28.4% | +0.405% | +0.286% |

统一锁在保本线、以 +0.074% 出场 —— **这一桶结构性为负**，而它的峰值本来有 40~80bps 可用。

| 想法 | 实测 | 结论 |

## 3. 设计：S0 / S1 / S2（比例保护，不平仓）

```
S0  peak < dd_min_peak(0.3)        → SL = 初始 SL（不动）
S1  0.3 ≤ peak < arm_hi(0.8)       → SL = entry ± (peak − dd(0.4))      # 按自身峰值给保护
S2  peak ≥ 0.8                     → SL = entry ± max(lock(0.4), peak − dd)  # 锁利地板
```
**不变式（代码断言）**
1. SL 只朝有利方向移动，且**永不差于初始 SL**（ratchet 地板）；
2. `peak − dd ≤ 0` 时**不武装**（锁到保本线等于按现价平仓 = 反效果）；
3. 到 `arm_hi` **不平仓**，只把止损抬到 `lock` —— 让右尾继续被 adaptive trailing 收割；
4. 本设计**不碰**入场、TP、初始 SL，爆炸半径仅限 BE 桶。

**为什么是"比例"而不是"时间回退"**：时间回退（0.8 → 到点降 0.4）在价格已跌破 0.4 后毫无作用，
且引入"何时降"的新自由度；比例保护不需要新时点参数——保护幅度天然随该笔自己的峰值走。

**数据地基（撤保护的下行有限）**

| 桶 | MAE p50 | p75 | p90 | MAE≥2% | MAE≥4% |
|---|---|---|---|---|---|
| [0.4,0.8) | 0.36% | 0.91% | **1.56%** | **8%** | 2% |
| [0,0.4) 对照 | 1.62% | 2.73% | 4.57% | 39% | 14% |

前向影子（`data/early_dead_signal_shadow.jsonl`，624 条 / 610 settled）：该桶在 15min 时
**92% 仍在 0 以上、67% 仍在 +0.4 以上**；30min 时 86% / 68%。⇒ 这桶不是"必跌回去的人"，
是被 0.4 线提前剪掉的人。

## 8. 预期与不确定性

- 中间桶 288 笔现状毛 +$1,252（净 −0.045%/笔）；新设计下出场约"峰值 − 0.4%"、均值 ~+0.20%
  ⇒ Δ 估算 **+$1.6k~4k / 4 个月**（**估算非承诺**；上界来自影子终值 +0.366% 代理）。
- 主要风险：锁利线滞后导致回吐更多（dd 0.4 兜住）；8% 的 MAE≥2% 笔会被更早保护（改善而非恶化）。
- **可执行 ≠ 有正期望**：本设计只把该桶从"费用线下"抬到"费用线上"，不解决 26% 的入场即错族
  （均 −1.347%，那里的杠杆是入场质量，不是退出线）。
