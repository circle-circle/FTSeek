## 3. 设计：S0 / S1 / S2（比例保护，不平仓）

```
S0  peak < dd_min_peak(0.3)        → SL = 初始 SL（不动）
S1  0.3 ≤ peak < arm_hi(0.8)       → SL = entry ± (peak − dd(0.4))      # 按自身峰值给保护
S2  peak ≥ 0.8                     → SL = entry ± max(lock(0.4), peak − dd)  # 锁利地板
```
**不变式（代码断言）**
1. SL 只朝有利方向移动，且**永不差于初始 SL**（ratchet 地板）；
2. `peak − dd ≤ 0` 时**不武装**（锁到保本线等于按现价平仓 = 反效果）；
3. 到 `arm_hi` **不平仓**，只把止损抬到 `lock` —— 让右尾继续被 adaptive trailing 收割；
4. 本设计**不碰**入场、TP、初始 SL，爆炸半径仅限 BE 桶。

**为什么是"比例"而不是"时间回退"**：时间回退（0.8 → 到点降 0.4）在价格已跌破 0.4 后毫无作用，
且引入"何时降"的新自由度；比例保护不需要新时点参数——保护幅度天然随该笔自己的峰值走。

**数据地基（撤保护的下行有限）**

| 桶 | MAE p50 | p75 | p90 | MAE≥2% | MAE≥4% |
|---|---|---|---|---|---|
| [0.4,0.8) | 0.36% | 0.91% | **1.56%** | **8%** | 2% |
| [0,0.4) 对照 | 1.62% | 2.73% | 4.57% | 39% | 14% |

前向影子（`data/early_dead_signal_shadow.jsonl`，624 条 / 610 settled）：该桶在 15min 时
**92% 仍在 0 以上、67% 仍在 +0.4 以上**；30min 时 86% / 68%。⇒ 这桶不是"必跌回去的人"，
是被 0.4 线提前剪掉的人。

## 10. 用户追问「0.4→0.8 能不能直接用昨日+历史成交记录算收益」——能做与做不了

**做不了**：规则级 P&L 需要"出场之后价格怎么走 + 新规则在该路径上何时触发"，成交记录里没有路径。
第四次尝试（`scripts/be_arm_08_bracket_replay.py`，1m bar 受限重放）依旧过不了保真：
- 同一引擎 arm0.4 基线 vs 实盘：死单桶（MFE<0.4）模型 **+30.4bps** 偏差、赢家桶（MFE≥0.8）**−36.8bps** 偏差——**符号相反**，
  说明偏差是状态相关的，不能靠"同引擎基线相减"抵消。
- 原因同前三次：实盘 BE 不是"碰线即出"（含费感知垫、patience、adaptive trailing），1m bar 上的碰线远多于真实触发。

**能做**：不依赖任何规则模型、只读行情的**出场后漂移**（descriptive，不是 P&L 估计）——

MFE∈[0.4,0.8) 已平仓 n=271（有出场后 bar 269 笔），方向调整后相对出场价的漂移：

| 窗口 | 均值 | 中位 | 为正占比 |
|---|---|---|---|
| +15min | **−1.6bps** | −3.6 | 46% |
| +30min | **−4.2bps** | −6.8 | 46% |
| +60min | **−5.3bps** | +2.0 | 51% |
| +120min | **−8.7bps** | −4.8 | 48% |
| →当日收盘 | **−1.2bps** | −2.1 | 49% |

⇒ 被 0.4 剪掉之后，价格**平均继续朝不利方向走**，中位≈0，正负各半。**不是"剪掉了赢家"的形状。**
再叠加"完全不武装"的尾部：该桶在 1m 重放里有 **2.6%** 会一路走到初始 SL（约 −580bps/笔）⇒ 期望再拖 −15bps。

**昨日（2026-11-06）单日**：13 笔出场后 +30min 均 **+14.8bps**、→收盘 **+70.4bps**（NET 单笔 +796bps 主导）。
这是**趋势日的离群值**，与 271 笔的 −1~−9bps 方向相反——正是"用一天当样本"的典型陷阱。

**结论（并撤回我上一轮的估计）**：上一轮据 `early_dead_signal_shadow` 终值代理给出的「+$1.6k~4k/4个月」
**与本次两个独立口径都不一致，撤回**。按现有证据，0.4→0.8 在该桶上预期 **≈ −5 ~ −20bps/笔**（负），
唯一能翻正的证据只有"出场后漂移为正"，而它在全样本上不成立。

⇒ 处置：**不改武装线**；RFC-188 影子继续跑，但角色从"证成"变成"证伪"——
预注册判据不变，只是现在需要它拿出与"出场后负漂移 + SL 尾部"相反的证据才可能转正。

## 11. 预期与不确定性

- ⚠️ **本节原估算（+$1.6k~4k / 4 个月）已撤回**，见 §10：它来自 `early_dead_signal_shadow` 终值代理，
  与"出场后漂移（−1~−9bps）"和"SL 尾部（−15bps）"两个独立口径都不一致。
- 现在的诚实预期：**Δ ≈ −5 ~ −20bps/笔（负）**；中间桶现状毛 +$1,252/4 个月（净 −0.045%/笔）。
- 主要风险：锁利线滞后导致回吐更多（dd 0.4 兜住）；8% 的 MAE≥2% 笔会被更早保护（改善而非恶化）。
- **可执行 ≠ 有正期望**：本设计只把该桶从"费用线下"抬到"费用线上"，不解决 26% 的入场即错族
  （均 −1.347%，那里的杠杆是入场质量，不是退出线）。
