# RFC-068: B门硬门转正 — 接飞刀拒入场 (2026-08-29)

**状态**: 已实施 (用户批准 "按建议执行")
**类型**: L1 行为变更 (<50 行)

## 背景

盘前失效影子规则 B (`premarket_invalidation.py`, record-only, 2026-08-09):
BUY 且盘前跌 ≤ -5% = 接飞刀区。影子攒样 20 天，8/28 审计中转正裁决。

用户明示裁决, 非统计显著性。保留影子版 record-only 继续采集对照。

## 机制

- 挂载点: `run_playbook_auto_execute` — 触发判定之后、`execute_instruction` 之前
- 语义: BUY/LONG 指令执行时刻 **实时价 / 昨收 < -5%** → 拒入场; 价格回升出飞刀区,
  下轮 (30分钟) 自然复评 — 非永久作废
- 判定复用 `premarket_invalidation.evaluate_rules` (SSOT, 阈值唯一定义源)
- 数据缺失 (价/昨收≤0、取数异常) → 放行 (质量门非安全门, 下游仍有 SL 兜底)
- 拦截记入 `exec_gate_audit.jsonl` (action=skipped_knife_gate)
- 昨收口径: `get_full_market_context.prev_close` — 盘中时段为已定盘的昨收,
  不受盘前快照陈旧问题影响 (盘前陈旧案见 de13b8d0/61a94fb)

## 配置

`config/unified_config.yaml`: `playbook.premarket_invalidation_hard_gate: true`
回滚: 置 `false` + `systemctl restart ftseek-us`

## 明确不做

- 不改影子版 (observe 继续采集, 供未来阈值校准)
- 不拦 SHORT、不拦盘前跌 -5%~-2% (回调日是赢家模式)
- 不做 re-price 封顶 (执行前实弹复演证伪, 见下)

## 附: re-price 封顶证伪记录 (建议②不落地)

## 勘误 (2026-08-29 独立复查, 实测非推断)

### 勘误1: 昨收口径声称错误 — 硬门曾结构性不触发 (P1, 已修)

本文"昨收口径"节声称 `get_full_market_context.prev_close` 盘中可用。**实测该键
从未被注入** (`market_data_router.py` 函数体内零处赋值, 静态扫描+行为模拟双证):
`pipeline.py` B门读 `_ctx_kg.get("prev_close")` 恒 0 → `px>0 and pc>0` 第一步
短路 → **自 08:58 提交至审计修复前, 硬门一次都不会拦** (配置键/挂载点/阈值/
影子对照全部正确, 唯数据键缺失)。08:59 重启加载的正是此死门。

根因族: "读了一个没有生产者的键" — 与 RFC-054 SymbolContext 丢字段、
exit_policy regime 未传同族; 守卫测试只做源码文本断言 (3 例均无法发现)。

修复: `market_data_router.get_full_market_context` 注入 `prev_close` — 日K自算
真昨收 (承 de13b8d0 教训, 不用快照 prev_close_price), 复用主路径已拉日K零新增
API, 日K缺失回落 quote.prev_close, 异常缺键按本门"数据缺失放行"语义。
守卫: `tests/test_router_prev_close_injection.py` 4 例 (含行为级变异反证)。

### 勘误2: 证据表两处口径错误

1. **RBRK 8/28 盘前 -5.6% 不成立**: 影子记录 (09:36:06 ET 实测) prev_close=107.02
   (日K验证=真昨收, 非陈旧) → 盘前价 103.385 = **-3.40%, hits=[]**。RBRK 当日
   根本不在盘前飞刀区; 其亏损 (入场 101.235 → 26min SL -158.79) 属执行时刻
   口径 (101.235/107.02 = -5.41%), 恰是本门执行时刻判定会拦的形态。
2. **反事实集合**: 执行时刻口径 (成交价/真昨收) 独立重算全窗口 139 笔:
   拦 **4** 笔 = BABA -6.20% / LRCX -5.58% / RBRK -5.41% / SNDK -5.48%
   (SNDK 不在原表, 影子报 -4.54% 系陈旧昨收 1786.85 假象), 避损 $305.48,
   误杀 LRCX +$2.51, 净 **+$302.97**; 原表"拦3 省$283 净+$280"为盘前快照口径,
   两口径差在 UCTT (执行时刻已回升 -2.85% 放行) 与 SNDK (快照陈旧)。

转正决策本身不受影响 (方向性全亏 + 用户裁决), 但本文数字一律以本节为准。
