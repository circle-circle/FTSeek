## 1. 重议触发 (预注册条件命中记录)

RFC-157 §6 预注册: 「每 20 个交易日统计 OVERNIGHT_GAP_STOP 笔数与笔均; **≥3 笔且笔均
≤ −$250** ⇒ 回头动」。2026-10-22 全链路复查实测 (滚动窗 10-08→10-21, 未满 20 交易日
但条件已提前命中): OGS 族 **4 笔** (QCOM −343.15 / SNDK −293.03 / AMD −357.49 /
CAT −302.52), 笔均 **−$324.05 ≤ −$250** ✓。近 11 日窗 OGS 净 −$1,296.19 = 该窗
总净亏 (−$437.98) 的 2.96×; 剔除后窗口翻正 +$858.21。

## 2. 判别器 (来自 2026-10-17 OGS 族尸检 §3, 非新造)

RFC-079 影子 52 行 (50 可结算) join 交易 MFE:

| 桶 | 当日 MFE | 结局 |
|---|---|---|
| 灾难 (4 笔 OGS, 影子深度≥2.5% 行) | 0.000 / 0.216 / 0.291 / 0.474 | **全 <0.5%** |
| 恢复者 (5 笔) | 0.472 / 0.603 / 0.607 / 0.813 / 1.321 | 4/5 ≥0.6% |

机制: **「当日从未盈利 0.5%」= 论点从未被市场证实**, 不配占用隔夜跳空敞口。
与 early_tight_sl (30min MFE<0.3%) 同哲学在不同时点的延续。入场侧过滤已被 §4
否决 (恢复者与灾难的生成侧画像不可分) — 判别器只在入场后可观测, 正确答案在退出侧。

⚠️ **刀尖注记 (必须随判据冻结)**: US.M (恢复, MFE 0.4715) vs QCOM (灾难, 0.4744)
只差 0.003pp; 0.5% 恰好落在两者之间是运气。判别力真实 (恢复者集中 ≥0.6%) 但
**精确切点不可信** — 前瞻攒样的意义即消化切点风险, 窗内禁改阈值 (改=重裁)。

## 3. 影子设计 (与 B19 同载体同尺)

- **载体**: 复用 RFC-079/RFC-095 打点+结算链 (`emit_eod_depth_gate_shadow` arm 行 +
  `settle_eod_depth_gate_shadow.py`, cron `30 6 * * 2-6`)。arm 行自本日起新增
  `mfe_pct_at_arm` (决策时刻当日 MFE, 方向感知: LONG=peak−entry / SHORT=entry−peak,
  与 meta.peak_price 同语义; 缺失落 null 不进分母, 不猜)。
- **触发谓词 (MFE 轨)**: arm 时刻 `mfe_pct_at_arm < 0.5%` ∧ `depth_net_pct < 0` (水下)。
  与 B19 深度轨 (≤−2.5%) **并列独立读数**, 互不影响; 报告 `mfe_track` 节承载。
- **结算**: Δ = 反事实「EOD 按 decision_price 平」 − 实际结局 (费两边抵消=纯价差);
  身份锚定 (RFC-095: trade_ref > entry_time > 价量锚), 未持夜排除, 同仓多夜按
  trade_id 取最早夜去重 — 全部复用, 不重造。

## 4. 预注册判据 (B19 形态沿用, 读数前写死)

MFE 轨触发组去重结算 **n≥8 ∧ ΣΔ>0 ∧ 误杀赢家 (Δ<−$5 费地板) ≤1** →
提请转硬闸 (**另立 DEB + 用户裁, 影子不自动生效**); 不过线 → 维持豁免机制原状。
窗内禁改: MFE 阈值 0.5% / 水下定义 (depth_net_pct<0) / EOD 豁免链行为。

## 5. 反证据与边界 (并陈, 裁决时必读)

- `EOD_FORCE_CLOSE` 笔均 **+$51.81** vs 持夜组 −$41.01 (RFC-157 §6): **不是所有
  过夜都坏**, 一刀切平仓被明示排除; 本轨只测「MFE∧水下」窄人群。
- B19 深度轨 2026-10-14 已终裁 GATE_NOT_WORTH (「−2.5% 深度区分度不足」,
  miskill=5 永久冻结) — 该终裁**只关闭深度轨转硬闸路径**, 不约束本轨
  (判别器不同: 深度=价格幅度, MFE=论点证实度)。
- 10-17 尸检回放读数 (MFE<0.5%∧depth≤−1.5%: 8/8 灾难全捕, ≈+$1,436/5周,
  误杀 2-3) 属**历史回放**, 只作方向证据, 不进判据样本 (判据 n 轴自本日前瞻起算)。
- C1 约束说明: 本项是持仓管理 (过夜豁免的窄撤条件), 不是新入场假设,
  不占 OKR-2026-10 C1 名额; 任何转硬闸动作仍需独立 DEB + 用户签字。

## 7. 2026-10-22 复核更正（不改判据或执行行为）

- §2「0.5% 恰好落在两者之间」撤回：`0.4715% < 0.4744% < 0.5%`，恢复者 US.M 与灾难样本 QCOM 均进入触发组；该示例不能证明阈值可分，小样本的判别力尚待前瞻验证。
- §5 引用的约 +$1,436 对应 `depth≤−1.5%`，并非本 RFC 的 `depth<0`。原尸检 §3 对任何水下人群报告 13 行、+$2,199、误杀 10；行数与前瞻去重仓数、误杀口径仍须对齐，不据此裁前瞻成败，也不得把窄人群节省额归给本轨。
- 决策输入必须来自 arm 时刻已知数据，不能用最终整笔持仓 MFE 回填；持仓累计峰值与单日峰值的区别必须显式披露。
- 本次仅修正证据解释：0.5% / `depth_net_pct<0` / n≥8 / 误杀≤1 均不变，不启用硬闸、不重算历史裁决；阈值变更仍须重新预注册及用户批准。
