# RFC-155 左尾风险尺寸分层影子（P2，只读）

**状态**: 2026-10-20 用户确认继续 P2；**仅只读反事实 + 前瞻影子预注册，不改生产尺寸**
**类型**: 风险尺寸（risk sizing），不是入场假设；不改 exit hash / 入场信号
**关联**: `docs/analysis/2026-10-20-left-tail-autopsy.md`、RFC-154、RFC-153

## 1. 依据

30 日 155 笔（净 −$786.97）左尾尸检：

- 开盘 0–15min：94 笔，净 −$1,175.69，左尾 13/16。
- ATR 5–8%：75 笔，净 −$1,711.08，左尾 11/16。
- UE 源：12 笔，净 −$773.91。
- 止损不是根因（SL_INITIAL MFE 中位≈0）；宽限价路由被 P0 反事实否决
  （PULLBACK_LIMIT delta −$640，跳过 69 个赢家）。

因此 P2 只做**尺寸分层**：对左尾集中的人群降低风险预算，不硬拦、不改变单笔 bps、
不改变入场信号。目标是降低左尾美元冲击和回撤，**不宣称 alpha 改善**。

## 2. 预注册规则（只读反事实；生产候选一次只开一条）

| 规则 | 尺寸乘数 | 30 日反事实净差 |
|---|---|---:|
| **R1 ATR≥5%**（主） | 0.5× | +$855.54 |
| R2 开盘 0–15min | 0.5× | +$587.84 |
| R3 UE 源 | 0.5× | +$386.96 |
| R4 ≥2 个旗标（ATR/开盘/UE） | 0.5× | +$827.16 |
| R5 any 旗标 | 0.5× | +$624.62 |
| R6 每旗标 0.5×，下限 0.25× | 0.25–1.0× | +$1,038.21 |

主候选 = **R1**（最简单、单变量、影响 75/155 笔）；R4 作为更窄的备选。
所有规则只用**入场前可得**字段：ATR（entry 时刻）、入场分钟、decision_id 源。
不引入新数据管道。

## 3. 测量与裁决

### 3.1 历史反事实（本批）
脚本 `scripts/risk_size_tier_shadow.py`；产物 `data/shadow/risk_size_tier_latest.json`。
- 对实际已平交易按乘数缩放 notional/净额（费用近似线性；固定佣金非线性已披露）。
- 必报：总净额、日级最大回撤、左尾净额、避免亏损 vs 放弃赢家、受影响笔数、
  胜率（尺寸不改变符号）、R:R（组合权重会变）。
- 全窗 + 前后半窗拆分（防单段过拟合）。

### 3.2 前瞻影子（转生产前）
- 在实盘路径只记录 `would_multiplier` 与 `counterfactual_size`，**不改实际 size**；
  至少 10 个 ET 交易日且 ≥30 笔受影响交易。
- 主判据：缩放后净额/回撤不劣于实际，且左尾净额下降；若放弃赢家的成本 > 避免亏损，
  则不采纳。
- 转生产须另立 RFC + 用户批准；生产实现为 `compute_position_size` 的风险乘数，
  一行配置回滚（乘数 1.0），不改 exit hash/入场信号。

## 4. 边界

- 不改变单笔 bps/胜率/R:R 的“alpha”口径；尺寸分层只改变美元暴露与回撤。
- 不得用尺寸分层替代入场质量修复，也不得借机加仓/提频。
- 不碰 `playbook_horizon.yaml` / exit hash；不改 BE/trail/TP/SL。
- C1：这是风险尺寸，不是新入场假设；仍须 RFC + 用户批准，且一次一变量。
