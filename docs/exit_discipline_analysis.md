## 三、待审查要点

1. **假设1**: 持到收盘 50.8% 命中 — 这个数字怎么算的? 是否包含所有 exit_reason 的交易，还是仅限某个子集?
2. **假设3**: "exit 把 50.8%→41%" — 41% 是什么口径? 是实际已平仓交易的整体胜率吗? 9.8个百分点是 exit discipline 的净效果还是其他因素混入?
3. **EOD_FORCE_CLOSE 数据**: 14笔平均+$127.5 — 是否有 selection bias (即能持到尾盘的本身就是好仓位)? 这是否说明退出策略在主动止损/breakeven 上过早退出反而砍掉了利润?
4. **样本量**: n=71 但 EOD_FORCE_CLOSE 仅14笔(n=14)，统计效力极低。方向性结论是否过度推断?
5. **核心矛盾**: 如果 EOD_FORCE_CLOSE 是最赚钱的退出方式，那当前 breakeven_at_pct=0.5%/1.0% 和 drawdown=0.5% 的退出参数是否过于激进，过早止损?

## 四、决策含义

如果上述分析成立:
- 当前退出参数(breakeven 1.0%, drawdown 0.5%)可能在砍利润
- 需要对比: EOD_FORCE_CLOSE vs 其他主动退出的盈亏分布
- 可能的调整方向: 放宽 breakeven/drawdown 阈值，让更多仓位持到尾盘
- 但: 这与"收紧退出纪律"的直觉相反，需要更多数据验证
