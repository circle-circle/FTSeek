## 1. 系统定位与不可违背的五条原则

**一句话定位**：耐心埋伏 + 关键时刻爆发型系统。平时靠退出纪律不亏死、把子弹省下来，
等明确风口来了能抓住。不追求每天赢，不追求完美预测。

**当前运行态**：富途**模拟盘**（`AUTO_TRADE_ACCOUNT=sim` / `execute_mode=futu_simulate`），
权益约 **$98,754**，峰值 $98,980，当前回撤 −0.23%，历史最大回撤 −3.33%，资金水位 GREEN。
**实盘四锁全闭**，未毕业前严格不切实盘（用户明令）。

**五条贯穿原则**（自 2026-07-22 确立，至今未改）：

1. **LLM 的定位 = 信息收集员 + 情报评估员，不是方向预言家。** 不对 LLM 方向预测抱期望，
   方向由退出纪律与人工重大判断兜底。
2. **退出是核心赚钱引擎。** 承认入场约等于随机，靠"截断亏损 + 让利润奔跑"赚钱。
3. **需要盘中时机/纪律的决策全部交给代码，不留人工插手口子。**
   理由：操盘者自认"心理偏 A（舍不得砍）、无盘中纪律"，机器的意义是替"理智的自己"执行 B。
4. **自动交易全程不停机，边跑边修。** 绝不为"重构完美"停机。
5. **新规则先 shadow 后实盘。** 任何新入场/退出规则先 record-only 攒证据，
   统计判分优于基线才实盘化。

> ⚠️ **原则 2 目前与实证冲突**：§9 显示毛利期望≈0，退出端既没杀赢家也没救亏损，
> 调退出参数在数学上不可能改变毛期望（最优停止定理）。这是本系统当前最大的认知张力，
> 也是 §13 问题 1 的由来。

## 2. 架构：双脑 + 唯一下单管线

```
决策脑 (DA, 盘前 ET 07:00 / CST 19:00 cron)
  全市场扫描 → 筛选 Top-N + 自选池 → 18~19 维数据采集 → LLM 深度分析（qwen，开思考模式
  thinking_budget=2048）→ 双模型辩论（分析师 vs 挑战者 deepseek，挑战者禁 SKIP 必表态）
  → signal_gate 质量闸（PASS/WARN/BLOCK，BLOCK 率约 48%）
  → 写入指令库 playbook_instructions

执行脑 (FTSeek, 盘中每 300s 轮询 run_playbook_auto_execute)
  失效门组 → 触发确认 → 实时重定价 reprice → 资金三护栏 → 下单（约 25 道内联风控门）
  → 记账

退出脑 (每 10s 独立快环 monitor_playbook_sim_exits)
  保本棘轮 / trailing / 8 条退出规则（见 §7）→ 全生命周期入库

复盘脑 (盘后 ET / CST 04:00 cron)
  日/周/月复盘 + IC 追踪 + 影子矩阵判分 → 参数校准提案（需用户裁决）
```

**关键架构事实**：

- **Playbook 是唯一下单与持仓管理管线。** 旧主信号管线（signal_pipeline → order_executor）
  已被**双锁冻结**（扫描侧硬编码 `_skip_execution_in_trading=True` + 执行侧 source_type 白名单），
  只跑信号研究/IC 采集与 housekeeping（日周月复盘、持仓快照、看门狗心跳）。
- ORB 引擎已停用（`orb.enabled=false`）；topup 补仓已冻结。
- 三态共存（shadow / futu_simulate / live），靠 env var + 约定维持，**无显式状态机**（已知债务）。
- 退出**不走**主线 ExitMonitor，由 Playbook 独立快环自管；主线对 Playbook 仓显式排除。

## 3. 信号生成层：LLM 如何给出方向与计划

### 3.1 DA 分析师 prompt 的硬约束（节选，逐字来自生产 prompt）

- **每条论点必须引用具体数据（数字 + 日期）**，不接受无数据观点；论点必须是该股独有、不可移植。
- **多空对等**：看多看空各至少 2 条，标强度（HIGH/MEDIUM/LOW）与来源类型；
  方向由证据权重决定，不预设偏向（数据支持看空就坚定给 SELL_SHORT）。
- **因果链至少 3 层**（宏观→板块→个股 或 事件→估值→价格）。
- **结构性约束（违反即废单）**：
  1. 止损距离 **2–5%**（>6% 被准入层硬拦；<2% 落入噪声扫损区）；
  2. **不接飞刀**：当日累计跌幅（含盘前/盘后，以"有效涨跌幅"为准）>5% 且无企稳证据的 LONG 一律不推荐；
     盘前暴跌（−10% 以上）视为隔夜信息重定价，不是回调机会；
  3. **回踩优先于追涨**：贴近支撑/VWAP 的回调企稳优先，新高延伸追涨降级；
  4. **盘前异动必须显式表态**：判断是"趋势延续"（顺势入场）还是"过度反应"（逆势需强证据）；
     所有价位必须锚定**有效现价**（盘前时段=盘前成交价），严禁锚定昨收。
- **校准原则（把历史表现直接告诉模型）**：prompt 内明写"你的方向判断历史命中率约 50%（≈掷硬币）"，
  因此缺乏独立硬证据时不得给 `score_band=HIGH`。
- **信息 edge 统一判定**：判断依据不是新闻年龄，而是**该信息是否已被价格反映**；
  判据材料 = 盘前异动（涨跌幅/量比/成交额）。已被反映 → 只能作背景陈述，全部论据均属此类 → 给低分并 SKIP。
- **同标的连续推荐纪律**：过去 3 天已推荐且价格未确认方向 → 必须给出"为什么这次不同"的新证据，
  否则禁止同方向再推。
- **数据充分性路由**：19 维数据覆盖由**代码算好注入**（缺失<6 维=充分），
  模型只读标记不自行计数；现价缺失（=$0）→ direction 只能 SKIP，禁止输出任何价位。

### 3.2 指令输出契约（机器可执行语义）

`direction`（BUY/SELL_SHORT/SKIP）、`score_band`（HIGH/MEDIUM/LOW → 映射数字分，
禁止用 LOW 表达看空）、`entry` / `stop_loss` / `take_profit`、`confidence`、
`entry_archetype`（BREAKOUT / PULLBACK_LIMIT / FADE_SHORT）、`confirmation`（确认位）、
`chase_cap_price`（**禁追线**：不得在此价以上追涨/以下追空）、
`invalidation` + `invalidation_triggers`（≥2 条**本股、代码可判定**的失效条件：
metric 限 {收盘价, 成交量, 5日涨跌, 盘前涨跌幅}，operator 限 </>，value 纯数字）、
`tripwires`（叙事性观测）、`conditions`（合法枚举因子，决定退出参数分桶）。

### 3.3 双模型辩论

分析师（qwen）出结论 → 挑战者（deepseek）尝试证伪，**禁 SKIP 必表态**。
一致 → 信心提升；一方质疑 → 降信心保留方向；分歧极大 → SKIP。
`confidence` 实际取值高度离散（历史上仅 {35,50,70,72,88,90} 六档）。

> ⚠️ 已知问题：挑战者 AGREE 率疑似饱和（判据 B11 在观察窗 9/1–9/12：
> 若 AGREE≥95% 且切片 PnL 无区分度 → 判定"仪式化"）。

### 3.4 signal_gate 质量闸

基于 `strategy_memory` 的历史赚/亏 pattern + claim 级 IC + regime 做质量评分，
输出 PASS / WARN / BLOCK（BLOCK 率约 48%）。**不做方向门禁**（不因"LONG 弱"就一律 BLOCK BUY）。

> 关键实证（2026-07）：**LLM 选方向无 edge，但 gate 的负向筛选有真实 edge** —
> 被 gate BLOCK 的 37 只当日方向胜率仅 27%、均值 −1.14%（反事实实测）。
> 准确表述是"LLM 选方向不行，gate 排烂单行"。

### 3.5 admission 准入层（指令落库时判分）

拒绝判据：`FEE_INEFFICIENT`（往返费用/预期收益比过低）、`NOTIONAL_TOO_SMALL`、
`SL_STOP_TOO_WIDE`（止损 >6%）、`PRICE_TOO_LOW`（<$5，拦 OTC 仙股）、
`SHARES_ABOVE_FEE_KNEE`（股数越过佣金拐点）、`LOW_CONFIDENCE`、辩论弱结论。
REJECT → 方向改 SKIP 并留 `skip_reason`。

### 3.6 UE 通道特有闸门

同标的同方向冷却 3 天；浮现续期硬闸 `max_emergence_streak=2`（streak≥3 不注入）；
价格地板 $5；evidence_ref 引证真实性核验（record-only）；
开盘+10min 确认门（两段式：21:10 CST 生成假设 → 09:40 ET 用真实盘中价裁决信息是否已被 price-in，
阈值 2%，当前为**影子**不拦既有注入链）。

## 5. 仓位与风险

### 5.1 sizing 公式（SSOT 单一实现）

```
risk_amount     = risk_base × (risk_pct/100) × regime_mult × water_mult
position_size   = risk_amount / |entry_price − stop_loss|
再依次截断：单名市值上限（max_position_pct 8%）→ 市场状态乘数（VIX × regime）→ max(1, size)
```

| 参数 | 值 | 备注 |
|---|---|---|
| `risk_base_capital` | $82,000（净值可取时改用实时净值） | 当前实际权益 $98,754 |
| `risk_pct` | 0.5% | 单笔风险预算 |
| `max_position_pct` / `max_per_symbol` | 8% / 8% | 由 15%/25% 收紧而来（映射实盘人工教训：单名 86% 集中、扛单 −$65.9k） |
| `max_per_sector` / `max_per_direction` | 40% / 65% | |
| `position.max_total` / `daily_notional_cap_pct` | 80% / 80% | 单日名义敞口双兜底 |
| 日开仓上限 | 16 笔（单轮 ≤3 笔） | 由 5→8→12→16 逐步放开，理由是 sim 期数据量优先 |
| `confidence_sizing_enabled` | **false** | 已停用：confidence 是反向指标（见 §9.5） |

### 5.2 市场状态乘数

- **VIX 仓位乘数**：low(<20) ×1.0 / medium(<25) ×0.8 / high(<30) ×0.5 / extreme ×0.0
- **VIX 止损加宽**：0 / +0.3pp / +0.8pp / +1.5pp
- **VIX 止盈折扣**：**全部 ×1.0**（原 0.9/0.7/0.5 已关，理由：全局市场因子打折违背 per-symbol 分桶原则，且 8 月 0 次触发=休眠）
- **regime 仓位乘数**：RISK_ON/CAUTIOUS/RISK_OFF 均 ×1.0，NO_TRADE ×0.0

### 5.3 regime 判定（MarketRegimeGate）

## 7. 退出引擎（`_check_playbook_exit_rules`，每 10s 一轮，端到端延迟约 15s）

### 7.1 优先级序列

```
[0]   开盘冷却：前 15min SL 放宽到 4%（防开盘噪声秒杀）
[0.5] 早期紧 SL：入场 30min 内 MFE 未达 0.3% → SL 收紧到 min(1.0%, 0.5×ATR%)，上限 2.5%
[1]   effective_sl 触及 → 三态归因：
        SL_INITIAL    （浮盈从未达保本线 → 初始固定止损被打掉）
        SL_BREAKEVEN  （净保本棘轮已激活，SL 提到成本 + 手续费缓冲附近）
        SL_TRAIL_LOCK （回撤锁利，SL 已锁在净保本线之上）
[1.5] TAKE_PROFIT：触及止盈价（仅当 RR ≥ 1.5 才生效，`_MIN_TP_RR` 为硬编码常量）
[2]   OVERNIGHT_GAP_STOP：隔夜仓次日开盘跳空 >3% 快平
[3]   PRE_CLOSE_EXIT：收盘前 8min（15:52 ET）
[3.4] MFE_STALL_EXIT：持仓 ≥150min 且峰值浮盈 <0.5% 且当前水下 → **当前 disabled**
[3.5] DEAD_SIGNAL_EXIT：持仓 ≥60min 且 MFE <0.2%（reentry 仓宽限 +60min；隔夜仓按"今日开盘以来"每日重置）
[4]   TIME_EXIT：持仓 > factor_time_exit_hours 且盈利 <0（默认 6h；隔夜仓每日重置）
[5]   MAX_HOLD_T5：持仓 ≥5 交易日（EOD 兜底执行）
```

### 7.2 保本棘轮与 trailing（当前生产值）

| 参数 | 值 | 演化理由 |
|---|---|---|
| `breakeven_at_pct` | **0.4%** | 1.5→1.0→0.5→0.4。0.4 = 与费用线对齐，做到"真净保本"。回放 n=265 悲观序 +88/乐观序 +161 双序为正 |
| `drawdown_from_peak_pct` | **0.8%** | 0.5→0.4→0.8。0.4 在日内噪声底触发、系统性截断赢家（TRAIL_LOCK 15 笔均赢仅 $27.59，MFE 1.48% 只捕获一半）；0.8 给赢家呼吸空间 |
| `breakeven_fee_cushion_pct` | 0.4% | 保本线含手续费垫，避免"纯净保本"被误标 TRAIL_LOCK |
| `breakeven_slip_cushion_pct` | 0.2% | 触发线 = 费用线 + 滑点垫 → 触发时限价单翻主动侧立即成交（依据：8s 超时降级市价的 3 笔全净负，滑点 6.6~43bps > 费用垫 7.5bps） |
| `breakeven_limit_timeout_s` | 3s | |
| `breakeven_passive_marketable_pad_bps` | 15bps | 保本线**已被击穿**的被动侧改挂 marketable limit，砍掉"3s 死等→撤单→市价"约 12s 往返（家族 5 案 0 次回摆成交、全负） |

### 7.3 按因子分桶的退出规则（`factor_exit_rules`，共 34 个因子）
