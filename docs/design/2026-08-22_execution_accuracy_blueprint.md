# 执行准确性蓝图: 从信号产出到精准执行的全链设计

**日期**: 2026-08-22 (周六)
**性质**: 设计提案 (未实施 — 全部排队 8/29 终裁后分期落地; Phase 0 只读件可先行)
**作者**: Claude Code (用户命题: "提升执行的准确性, 不要背离明显的信号, 顺势而为, 从指令策略产出到合理精准的执行")
**证据基线**: DEB-20260822 (体检+T+5反事实) / ADR-031 (反馈链路) / ADR-032 (证伪门接线修复) / ic_tracker 实测

---

## 〇、一句话诊断

本系统不缺方向感, 缺的是**让方向感活到结算日的执行链**。实测: LLM 方向在 T+5 有真信号 (IC +0.265), 但执行层在 T+1 时间尺度上入场、用 5 分钟斜率翻转方向、用"放弃性出场"在中途砍掉 62 笔后来会赢的单 — **信号层说的和执行层做的, 是两个周期、两个方向的事**。提升执行准确性的本质 = 消除层间周期错配与方向背离。

## 二、"明显的信号"的机械定义 (顺势而为的可操作化)

"顺势"不能靠感觉, 必须可计算。定义三级趋势态 (每日收盘后批量计算, 只读缓存):

```
周级势 (thesis 势):  close vs MA20 且 MA20 斜率; 52 周高点距离分位
日级势 (structure):  MA5 vs MA20 相对位置 + 近 10 日 higher-low/higher-low 结构
盘中势 (timing):     5m slope + VWAP 相对位置 (现有 slope_5m)
```

**顺势规则 (方向裁决优先级从高到低)**:
1. 周级势决定**允许的方向集** {LONG, SHORT, BOTH, NEUTRAL} — NEUTRAL = 只减不加
2. 日级势决定**入场时机合法性** — 顺周级势回踩日级支撑 = 合法; 逆日级势追 = 非法
3. 盘中势只决定**入场触发与微调**, 永远无权翻转周级方向

**"不背离"的硬规则**: 三级势同向 = 满仓信号资格; 两级同向 = 标准仓; 仅周级孤立看多/看空 (逆日级) = 半仓 + 必须给反转触发条件; 三级互斥 = 不交易 (这不是机会, 是噪音)。

## 三、全链五层设计

### L0 信号产出层 (LLM 辩论引擎 → playbook_instructions)

| 机制 | 设计 | 依据 |
|---|---|---|
| 方向+周期绑定 | 指令必须带 `thesis_horizon` 字段 (默认 120h), 出场语义从生成时刻就绑定周期 | A1/A6 |
| 趋势态强制注入 | 三级趋势态作为必填 context 注入 debate prompt; LLM 逆势必须给反转触发条件, 否则降 watch_only | "不背离明显信号" |
| 置信度降级为排名 | conf 不再驱动仓位/特权, 只用于同日候选排序; 仓位改 ATR 风险平价 (见 L2) | A4 |
| 提名预算 | 每日新指令上限 N (建议 8-10, 现 ~17); 超出只替换不追加 | A5 (费用∝笔数), 同日齐射相关性 |
| 熊市触发条件必填 | 每指令必须带"什么情况说明我错了" (bear-case trigger), 供 L3 的 DEAD_SIGNAL 语义使用 | A3 (DEAD_SIGNAL 是好出场, 因为它证伪了 thesis) |

### L1 指令校验层 (证伪门族 — 已修复的 8 门 + 新增 3 门)

现有 8 活门保留 (capital_flow / short_squeeze / insider / analyst修订动量 / earnings / finnhub情绪极端 / sec_event / 逐笔情绪)。新增三门, 全部证伪语义:

1. **趋势一致性门**: DA 方向 vs 周级+日级趋势态。LONG 逆既定下降趋势且无反转触发 → 拒; SHORT 逆强上升趋势 → 拒。这是"不要背离明显的信号"的机械化, 也是本蓝图第一优先。
2. **费用边际门**: 预期波动 (ATR% × 周期系数) ≥ 3 × 往返费率 (11.7bps × 3 ≈ 35bps) 才放行 — 预期波动连费用都盖不住的票不进。A5: 毛期望 -3.6bps 意味着大量交易在开仓前就注定亏损。
3. **同日相关门**: 同板块同日新开仓 ≤2; 与现有持仓同标的/高相关 (β>0.8) 的加仓需增量证据。体检已证同日齐射的连亏 22 笔非独立事件。

### L2 入场执行层

| 机制 | 设计 | 依据 |
|---|---|---|
| 方向与时机解耦 | 周级 thesis 定方向, 盘中回踩定价格。**废除 slope_5m 翻转周级方向的权力**: 斜率与 thesis 反向 → 不翻向, 站到一边 (no trade) | A1: 5 分钟斜率是噪音尺度, 无权裁决周级判断; 现行 direction_adaptive 让噪音覆盖论点 |
| 限价纪律 | 只用限价+超时撤单, 禁市价追单; spread 门保留 | 滑点调整后期望 -$18.48/笔, 滑点是费用之外第二大出血 |
| ATR 风险平价仓位 | 每笔风险 = 账户固定小比例 (如 0.5%) ÷ (入场价-SL距离) = 仓位; 与 conf 脱钩 | A4: conf 无信息量; 波动率才是仓位该对齐的量 |
| 入场后立即挂保护 | 初始 SL 开仓即挂 (现行为保留) | A3 |

### L3 持仓管理层 (实测最大出血点, 第二优先)

核心语义转换: **出场只有两种合法理由 — 保护 (protective) 或 证伪 (thesis-invalidated)。'放弃' (abandonment) 不是出场理由。**

| 出场 | 现行为 | 实测 | 设计 |
|---|---|---|---|
| 初始 SL / BE / trailing | 保留 | A3 全部验证 | **原样保留, 一字不动** |
| TIME_EXIT | 到时即砍 (日级) | Δ+$47.77/笔, 16/0 翻转 | LONG: 到时改挂**收紧的 trailing** 而非平仓, 让赢家跑到 thesis_horizon (T+5); SHORT: 保留日级纪律 (A6) |
| MFE_STALL_EXIT | 动量停滞即砍 | Δ+$51.93/笔, 16/0 翻转 | 停滞 + 趋势态未破坏 → 收紧 trail 持有; 停滞 + 趋势态破坏 → 才出场 (把"停滞"从出场信号降级为止盈保护触发器) |
| DEAD_SIGNAL_EXIT | thesis 证伪即出 | Δ-$167.91 (好出场) | 保留, 并升级为 LONG 延长持有的**唯一**主动出场伙伴: thesis 熊市触发条件命中即出 |
| W_WEEK | 日历到期 | 与周期错配 | 到期日 = 开仓日 + thesis_horizon, 与 L0 绑定 |

预期量级: 两放弃桶合计 ~$3,100/窗口, 即使只收回一半也足以把系统从净亏推到净盈 — 这是全蓝图杠杆最大的一层。

### L4 反馈闭环层 (ADR-031 已修通, 补三件)

1. **出场决策反事实评分**: t5_hold_counterfactual (已上线 cron) 的分桶 Δ 每周注入 debate prompt — 让引擎看见"你的放弃性出场上周又砍掉了多少会赢的单" (个体级+桶级双通道, A8)。
2. **证伪门质量遥测**: 每门记录 触发/放行 + 被拒候选的 T+5 反事实结果 — 用数据杀掉"拦错了好交易"的门 (门也是假设, 也要被证伪)。Phase 0 只读件。
3. **月度校准表刷新**: conf→期望映射每月重算注入, 替代模型对自身置信度的想象 (A4)。

## 四、分期落地 (尊重冻结纪律与 8/29 终裁)

| 期 | 窗口 | 内容 | 性质 |
|---|---|---|---|
| **P0 尺子先行** | 现在 → 8/29 | 只读三件: ①趋势态记录器 (每日批量落盘三级趋势态, 为 P1 攒 A/B 样本) ②证伪门遥测 (被拒候选 T+5 反事实) ③校准表月更脚本 | 修尺子+攒样本, 白名单内 |
| **P1 信号侧** | 终裁后第 1-2 周 | 趋势一致性门 + 费用边际门 + 同日相关门 + 提名预算 + thesis_horizon 字段 | 生成器/校验器侧, 零执行器改动; shadow ≥2 周 (被拒候选反事实为判据) |
| **P2 执行侧** | P1 shadow 期满后 | L3 出场语义改造 (LONG TIME_EXIT/MFE_STALL → 收紧 trail; SHORT 不动) + slope_5m 翻向权废除 | 执行器语义变更, **先影子臂 A/B** (t5_hold_counterfactual 为现成判官), 单飞原则 |
| **P3 仓位侧** | P2 稳定后 | ATR 风险平价替代 conf 仓位 | 影子对照后切换 |

每期预注册判据 + 变更日历 (只周六动配置) + 落档当日清零 (9 月流程硬化三条, 待批中)。

## 五、不做什么 (anti-scope)

1. **不做预测器堆叠** — 不加"预测明天涨跌"的模型; 只做证伪与周期对齐 (A7)。
2. **不动保护性出场** — SL/BE/trailing 实测无罪, 碰它就是破坏系统里少数被验证有效的部分 (A3)。
3. **不追求交易频率** — 相反, 提名预算是做减法; 费用结构下"少而大"优于"多而小" (A5)。
4. **SHORT 不延长持有** — 无论 LONG 侧怎么改 (A6)。
5. **不绕过毕业门禁** — Playbook 唯一毕业通道不变; 本蓝图全部机制先 sim 攒样, 达标才谈 live。
