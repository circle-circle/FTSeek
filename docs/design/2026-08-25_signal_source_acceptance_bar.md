# 十月信号源验收标准 (预注册, 2026-08-25)

> 归属: DEB-20260825-outcome-feedback-loop-revival 第5/6轮终判的执行项。
> 第5轮终判: 当前信号源毛收益率 2.1bps/名义 < 费用地板, 内部无翻正杠杆 → 翻正唯一路径 = 换信号源。
> 本文档在十月候选评估**开始之前**锁定验收口径, 防止评估期氛围驱动、事后挪门柱
> (8/22 教训: 识别层"自报提升"系统性虚高; 8/14 纪律: 判据先行)。

## 一、唯一验收口径

**费用模型后毛 bps / 名义 · 暴露日** (fee-adjusted gross yield per notional-day):

```
yield(source) = Σ(方向性毛利 bps) / Σ(名义 × 暴露天数)
过线条件:      yield ≥ breakeven_bps(geometry) + margin
```

- **不用命中率/胜率作主口径** (DEB-20260823: LLM 方向命中 ≈50%, 胜率非分水岭);
- **不用单笔均盈** (与名义/暴露时长无归一, 不可跨源比较);
- 毛利按 `fee_model.py` 金标准逐腿扣费前口径, 但**必须同时报费用后净额曲线**。

## 二、盈亏线的止损几何耦合 (第5轮未算的部分)

第5轮"$41k 名义才翻正"按**当前**止损距离计算。但名义 = 风险额 ÷ 止损距离%,
止损几何是设计变量。实测基线 (8/7 起 n=181): 名义中位 **$5,662**, 风险额中位 **$252**,
止损距离中位 **4.72%**。固定风险额 $252 下:

| 止损距离 | 名义 | 双边地板费占比 ($3.98) | 翻正所需毛收益 (地板+从价~0.5bps+50%边际) |
|---|---|---|---|
| 4.72% (现状) | ~$5.3k | ~7.5bps | ~12 bps |
| 3% | ~$8.4k | ~4.7bps | ~7.8 bps |
| 2% | ~$12.6k | ~3.2bps | ~5.5 bps |
| 1% | ~$25.2k | ~1.6bps | ~3.1 bps |
| 0.5% | ~$50.4k | ~0.8bps | ~1.9 bps (超单仓日帽约束, 仅作曲线端点) |

→ **评估新源时必须联动测**: 该源的可承受止损紧度 (紧止损下的存活率/鞭笞损耗) 决定它自己的过线门槛。
一个"毛 4bps 且容忍 1% 止损"的源好于一个"毛 6bps 但需 4.7% 宽止损"的源。
当前源的实测毛收益率 2.1bps 连现状档的 12bps 都远不够 — 这就是第5轮终判的几何解释。

## 三、预注册裁决流程

1. **样本**: 候选①盘前特征走全史回测 (4/28 起, 双窗口对半); 候选②资金流等攒样源走
   n≥30/组 + 双窗方向一致且差≥15pp (既有攒样器纪律); 任何新源不得跳过双窗。
2. **过线定义**: 双窗均满足 `yield ≥ breakeven_bps + 30% margin`, 且被该源拦下/放行的
   反事实净差 > 费用量级 (与死胎回放同款费用门槛另算条款)。
3. **裁决产出**: 只允许三种结论 — GO (进 DEB+影子+门禁流程, 不直接落地) / NO-GO (出池) /
   EXTEND (延长攒样, 须写明缺什么)。
4. **防虚高条款**: 声称的提升必须用与 8/22 adj 三闸同款的费用后口径复算;
   任何"影子毛改善但费用后为负"的结果自动降级 NO-GO。
5. **时间盒**: 十月最后一个交易日前未过线的候选全部出池, 不携带进十一月 (防僵尸候选占用注意力)。
