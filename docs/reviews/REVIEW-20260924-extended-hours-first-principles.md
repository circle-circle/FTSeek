# REVIEW-20260924 延长时段交易链路第一性原理复查

**结论**：当前“事件候选 → 执行闸 → durable exit”的总体分层是对的；更好的实现方式不是加策略参数，而是把入场侧从“每轮盲扫异动榜”改成 RFC-104 的**事件计划-状态机**。但计划只能负责“谁可能进入闸”，不能预先决定“能不能下单”。本轮已顺手修复一个空侧执行错边风险；其余建议保持影子/待裁，不直接改交易行为。

## 1. 第一性原理

延长时段和常规时段的本质差异不是“涨跌幅更大”，而是：

1. **事件先于价格发现**：财报日/相位可提前枚举，价格、量、actual 与盘口在事件后逐步可用；
2. **流动性是状态变量**：同一标的 04:00、07:30、16:20、19:50 的可执行价差和深度不同，不能把 RTH 阈值原样搬过来；
3. **成本是硬门槛**：价格毛利必须覆盖价差、冲击、往返费用、空头隔夜成本和错过窗口的机会成本；
4. **状态必须跨进程存活**：entry state、exit ledger、券商孤儿单和本地账本是同一条真相链，崩溃/重启不能造成双下单或漏平仓；
5. **错过优于错做**：计划缺失、数据缺失、相位冲突、盘口失效时应 fail-closed。

因此链路职责应拆成四层：事件枚举 → 数据就绪 → 执行闸 → 订单生命周期。策略阈值属于执行闸，事件计划不携带方向、收益预期或放行结论。

## 2. 已落地修复

### P0：空侧入场用错可执行盘口

原 `_pretrade_gate` 对所有方向都用 `ask` 与 `ask_volume`，并在费用模型中按 `LONG` 估算。空侧开启后，这会造成：

- `SELL` 限价挂在 ask，实际应打 bid，容易变成被动单/不成交；
- 深度检查看错边（应看 bid volume，不看 ask volume）；
- 不利漂移方向看错（SHORT 应防 bid 向下漂移，LONG 应防 ask 向上漂移）。

修复后：LONG 用 ask/ask depth，SHORT 用 bid/bid depth；数量按可执行价重算；往返费按实际 direction 计算；多侧行为保持不变。新增契约测试覆盖方向、深度、漂移和价格。

## 3. 对 RFC-104 的复核意见

RFC-104 的“盲扫-发现 → 计划-消费”方向正确，符合第一性原理：财报事件可提前枚举，异动榜只是价格发现后的补漏观测。建议采纳，但做三处收紧：

1. **不要在计划生成时预筛价格/量/市值**。这些是执行时状态；T−1 快照不代表 T 日跳空后的价格。计划应保留完整事件人群，执行闸负责判定。`gate_snapshot` 只做审计，不决定进入计划与否。
2. **源冲突不投票、不择优**。futu/Finnhub 对日期或相位冲突时，状态应为 `ambiguous`（或生成双 session 待命），消费侧必须 fail-closed，直到源刷新或人工裁决；不能 silently 选一个来源。
3. **计划是事件清单，不是策略卡**。不含方向、SL/TP、预期收益、费用或“看起来可成交”的数字；每票状态只推进 `planned → armed → waiting_data → ordered/rejected/expired`。

这样能把 4,300 票次/日的无效扫描降到约事件数×轮次，同时不把“发现效率”伪装成“交易胜率”。

## 4. 策略与退出链路判断

### 盘前

盘前仓 09:25 收口、亏损侧不强止损、利润保护可执行，是现有回放支持的行为，但要承认其证据是局部 cohort，不是普适定律。它的第一性逻辑是：盘前噪声回归概率高、薄盘止损容易付出价差成本；但事件失效、深亏破位或流动性异常时仍应交给条件化/盘中规则，而不是无条件持有。

### 盘后

盘后仓“无利润信号则持到次日 09:30–09:45”逻辑成立，因为盘后事件趋势的 MFE 常在隔夜开盘延续；但这是隔夜跳空暴露，不是无风险套利。应保留总在仓/名义敞口帽，并继续把“事件失效、深亏、盘口不可执行”作为单独状态记录。

### 退出执行

当前链路采用限价单、durable exit ledger、券商回报后本地落账、孤儿单监测，方向正确。退出侧不建议简单复制入场盘口硬闸：退出是风险降低动作，盘口差时应优先记录并可重试，而不是为了通过闸而持有风险。但建议先做只读观测：退出前 quote age、spread、depth、净可执行收益，攒样后再决定是否条件化。

## 5. 后续建议

1. 落地 RFC-104 阶段 0（只读计划），不预筛、不放行、不含策略参数；
2. 为入场 `_liquidity_quote` 增加 `update_time/quote_age_seconds` 只读字段，先积累分布，再评估 30–60 秒 fail-closed 阈值；
3. 保留 $5、市值、换手、费用和盘口闸。近期零成交来自“事件人群与闸不匹配”，不是链路故障；不应为出样本而放宽 9/17 已验证的防低价高费门槛；
4. SHORT 继续只做事件 + 幅度人群，且把借券费/隔夜成本纳入后续净额口径；本修复先保证方向和盘口正确。
