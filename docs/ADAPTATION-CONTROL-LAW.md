## 0. 控制论定位: 这是慢环的适应律

台账 §1 把系统分为快/中/慢三环。本律是**慢环 (适应层) 的转移函数**:

```
误差信号(中环测量) ──→ [本律: 触发→证据→增益→验证→回滚] ──→ 参数变更(作动)
                              ↑
                     人工门: 用户签字 (最高裁决权)
```

**为什么增益必须受限 (物理定律, 非官僚)** — 自适应系统的稳定条件要求适应速率
(增益) 远小于对象动态与测量噪声的尺度。本系统的三个硬约束:

| 约束 | 实值 | 后果 |
|------|------|------|
| 反馈延迟 | 裁决在日/周级落定 | 适应律拿到的误差永远滞后一个对象时间常数以上 |
| 单次裁决样本 | 几十笔交易 (~46 笔/周) | 误差估计的方差大 |
| 测量噪声 | 同日信号强相关 (~67 信号/日, 宪章第 9 律) | 有效样本 = 天数, 非信号数; pooled t 被夸大约 √(信号/日) 倍 |

延迟大 × 样本小 × 噪声强 → **适应增益必须极小**, 否则适应律退化为噪声放大器
(实证: 每周改一个退出参数循环 7 周 7 版本, 每窗仅 46 笔, 输出与掷硬币不可区分,
DEB-20260823 §三; 已废止)。本律五段就是这个"极小增益"的具体实现。

**本律不发明新机制** — 五段的每一段都由已在运转的执行器承担, 本文档的价值是
把它们编排成一条完整链条并给出处 (此前散在宪章/OKR/DEB 三处, 无单一真源)。

## 1. 触发段 (何时允许考虑改参)

**控制论含义**: 适应律的使能信号。误差信号存在 ≠ 允许作动, 必须先过使能门。

| 规则 | 出处 |
|------|------|
| 三类动作白名单: 修尺子 / 攒样本 / 做减法。**新机制默认排队**, 任何人 (含用户) 坚持插队须在对应 DEB 记"知情破例 + 归因影响评估" | 宪章 §四.1 |
| 触发来源只能是**机械判定输出**: 证伪门周检 verdict / 影子毕业门 verdict / 冻结核查异常, 不接受"感觉某参数不对" | 台账 §2.4 + 本律 §4 |
| 反例 (已证伪, 永久废止): "每周五改一个退出参数"迭代循环 | OKR-2026-08 §每周迭代循环, DEB-20260823 |

**使能门当前状态**: 2026-08-24 → 09-30 参数冻结期 (OKR-2026-09 KR2), 退出段
使能门**关闭**; 例外通道仅 P0 bug + DEB 落档 + 用户知会。

## 2. 证据段 (改之前必须有什么)

**控制论含义**: 误差信号必须可辨识 (高于噪声地板) 才能驱动适应, 否则是追噪声。

| 规则 | 出处 |
|------|------|
| n<30 不下结论; "单周完美分离"默认过拟合 | 宪章 §二.5 |
| 阈值预注册: **先写判据再看数据**; 临近裁决 (终裁前 2 周) 禁改阈值 | 宪章 §二.6 |
| 跨信号统计必报**按日聚类值 + MDE** (`MDE = 2.8 × sd_daymean × √(2/n_days)`); \|效应\|≤MDE 一律"不可分辨", 不予采信 | 宪章 §二.9 (第 9 律) |
| 基线纪律: 新规则必须在**当前已落地规则基线**上算残存效应, 禁止在"无任何规则"旧基线上模拟 | DEB-20260808 (post-blackout 教训) |
| 新旧基线切分: 退出参数变更前后数据不可混合下结论 | 宪章 §二.2 |

## 3. 增益上限段 (一次最多动多少)

**控制论含义**: 适应增益的显式上界。方向维度 = 1, 幅度 = 单参数, 速率 = 冻结窗口隔离。

| 规则 | 出处 |
|------|------|
| **一次一变量**: 同一交易日不叠加两个会改变信号分布或退出行为的变更 | 宪章 §四.2 |
| 一切 live 改动带**独立开关**, 一行配置回滚 | 宪章 §四.3 |
| prompt = 信号源改动, 必须 scan-eval 离线 A/B 先行 (v2.0 相变教训) | 宪章 §四.3 |
| 冻结期内退出参数零变更 (config_version 唯一值数 = 1) | OKR-2026-09 KR2 |
| 增益的物理上界由**费用线**给出: 任何改动声称的期望增量若 < ~10bps 费用线, 即使统计显著也无工程价值 (毛利救不回费用, 8/22 证伪) | DEB-20260823 §8.3 |

## 4. 验证段 (改之后怎么判)

**控制论含义**: 适应后的闭环辨识。每次参数变更 = 开一个新的可辨识窗口, 不混淆。

| 规则 | 出处 |
|------|------|
| 每个参数版本打 **config_version** 标 (playbook_horizon.yaml 整文件哈希), 统计只在同窗口内取样 | `app/playbook/config.py:get_exit_config_version` (8/24 R-4b 起整文件哈希, 漏键闭合) |
| 单版本样本窗口目标 ~250 笔 (9 月窗口), 是系统史上首个统计可用窗口 | OKR-2026-09 KR2 |
| 转正/采信需 OOS 双窗口: OOS≥15 日 + 净均>0 + 毛利 t>1 + ADF 平稳; 双窗口 ≥40% 才采信 | 记忆/转正门槛 |
| 判据预注册并冻结, 验证期内不得挪门柱 | 宪章 §二.6 |
| 冻结执行的**权威载体=日级守卫** `scripts/daily_invariant_check.py` `_check_config_freeze` 的 cohort 维 (info["cohort"]): 判分单位=主 cohort 窗 (2026-09-03→09-30) 内退出哈希唯一; 周六周检 `check_freeze()` 同口径锚点并列核查 | `scripts/daily_invariant_check.py` + `/root/.hermes/scripts/ftseek_weekly_checkpoint.py` (2026-09-06 KR2 判分单位修订, 用户授权代裁 (a)+(b) 合流) |

## 5. 回滚段 (出问题怎么退)

**控制论含义**: 适应律必须可逆, 否则一次错误适应 = 永久污染样本。

| 规则 | 出处 |
|------|------|
| 一行配置开关回滚 | 宪章 §四.3 |
| config_version 回退 (还原上一参数版本哈希) | 本律 §4 |
| `git revert` 对应提交 | 工程纪律 |
| 验证窗口冻结: 首夜/裁决日前 8 小时管线冻结, 零收益纯风险改动不占验证名额 | 宪章 §四.4 |

## 7. 与自调器的关系 (G5, 用户已裁不做)

自调器 (自动改参) = 把本律的**人工门 (§0 用户签字)** 替换为自动增益。在
延迟日/周级 + 样本几十笔 + 噪声强相关的约束下, 自动适应大概率是噪声放大器
(§0 物理定律)。现形态"自动观测 + 人工裁决 + 门控生效"即小样本控制的正确解,
本律是该形态的成文。G5 维持不做。
