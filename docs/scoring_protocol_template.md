# 判分协议模板 v1（DEB-20260819 §十九-P0-3 固化）

> 每个新判分设计**先过本模板**再开跑。三轮踩坑（带卡vs无卡选样混淆、
> pangan_refs 语义漂移、低功效误读）证明：判分协议不模板化，学费反复交。

## 1. 分组定义（必填）

| 项 | 要求 | 反例（踩过的坑） |
|---|---|---|
| 处理组 | 明确到"发生了什么行为"（如：DA 文本引用了卡规则） | "pangan_refs 非空"=注入标记被当引用标记 |
| 对照组 | 与处理组**同源受控**，只差被测行为本身 | 带卡票 vs 无卡票（选样混淆：带卡票本就因强规律被选中） |
| 最干净对照 | 同为带卡票的 cited vs 未引用 | — |
| 字段语义 | 字段名必须等于其内容语义，禁止一字段多义 | pangan_refs 名"引用"实"注入" |

## 2. 最小样本量（必填）

- 每组 ≥30 笔（二项近似正态的底线）
- **不足 → 只出观察报告，不做保留/回滚二元裁决，窗口顺延**
- 禁止把"未显著劣化"读成"安全"——低功效下无异于没检验

## 3. 单侧安全门（必填）

判分只回答一个问题：**新组件是否劣化？**
- 处理组显著劣于对照（p<0.05 且效应>费用线）→ 回滚
- 不劣 → 保留（但不宣称"有效"——有效需要正效应的独立证据）
- 有效性的正面证明需要另一套设计（正效应+置信区间），不混在本判分里

## 4. 混淆清单（逐项排查）

- [ ] **选样混淆**：处理/对照的入选机制是否相关于结果？
- [ ] **语义漂移**：分组字段的名字和实际内容一致吗？下游会误读吗？
- [ ] **时效混淆**：两组交易时段/regime 分布一致吗？
- [ ] **打标完整性**：结构化打标 + 文本兜底并集了吗？漏标方向是哪边？
- [ ] **执行污染**：执行异常样本是否打标并从主口径剔除（双口径判分）？
- [ ] **自引用**：判定逻辑扫描的文本里是否含判定依据本身？（假阳性源）

## 5. 预注册（开跑前写死，事后不改）

- 判分指标（净均差/胜率差/效应阈值）
- 最小样本量与窗口规则
- 回滚触发条件
- 数据口径（费用扣减、anomaly 剔除规则）

## 6. 当前生效判分实例（股性卡，8/29 首检）

- 处理组：文本引用(cited)的带卡票入场 | 对照组：注入未引用的带卡票入场
- 每组≥30 笔门槛，不足出观察报告延窗
- 引用组净均差 p<0.05 且劣化>费用线 → 关 symbol_card_prompt_enabled
- 口径：pnl_net（费用后），execution_anomaly 样本双口径
