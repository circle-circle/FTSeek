## 〇、一页摘要

**reentry 的病灶不在方向选择、不在证伪门覆盖不足，而在"盈亏结构三层剪刀差"——名义 RR 1.6:1（SL 1.5% / TP≈2.4%），实际执行出来是倒挂的 ≈0.5:1：**

1. **右尾被切**：SL_BREAKEVEN 在 MFE 仅 0.4-0.7% 时即锁平，盈利单实收均值只有 **+0.23%**（SL_BREAKEVEN 桶 7 笔净 +51.32，单笔实收 +0.1~0.2%）；MFE 峰值 0.43-1.51% 的空间被 breakeven 锁提前兑现。
2. **左尾全留**：DEAD_SIGNAL 桶 7 笔净 **−118.01（6 亏 1 赚**，唯一赚 UBER +1.65），共同特征是 **MFE≤0.2%（其中 3 笔=0**：CRM/TSM/CSCO；全样本第 4 笔 MFE=0 是 9/3 AVGO，在 SL_INITIAL 桶）——入场后从未浮盈，是"入场即错"而非"发酵不足"；而 `dead_signal_reentry_extension_min: 60` 恰恰给这类仓**加宽**死单宽限（9/2 ASTS 持有了 2.7h），方向与证据矛盾。
3. **费用吃薄利**：19 笔费合计 −80.85（均笔 $4.26 ≈ 名义 **0.076%** 往返，pooled 口径 0.0762%），毛利仅 +5.67——费用吃掉盈利单实收的约 1/3。

**全史总账：毛 +5.67 / 费 −80.85 / 净 −75.18（n=19，胜率 9/19）。**

**最有行动价值的分离变量不是 slope，而是 VWAP 偏离符号**（逐笔回查，§二-表3）：
LONG 侧 `vwap_dev>0`（VWAP 上方追入）9 笔净 **−96.95**；`dev≤0`（真回踩）4 笔净 **+24.24**。
dev>0 与 reentry 自身 thesis 模板（"回踩VWAP企稳"）自相矛盾——`vwap_band_high_pct: 1.0` 的不对称带把"追入"放进了"回踩"的壳里。

## 二、根因链

```
vwap_band 不对称 [−0.3%, +1.0%]  →  LONG "回踩" thesis 实际允许 +1% 追入
→ dev>0 追入桶 9 笔 −96.95（thesis 自相矛盾的入场）
→ MFE≈0 死单被 DEAD_SIGNAL 宽限（+60min）加倍占用敞口与日名额
→ 有 MFE 的活单被 SL_BREAKEVEN 在 0.4-0.7% 早锁，右尾切掉
→ 名义 RR 1.6:1 实收倒挂 ≈0.5:1，47% 胜率 × 倒挂 RR × 0.076% 费率 = 结构性必亏
```

**修法层次**：R1 dev 闸 = 治根因（入场侧，**拆键形态**——见下）；R3 breakeven 后移 = 治结构（需 C1 解冻裁决，只影子）；
R4 宽限 MFE 条件化 = 治资源占用（不省钱，省名额与敞口）；R2 slope/量比阈值 = 候选增强（攒样后议）。

**为什么根因修复必须拆键而非收窄共享键**（qwen-architect）：`vwap_band_high_pct` 被 SHORT 分支共享
（SHORT 带 = [−hi, +lo]），收窄 hi 会**倒置 SHORT 带语义**并杀掉现役最赚 SHORT（SNDK dev=−0.84，+38.07）。
故新增 LONG 专用键 `vwap_band_long_high_pct`，SHORT 路径零变。

## 四、R1 · LONG dev>0 追入闸 —— **已生效（2026-09-06 用户裁决直接 enforce）**

### 最终形态：拆键 CF-A（纯 dev≤0，**无例外臂**）

  LONG 分支上界改用此键，SHORT 分支仍共享 `vwap_band_high_pct` → SHORT 带语义零变。
  缺键回退 hi（手工 cfg dict 兼容）。回滚 = yaml 改回 `1.0` 或删键。
  代码：`evaluate_candidate` LONG 分支（`hi_long`）+ `_DEFAULTS` 键 + 契约测试 ×4（闸拒追高 / 回踩不误伤 / SHORT 零变 / 缺键回退恒等）。
- **为什么杀掉 slope≥0.30 例外臂**（三模型一致）：该阈值恰落在死单 UBER slope=0.295 与盈利 META slope=0.344 的
  **样本内间隔**——n=19 里的完美分割，是过拟合教科书形态，且原稿未披露此构造过程（kimi-reviewer 反幻觉发现）。
  例外臂从闸设计中**移除**；"强趋势追高是否被误杀"降级为 record-only 观察标记 `momentum_chase_candidate`
  （LONG 且 dev>0 且 slope≥0.30，阈值仅作切片不作闸；闸生效后此类行恒为 rejected，攒的是**无 P&L 的反事实分布**，局限已在代码注释声明）。
- **反事实（全史同窗回放，上界口径）**：实际 −75.18 → CF-A（纯 dev≤0）**+21.77（改善 +96.95）**。
  CF-B（含例外臂）+50.19 仅作"例外臂样本内来源"的证据保留，**不是候选方案**。
  回放局限声明：假设"被拦则当日无交易"，未建模 `max_arms_per_day=3` 名额被后续候选占用的替代效应 → **CF 收益是上界**。
- **毕业/复查判据（终态预注册，enforce 后时代）**：
  - 被拦日定义：该标的当日存在 `vwap_dev` 拒绝行（reasons 含 vwap_dev 且 dev>0）**且**当日无 armed 行。
  - 复查触发：被拦标的当日经**其他生成器**（DA/UE）入场且该笔净额显著为正（>+$10）累计 ≥3 例 → 起复核（闸可能误杀 regime 型机会）。
  - 撤闸认错：不以前向 P&L 单点裁决（被拦桶无 P&L 是本设计的固有局限），而以 30 个被拦日的
    `momentum_chase_candidate` 分布 + 同期大盘 regime 切片复核后由用户裁决。
- **诚实边界**：n=19 全史、LONG dev>0 桶 n=9；META 单笔占放行桶利润 54%（outlier 依赖，与 DA HIGH 桶同型）；
  未做日聚类 bootstrap。闸设计为可秒级回滚（单配置键）。

### R2 · slope / vol_ratio 阈值（**不预设数字**，攒样后议）

- `min_slope_5m_pct: 0.0` 形同虚设（任何微正斜率即过），但全史两桶 slope 区间重叠，现在定阈值 = 过拟合 19 笔。
- 路径：R0 攒样 ≥30 个武装候选（含 rejected 对照，注意 R0b 覆盖域不含早 continue 分支）→ 按 slope×dev 二维密度定阈 → 另起裁决。

### R3 · SL_BREAKEVEN 早锁右尾（**触 C1 退出参数冻结，只影子不落地**）

- 事实：盈利单实收/MFE 峰值 ≈ 0.23%/0.43-1.51% ≈ 15-50%。
- 影子设计：既有 `reentry_quick_tp_shadow_enabled`（config:1101）已在攒 quick TP 影子，R3 并入同族新增一臂"breakeven 触发后移"虚拟出场；回放局限 = trade_records 只有 mfe/mae/exit 三点无分时路径，只能粗估，预注册声明此局限。
- 裁决路径：影子 + 月报流程，**是否动 breakeven 参数属 C1 解冻裁决，本提案不请求**。
- 联动声明：R1 即使完美生效，费用结构（表4）决定总账仍需 R3 类改动抬实收才回正——两项不是替代关系。

### R4 · dead_signal 宽限 MFE 条件化

- 现状：`dead_signal_reentry_extension_min: 60` 对所有 reentry 仓一律加宽；证据显示 MFE≈0 单（宽限的主要命中对象）是入场即错而非发酵不足。
- 影子规则：宽限仅当持仓 MFE 曾 ≥0.2%（发酵中单）；MFE 恒 0 的单走基础 60min 不加宽。
- 价值定性：不省钱（阴跌+费在入场时已锁定），省的是 `max_arms_per_day=3` 名额与实时敞口。优先级低于 R1/R3。
