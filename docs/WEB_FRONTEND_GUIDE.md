## 🔐 安全特性

### 1. 密码加密

- SHA256 + Salt 哈希
- 密码不在网络传输明文
- Cookie HttpOnly 防止 XSS

### 2. Session 管理

- 7 天有效期
- 自动过期
- 退出登录自动清除

### 3. 权限控制

- 管理员：所有权限
- 普通用户：只读权限

## 🛠️ 用户管理

### 添加用户（管理员）

```bash
curl -X POST "http://localhost:8899/auth/users/add" \
  -H "Cookie: session_id=YOUR_SESSION_ID" \
  -F "username=newuser" \
  -F "password=newpassword" \
  -F "role=user"
```

### 列出用户（管理员）

```bash
curl "http://localhost:8899/auth/users" \
  -H "Cookie: session_id=YOUR_SESSION_ID"
```

## ⚠️ 注意事项

### 1. 默认账户

- 首次部署后请修改默认密码
- 不要将 admin 密码告诉他人

### 2. HTTPS

生产环境建议配置 HTTPS：
```nginx
server {
    listen 443 ssl;
    server_name aitz.cc;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://127.0.0.1:8899;
    }
}
```

### 3. 防火墙

只开放必要端口：
```bash
# 只允许信任 IP 访问
iptables -A INPUT -p tcp --dport 8899 -s 信任 IP -j ACCEPT
iptables -A INPUT -p tcp --dport 8899 -j DROP
```

```css

```

### 修改 Session 超时

编辑 `app/auth/users.py`：
```python
self.session_timeout = 86400 * 7  # 7 天
```
