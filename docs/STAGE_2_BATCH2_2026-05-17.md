## 4. 盘中安全保证 (重点)

### regime_classifier 关键警示
代码内加注释:
```python
# ⚠ 实盘铁律: 此函数可能被 30min 间隔的盘中调度触发.
# 调用方必须在异步线程包装 (不阻塞主线程). 例:
#   threading.Thread(target=lambda: classify(ctx), daemon=True).start()
# 当前函数本身是同步, 单次 LLM 8-20s. 主调度路径绝不能直接 await.
```

### 未迁的 3 个 (需异步重设计后才能启用)
| Feature | 触发点 | 推荐设计 |
|---|---|---|
| **large_position_review** | 仓位 > 5% 时盘中触发 | `Thread(daemon=True).start()` fire-and-forget, 结果异步写 audit 表, 不阻断下单 |
| **emergency_review** | 风控触发 (跌停/熔断) 盘中 | 同上, 但额外加 `signal.SIGALRM` 超时保证 (Linux only) |
| **news_classifier** | 新闻流盘中调 | 需队列 + 背压 (avoid Thread 堆积) |
