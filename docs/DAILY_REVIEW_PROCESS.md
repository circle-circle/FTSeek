## 📊 核心指标跟踪

### 信号质量指标
| 指标 | 公式 | 目标值 |
|------|------|--------|
| **信号执行率** | 执行数/总信号数 | ≥ 70% |
| **信号胜率** | 盈利信号数/总执行数 | ≥ 60% |
| **平均置信度** | 所有信号置信度均值 | 0.5-0.7 |
| **置信度校准** | 高置信度信号胜率 | 高置信度→高胜率 |

### 交易质量指标
| 指标 | 公式 | 目标值 |
|------|------|--------|
| **平均盈亏比** | 平均盈利/平均亏损 | ≥ 1.5 |
| **最大回撤** | 峰值到谷值最大跌幅 | ≤ 15% |
| **夏普比率** | (收益率-无风险利率)/波动率 | ≥ 1.0 |
| **持仓时间** | 平均持仓分钟数 | 符合日内策略 |

### 风控指标
| 指标 | 公式 | 目标值 |
|------|------|--------|
| **日交易次数** | 当日交易总数 | ≤ 15 |
| **连续亏损** | 连续亏损次数 | ≤ 5 |
| **单日亏损** | 当日累计亏损 | ≤ 5% |
| **信号拒绝率** | 拒绝数/总信号数 | ≤ 30% |

## 🔄 优化迭代流程

### Step 1: 问题识别
```
观察数据 → 发现异常 → 记录问题
```

**常见问题类型**:
- 信号过多/过少
- 执行率过低
- 胜率不达标
- 止损止盈触发不合理
- 置信度与实际偏离

### Step 2: 原因分析
```
5Why 分析法 → 找到根本原因
```

**分析维度**:
- 参数配置
- 市场环境
- 策略逻辑
- 数据质量
- 执行时机

### Step 3: 方案设计
```
提出假设 → 设计实验 → 小范围验证
```

**优化方向**:
- 参数调整
- 权重重分配
- 新增过滤条件
- 改进执行逻辑

### Step 4: 实施验证
```
修改配置 → 运行测试 → 记录结果
```

**验证方法**:
- A/B 测试
- 回测验证
- 小仓位实盘

### Step 5: 效果评估
```
对比前后 → 判断效果 → 决定是否保留
```

## 🎯 阶段性目标

### Week 1-2: 数据积累
- 收集足够信号样本 (目标: ≥50 个信号)
- 建立基准表现数据
- 识别明显问题

### Week 3-4: 参数优化
- 基于数据调整参数
- A/B 测试不同配置
- 找到最优参数组合

### Week 5-8: 策略验证
- 验证优化效果
- 追踪胜率目标 (≥60%)
- 准备实盘切换

### Week 9-12: 稳定运行
- 持续监控表现
- 微调参数
- 确认策略稳定性

## 📚 学习资源

### 复盘方法论
- **PDCA 循环**: Plan → Do → Check → Act
- **5Why 分析**: 连续问5次为什么
- **A/B 测试**: 对照实验验证假设

### 关键指标解读
- **胜率高但盈亏比低**: 可能止盈过早
- **胜率低但盈亏比高**: 正常趋势策略特征
- **执行率低**: 检查风控是否过严
- **置信度偏离**: 模型需要校准
