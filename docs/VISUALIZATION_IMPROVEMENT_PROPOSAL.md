## 📈 专业量化指标体系

### 一级指标 (核心 KPI)

| 指标 | 公式 | 阈值 | 说明 |
|------|------|------|------|
| **夏普比率** | (Rp-Rf)/σp | >1.5 | 风险调整后收益 |
| **索提诺比率** | (Rp-Rf)/σd | >2.0 | 下行风险调整收益 |
| **卡玛比率** | 年化收益/最大回撤 | >3.0 | 回撤调整收益 |
| **信息比率** | (Rp-Rb)/σ(Rp-Rb) | >0.5 | 相对基准超额收益 |
| **最大回撤** | max(峰值 - 谷值)/峰值 | <15% | 历史最大亏损 |
| **VaR 95%** | 95% 置信度日风险值 | <3% | 日风险价值 |
| **CVaR** | 超过 VaR 的平均损失 | <5% | 条件风险价值 |

### 二级指标 (策略表现)

| 指标 | 公式 | 阈值 | 说明 |
|------|------|------|------|
| **胜率** | 盈利交易数/总交易数 | >45% | 交易成功比例 |
| **盈亏比** | 平均盈利/平均亏损 | >1.5 | 赚赔比例 |
| **盈利因子** | 总盈利/总亏损 | >1.5 | 整体盈利能力 |
| **期望值** | (胜率×均赢)-(败率×均亏) | >0 | 单笔期望收益 |
| **连败次数** | 最大连续亏损 | <5 | 风险承受能力 |
| **恢复时间** | 回撤恢复所需天数 | <30 | 策略恢复力 |
| **交易频率** | 交易次数/交易日 | 0.5-5 | 交易活跃度 |

### 三级指标 (风险细节)

| 指标 | 说明 | 预警 |
|------|------|------|
| **Beta 系数** | 相对市场波动敏感度 | >1.5 高 |
| **相关性** | 持仓标的间相关性 | >0.7 警戒 |
| **集中度** | 前 N 大持仓占比 | >50% 高 |
| **流动性** | 持仓/日均成交量 | >10% 警戒 |
| **杠杆率** | 总暴露/净资产 | >2 高 |
| ** Greeks** | Delta/Gamma/Vega/Theta | 期权专用 |

### 2. 指标计算模块

```python
# app/risk/metrics_calculator.py

class MetricsCalculator:
    """专业量化指标计算器"""
    
    def sharpe_ratio(returns, risk_free_rate=0.02) -> float:
        """夏普比率"""
        excess_returns = returns - risk_free_rate / 252
        return np.sqrt(252) * excess_returns.mean() / excess_returns.std()
    
    def sortino_ratio(returns, risk_free_rate=0.02) -> float:
        """索提诺比率 (只考虑下行波动)"""
        excess_returns = returns - risk_free_rate / 252
        downside_std = np.sqrt(np.mean(excess_returns[excess_returns < 0] ** 2))
        return np.sqrt(252) * excess_returns.mean() / downside_std
    
    def calmar_ratio(returns, max_drawdown) -> float:
        """卡玛比率"""
        annual_return = np.prod(1 + returns) ** (252 / len(returns)) - 1
        return annual_return / abs(max_drawdown)
    
    def var_historical(returns, confidence=0.95) -> float:
        """历史 VaR"""
        return np.percentile(returns, (1 - confidence) * 100)
    
    def cvar(returns, confidence=0.95) -> float:
        """条件 VaR (预期亏损)"""
        var = self.var_historical(returns, confidence)
        return returns[returns <= var].mean()
    
    def max_drawdown(equity_curve) -> float:
        """最大回撤"""
        peak = np.maximum.accumulate(equity_curve)
        drawdown = (peak - equity_curve) / peak
        return drawdown.max()
    
    def beta(returns, benchmark_returns) -> float:
        """Beta 系数"""
        covariance = np.cov(returns, benchmark_returns)[0, 1]
        benchmark_variance = np.var(benchmark_returns)
        return covariance / benchmark_variance
    
    def correlation_matrix(returns_dict) -> dict:
        """相关性矩阵"""
        df = pd.DataFrame(returns_dict)
        return df.corr().to_dict()
```
