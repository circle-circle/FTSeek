## 📊 回测指标体系

### 收益指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 总收益率 | (最终值 - 初始值) / 初始值 | 总体收益 |
| 年化收益率 | (1 + 总收益率)^(252/天数) - 1 | 年化收益 |
| 超额收益 | 策略收益 - 基准收益 | 相对基准表现 |

### 风险指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 最大回撤 | max(峰值 - 谷值) / 峰值 | 最大亏损幅度 |
| 波动率 | std(日收益率) × √252 | 年化波动率 |
| VaR(95%) | 5% 分位数日收益 | 95% 置信度最大亏损 |
| CVaR | VaR 尾部平均 | 条件风险价值 |

### 风险调整收益

| 指标 | 公式 | 说明 |
|------|------|------|
| Sharpe 比率 | (年化收益 - 无风险利率) / 波动率 | 单位风险超额收益 |
| Sortino 比率 | (年化收益 - 无风险利率) / 下行波动率 | 只考虑下行风险 |
| Calmar 比率 | 年化收益 / 最大回撤 | 收益回撤比 |
| Win Rate | 盈利交易数 / 总交易数 | 胜率 |
| Profit Factor | 总盈利 / 总亏损 | 盈亏比 |

## 🔧 参数优化方案

### 方案 1: 网格搜索

**适用场景:** 参数空间小，参数数量≤3

**实现:**
```python
param_grid = {
    'stop_loss': [0.05, 0.08, 0.10],
    'take_profit': [0.10, 0.15, 0.20],
    'position_size': [0.1, 0.2]
}
# 遍历所有组合，共 3×3×2=18 种
```

**优点:** 简单，保证找到全局最优
**缺点:** 计算量大，参数多时不可行

### 方案 2: 贝叶斯优化

**适用场景:** 参数空间大，评估成本高

**实现:**
```python
from skopt import gp_minimize

param_bounds = [
    (0.05, 0.15),  # stop_loss
    (0.10, 0.25),  # take_profit
    (0.05, 0.30),  # position_size
]

result = gp_minimize(
    backtest_and_score,
    param_bounds,
    n_calls=50,
    acq_func='EI'
)
```

**优点:** 高效，参数多时优势明显
**缺点:** 可能陷入局部最优

## 📈 蒙特卡洛模拟

### 功能 1: 随机路径生成

**目的:** 评估策略在不同市场情景下的表现

**方法:**
```python
# 基于历史收益率分布生成随机路径
for i in range(1000):
    random_returns = np.random.choice(
        historical_returns, 
        size=len(trades)
    )
    equity_curve = calculate_equity(random_returns)
    results.append(equity_curve)
```

---

### 功能 2: VaR 计算

**目的:** 量化风险

**方法:**
```python
# 历史模拟法
VaR_95 = np.percentile(returns, 5)

# 蒙特卡洛法
simulated_pnl = []
for _ in range(10000):
    pnl = simulate_pnl()
    simulated_pnl.append(pnl)
VaR_95 = np.percentile(simulated_pnl, 5)
```
