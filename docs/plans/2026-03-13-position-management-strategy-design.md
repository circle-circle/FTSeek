## 🏗️ 核心策略设计

### 1️⃣ 开仓策略 - 分批建仓

**原则**: 避免一次性满仓，分 2 批建立初始仓位

```
首次开仓：50% 计划仓位 (总资金的 10%)
加仓确认：50% 计划仓位 (总资金的 10%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总仓位：20% (不超过风控上限)
```

**示例** (腾讯控股，股价 HK$ 400):
```
计划仓位：20% = HK$ 200,000
计划股数：500 股

首次开仓：250 股 @ HK$ 400 = HK$ 100,000 (10%)
加仓确认：250 股 @ HK$ 410 = HK$ 102,500 (10.25%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总投入：HK$ 202,500 (20.25%)
平均成本：HK$ 405/股
```

**加仓确认条件** (满足任一):
- 价格上涨 ≥ 2% (确认趋势)
- 信号置信度 ≥ 75% (强信号)
- 持仓时间 ≥ 24 小时 (时间确认)

---

### 2️⃣ 加仓策略 - 金字塔加仓

**原则**: 越涨买越少，降低风险

```
第 1 次加仓：30% 计划仓位 (价格上涨 5%)
第 2 次加仓：20% 计划仓位 (价格再涨 5%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
最多加仓 2 次，总仓位不超 20%
```

**金字塔结构**:
```
价格涨幅 | 加仓比例 | 加仓股数 | 累计仓位
━━━━━━━━┿━━━━━━━━━┿━━━━━━━━━┿━━━━━━━━━
  +0%    |  50%    |  250 股  |  10%
  +5%    |  30%    |  150 股  |  16%
 +10%    |  20%    |  100 股  |  20% (满)
```

**加仓触发条件** (必须同时满足):
- ✅ 当前有盈利 (浮动盈亏 > 0)
- ✅ 价格上涨 ≥ 5% (从平均成本)
- ✅ 信号置信度 ≥ 70%
- ✅ 未达最大仓位 (20%)
- ✅ 冷却时间已过 (4 小时)

**禁止加仓场景**:
- ❌ 当前亏损
- ❌ 价格下跌
- ❌ 已达最大仓位
- ❌ 冷却时间内

---

### 3️⃣ 出仓策略 - 组合策略

**原则**: 止损保护 + 趋势跟踪

```
止损线：-5% 强制平仓 (风控优先)
止盈线：+15% 部分平仓 (50% 仓位)
反向信号：剩余仓位全部平仓
```

**出仓流程**:
```
1. 实时监控盈亏
   │
   ├─ 达到 -5% → 立即全部平仓 (止损)
   │
   ├─ 达到 +15% → 平仓 50% (止盈锁定)
   │   │
   │   └─ 等待反向信号 → 平仓剩余 50%
   │
   └─ 收到反向信号 → 全部平仓
```

**止损执行** (强制):
```
触发条件：浮动盈亏 ≤ -5%
执行：立即市价平仓 100%
通知：钉钉推送"止损平仓"警告
```

**止盈执行** (分批):
```
触发条件：浮动盈亏 ≥ +15%
执行：
  1. 市价平仓 50% (锁定利润)
  2. 剩余 50% 继续持有
  3. 等待反向信号或止损

通知：钉钉推送"止盈部分平仓"
```

**反向信号平仓**:
```
触发条件：持仓方向与信号相反
  - 持仓 BUY + 信号 SELL
  - 持仓 SELL + 信号 BUY

执行：平仓 100% (包括止盈后剩余仓位)
通知：钉钉推送"反向信号平仓" + 盈亏详情
```

---

### 4️⃣ 交易间隔 - 组合限制

**原则**: 多维度防止过度交易

```
时间维度：开仓后 4 小时冷却期
强度维度：加仓需置信度 ≥ 70%
次数维度：单股最多 3 次交易/日
```

**冷却时间规则**:
```
开仓/加仓后 → 4 小时内禁止再次交易同一股票
例外：止损平仓不受冷却限制 (风控优先)
```

**信号强度过滤**:
```
置信度 < 60%: 忽略信号
置信度 60-70%: 仅开仓，不加仓
置信度 ≥ 70%: 可开仓 + 加仓
```

**日交易次数限制**:
```
单只股票：最多 3 次交易/日 (开仓 + 加仓 + 平仓)
全局：最多 20 次交易/日 (现有频率限制)
```

```python
class PositionManager:
    def can_add_position(self, code: str, signal_confidence: float) -> bool:
        """检查是否可以加仓"""
    
    def get_add_quantity(self, code: str, price_increase: float) -> int:
        """计算加仓数量 (金字塔)"""
    
    def check_stop_loss(self, code: str, current_price: float) -> bool:
        """检查是否触发止损"""
    
    def check_take_profit(self, code: str, current_price: float) -> bool:
        """检查是否触发止盈"""
    
    def is_in_cooling_period(self, code: str, hours: int = 4) -> bool:
        """检查是否在冷却期内"""
    
    def get_today_trade_count(self, code: str) -> int:
        """获取今日交易次数"""
```

**TradeExecutor 新增方法**:
```python
class TradeExecutor:
    def execute_partial_close(self, signal: Signal, close_ratio: float) -> TradeResult:
        """执行部分平仓"""
```

### 3. 监控任务

**定时检查任务** (每 5 分钟):
```python
def monitor_positions():
    """监控所有持仓"""
    positions = position_manager.get_all_positions()
    
    for position in positions:
        current_price = get_current_price(position.code)
        
        # 检查止损
        if position_manager.check_stop_loss(position.code, current_price):
            execute_stop_loss(position)
        
        # 检查止盈
        elif position_manager.check_take_profit(position.code, current_price):
            execute_take_profit(position)
```

```

### 场景 2: 止损出仓

```
持仓：500 股 腾讯控股，平均成本 HK$ 405

  → 浮动盈亏：(385-405)/405 = -4.94%

## ⚠️ 边界情况处理

### 1. 资金不足
```
场景：加仓时可用资金不足
处理：
  - 计算最大可买股数
  - 按比例调整加仓数量
  - 推送"资金不足，部分加仓"通知
```

### 2. 价格跳空
```
场景：开盘价直接跌破止损线
处理：
  - 立即市价平仓
  - 接受实际成交价
  - 记录"跳空止损"标记
```

### 3. 停牌
```
场景：持仓股票停牌
处理：
  - 暂停该股票交易
  - 继续监控其他股票
  - 复牌后重新评估
```

### 4. 频率限制
```
场景：触及 20 条/日限制
处理：
  - 优先执行止损平仓 (不受限制)
  - 其他信号排队等待次日
  - 推送"频率限制"通知
```
