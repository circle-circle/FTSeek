## 📖 使用示例

### 基本使用

```python
from app.analyzers.news_classifier import NewsClassifier

classifier = NewsClassifier(use_llm=True)

result = classifier.classify(
    title='央行宣布降准 0.25 个百分点',
    content='中国人民银行决定下调存款准备金率'
)

print(f"{result.level1}/{result.level2} (置信度：{result.confidence})")
# 输出：宏观经济/央行政策 (置信度：0.9)
```

### 自定义规则

```python
classifier.add_custom_rule(
    name='ai_industry',
    keywords=['人工智能', 'AI', '大模型'],
    level1='行业政策',
    level2='监管政策'
)
```

### 批量分类

```python
news_list = [
    {'title': '央行降准', 'content': '...'},
    {'title': '腾讯财报', 'content': '...'}
]

results = classifier.classify_batch(news_list)
stats = classifier.get_statistics(results)
```
