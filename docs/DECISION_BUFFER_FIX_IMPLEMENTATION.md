# 决策缓冲队列满问题 - 修复实施报告

**日期**: 2026-04-09  
**状态**: ✅ P0 修复已完成

---

## 问题总结

### 现象
```
[决策缓冲] ❌ 拒绝信号：HK.01024 BUY | 原因：队列已满，被更高优先级信号替换
[决策缓冲] 队列已满，移除低优先级信号：HK.01024 BUY
```

多个不同标的 BUY 信号连续被拒绝，说明：
- 市场普涨，大量信号涌入
- 执行速度跟不上信号产生速度
- 队列容量不足

### 根本原因
**信号生产速度 > 执行消费速度**

---

## 已实施修复

### 1. 增加队列容量 ✅

**文件**: `app/main.py` L118

**修改**:
```python
# 修改前
max_pending=30  # 最大待处理队列长度

# 修改后
max_pending=50  # 10 → 30 → 50
```

**效果**: 队列容量提升 67% (30→50)

### 2. 添加队列拥堵告警 ✅

**文件**: `app/decision_buffer.py` L196-201

**新增代码**:
```python
# 队列使用率告警
usage_rate = len(self._pending_queue) / self.max_pending
if usage_rate >= 0.8:
    logger.warning(
        f"[决策缓冲] ⚠️ 队列拥堵告警：{len(self._pending_queue)}/{self.max_pending} "
        f"({usage_rate:.0%})"
    )
```

**效果**: 当队列使用率 ≥ 80% 时推送警告日志
