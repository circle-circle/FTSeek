## 三、API 端点设计

### 3.1 新增端点

```
GET /api/v2/review/dashboard
  - 获取大盘 KPI 指标
  - 收益曲线数据
  - 回撤分析数据

GET /api/v2/review/attribution
  - 按策略分组统计
  - 按市场状态分组统计
  - 按信号强度分组统计
  - 策略×市场状态交叉分析
  - 噪声信号识别
  - 过拟合信号识别

GET /api/v2/review/correlation
  - 信号分数 vs 盈亏相关性 (Pearson r)
  - 置信度 vs 胜率关系
  - 按策略分组的相关性
  - 噪声信号列表
  - 过拟合信号列表

GET /api/v2/review/recommendations
  - 降权/加权建议
  - 重新校准建议
  - 黑名单建议
  - 执行策略调整建议

GET /api/v2/review/trades/detail
  - 交易明细列表
  - 支持日期/策略/市场状态过滤
```

### 3.2 响应示例

```json

  "generated_at": "2026-04-05T23:30:00",
```
