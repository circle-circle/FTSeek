## 💰 二、收益计算 (扣除费用)

### 港股交易费用明细

| 费用类型 | 费率 | 收取方 | 说明 |
|----------|------|--------|------|
| **印花税** | 0.1% | 香港政府 | 买卖双方各收 (2021 年 8 月起) |
| **交易费** | 0.00565% | 港交所 | 买卖双方各收 |
| **交易征费** | 0.0027% | 证监会 | 买卖双方各收 |
| **平台费** | HK$15/笔 | 富途 | 每笔订单固定 |
| **佣金** | 0.03% | 富途 | 最低 HK$3 |

### 费用计算公式

**买入费用**:
```
买入总额 = 股价 × 数量
印花税 = 买入总额 × 0.1%
交易费 = 买入总额 × 0.00565%
交易征费 = 买入总额 × 0.0027%
佣金 = MAX(买入总额 × 0.03%, HK$3)
平台费 = HK$15

买入总费用 = 印花税 + 交易费 + 交易征费 + 佣金 + 平台费
买入成本 = 买入总额 + 买入总费用
```

**卖出费用**:
```
卖出总额 = 卖出价 × 数量
印花税 = 卖出总额 × 0.1%
交易费 = 卖出总额 × 0.00565%
交易征费 = 卖出总额 × 0.0027%
佣金 = MAX(卖出总额 × 0.03%, HK$3)
平台费 = HK$15

卖出总费用 = 印花税 + 交易费 + 交易征费 + 佣金 + 平台费
卖出实收 = 卖出总额 - 卖出总费用
```

**净收益**:
```
毛盈亏 = (卖出价 - 买入价) × 数量
净收益 = 卖出实收 - 买入成本
收益率 = 净收益 / 买入成本 × 100%
```

### 计算示例

**交易**: 腾讯控股 (HK.00700)
- 买入：380.50 × 100 股
- 卖出：395.00 × 100 股
- 持有：5 天

#### 买入费用
| 项目 | 计算 | 金额 |
|------|------|------|
| 买入总额 | 380.50 × 100 | HK$38,050.00 |
| 印花税 | 38,050 × 0.1% | HK$38.05 |
| 交易费 | 38,050 × 0.00565% | HK$2.15 |
| 交易征费 | 38,050 × 0.0027% | HK$1.03 |
| 佣金 | MAX(38,050×0.03%, 3) | HK$11.42 |
| 平台费 | 固定 | HK$15.00 |
| **买入总费用** | - | **HK$67.65** |
| **买入成本** | 38,050 + 67.65 | **HK$38,117.65** |

#### 卖出费用
| 项目 | 计算 | 金额 |
|------|------|------|
| 卖出总额 | 395.00 × 100 | HK$39,500.00 |
| 印花税 | 39,500 × 0.1% | HK$39.50 |
| 交易费 | 39,500 × 0.00565% | HK$2.23 |
| 交易征费 | 39,500 × 0.0027% | HK$1.07 |
| 佣金 | MAX(39,500×0.03%, 3) | HK$11.85 |
| 平台费 | 固定 | HK$15.00 |
| **卖出总费用** | - | **HK$69.65** |
| **卖出实收** | 39,500 - 69.65 | **HK$39,430.35** |

#### 净收益
| 项目 | 计算 | 金额 |
|------|------|------|
| 毛盈亏 | (395.00-380.50)×100 | +HK$1,450.00 |
| 总费用 | 67.65 + 69.65 | HK$137.30 |
| **净收益** | 1,450.00 - 137.30 | **+HK$1,312.70** |
| **收益率** | 1,312.70/38,117.65 | **+3.44%** |

### signals 表 (扩展字段)
```sql
CREATE TABLE signals (
    id TEXT PRIMARY KEY,
    code TEXT,
    action TEXT,              -- BUY/SELL
    price REAL,               -- 成交价格
    quantity INTEGER,         -- 数量
    buy_amount REAL,          -- 买入总额
    buy_fees REAL,            -- 买入费用
    buy_cost REAL,            -- 买入成本
    sell_amount REAL,         -- 卖出总额
    sell_fees REAL,           -- 卖出费用
    sell_net REAL,            -- 卖出实收
    gross_pnl REAL,           -- 毛盈亏
    net_pnl REAL,             -- 净收益
    return_rate REAL,         -- 收益率
    status TEXT,              -- pending/confirmed/executed
    ...
);
```

## 📊 五、收益统计指标

### 日报指标
- 今日净收益 (扣除费用)
- 今日收益率
- 今日交易笔数
- 胜率 (盈利交易/总交易)
- 平均单笔收益

### 周报指标
- 周净收益
- 周收益率
- 周交易笔数
- 周胜率
- 盈亏比 (平均盈利/平均亏损)
- 费用总额

### 月报指标
- 月净收益
- 月收益率
- 月胜率
- 夏普比率 (基于净收益)
- 最大回撤
- 费用占比 (费用/交易总额)
