## 可选方案

### 方案 A — MFE 结局画像注入 (换信息, 零行为变更)

- 提出者: Hermes
- 核心思路: 把喂给 DA/辩论的历史反馈从 "总交易N次, 胜率X%, 最近3笔盈亏" 换成结果锚定的结局画像:
  - 该标的最近 K 笔的 **死胎率** (MFE<1% 占比) 与 **存活笔的锁利分布**
  - 死胎笔的共性时段 (如 "死胎全在开盘 30 分钟内出场")
  - 用 trade_records.mfe_pct 权威字段, 不用标签胜率
- 优点: 喂的是已被证明是唯一分水岭的统计量; 不改任何行为、不加规则、不碰冻结参数; 纯"修尺子"性质 (零行为变更); 可量化验证 (注入前后 DA 对高死胎率标的的 SKIP 率变化)
- 缺点: 若逐笔预测本就零分离 (E2), 标的级聚合画像可能同样无分离 → 做了也可能空; 增加 DA prompt 长度
- 适用条件: 无前置条件 (零行为变更), 但效果需影子验证
- 风险: **低**。最坏结果 = 信息没用, 无损失

### 方案 B — 盘中 regime 反馈环 (影子先行)

- 提出者: Hermes (E3 种子)
- 核心思路: 记录"入场时刻当日累计已实现结局"作为每笔交易的协变量 (record-only), 攒样后按预注册判据 (双窗方向一致 + 死胎率差≥15pp + n≥30/层) 裁决是否构成真信号
- 优点: 这是"市场识别"里唯一没被证穷的一块 — 系统当前开仓决策与当日已发生结局零关联; 若有效, 是真实的 regime 识别 (用户命题核心)
- 缺点: E3 初测仅 5-10pp 差, 远低于 15pp 候选线; 与开盘效应/样本顺序强混杂; 大概率重蹈"看似有信号→双窗口击穿"覆辙
- 适用条件: 必须影子模式 + 预注册判据, 攒 2-3 周
- 风险: **低** (纯记录), 但期望收益也低 — 诚实标注: 这是"买一张便宜的彩票"

### 方案 C — 假设种群生命周期 (记忆形态改造, "不固化"的机制解)

- 提出者: Hermes
- 核心思路: 经验教训的存储从叙事 (lesson_log) 改为**假设种群**:
  - 每条经验 = {预测文本, 预注册证伪判据, 样本计数器, 创建日期, 过期日期}
  - 周检 (复用周六 09:05 OOS 周检时点): 攒够样本的假设按双窗口裁决 — 活→升级为候选门禁 (走既有攒样器纪律), 死→**自动删除**
  - 新证据随时可挑战旧假设 (任何回放/实弹结果与假设冲突 → 计数器清零重攒)
  - lesson_log 的 391 条叙事: 批量过一遍 → 能翻译成假设的翻译, 不能的归档删除
- 优点: 直接回答用户"不固化"命题 — 记忆是有选择压力、会死亡的种群, 不是规则清单; 复用已验证的攒样器纪律 (8/14 跑通过); 消灭死内存
- 缺点: 工作量最大 (假设登记簿 + 周检钩子 + 翻译存量); "翻译存量"本身有主观性风险; 若种群长期没有假设通过裁决, 机制空转
- 适用条件: 需要用户批准架构方向; 实施前先把 A/B 挂上 (否则种群没有假设来源)
- 风险: **中**。架构改动, 但改动在记忆层不在交易层, 零交易行为风险

### 方案 D — 删除死内存 (减法选项)

- 提出者: Hermes (对抗性自审: 最简方案必须列出)
- 核心思路: lesson_log 零消费 → 直接停写+归档; pattern_memory 休眠 → 归档。不做 A/B/C 任何新建设。理由: 毛期望≈0 的世界里, 识别层的任何"提升"大概率是幻觉; 9月定位修尺子攒学费, 不加新组件
- 优点: 零工作量、零新代码、符合"做减法>打补丁"原则
- 缺点: 放弃用户明确提出的命题 ("要让链路不固化、有泛化识别能力"); 若未来换信号源 (10月备选方向), 没有记忆基建承接
- 适用条件: 用户认为识别层优化在毛期望≈0 约束下无意义时
- 风险: **低**, 但战略上是"不答题"

## 关键分歧

1. **分歧点 1: 识别层优化在"毛期望≈0"的世界里是否有意义?**
   - 方案 A/B/C 观点: 毛期望=0 是**当前信号源**下的结论; 反馈回路修复是为换信号源 (10月备选) 铺基建, 且 A 是零行为变更的尺子修正
   - 方案 D 观点: 9月明文修尺子攒学费期, 任何识别层新组件都是"在零分子上加装饰", 8/22 adj 三闸已证明识别层"自报提升"系统性虚高
   - 可验证方式: A 有直接验证 (注入前后影子对照); D 无法证伪 (不做就没有数据) — 这本身是 D 的缺陷

2. **分歧点 2: 死胎不可预测 (E2) 是否意味着标的级画像也无意义?**
   - 反方: 逐笔零分离 → 聚合到标的级大概率也零分离 (同一噪声源), A 大概率空
   - 正方: 逐笔分离度为零 ≠ 标的间死胎率无差异 (今日数据: AU 死胎率 100% n=4 vs UBER 50% n=8); 差异是否有**持续性** (本周高死胎率标的下周是否仍高) 未测 — 这是 A 的核心待验证假设
   - 可验证方式: 先算标的死胎率的周间自相关 (本周数据可直接跑), 自相关≈0 则 A 也判死, 不实施

3. **分歧点 3: "不固化"应该靠机制还是靠流程?**
   - 方案 C: 机制化 (假设种群自动淘汰)
   - 对抗观点: 现有攒样器纪律 + 用户终裁流程已经在事实上做"假设淘汰" (8/14-8/24 已否决 6+ 个提案), 机制化是否重复建设?
   - 可验证方式: 统计过去 30 天"提出→否决/落地"的提案生命周期, 若现有流程已能在 ≤2 周内完成淘汰, C 的增量价值存疑

### 第 2 轮 — 分歧点 2 前置检验结果 (2026-08-25, 用户批"要"后执行)

**标的死胎率半程自相关检验** (窗口 7/25–8/24, 切点 8/10, H1 n=90 / H2 n=112):
- 两半都出现的标的 16 只; 双半 n≥3 的仅 **4 只** (样本极薄)
- **pearson = −0.40** (n=16, t=−1.63 不显著, 方向还是**反持续**); n≥3 子集 −0.42
- 同侧 (两半死胎率同高于/低于 50%) 仅 10/16, sign test p≈0.23
- 噪声地板: 半程 n≈4 时死胎率二项抽样标准差 ≈ **23pp** — 观测 delta (17-67pp) 多数在噪声量级内
- 个案直观也无反例支撑持续性: UBER 100%→33% (−67pp), BABA 38%→100% (+62pp), 双向乱跳

**裁决: 方案 A 按本议题自设判据判死 (自相关≈0 且方向为负), 不实施。**
逐笔零分离 (E2) + 标的级无持续性 (本轮) 两条独立证据链闭合: 已记录数据空间内,
死胎率在任何粒度上都不构成可事前利用的信号。注入"结局画像"大概率注入的是噪声。

**遗留影响**: 方案 B 的判据不变 (影子预注册); 方案 C 的假设来源少了一条 (A 出局),
但 C 的价值在机制本身不在存量假设; 方案 D 相对地位上升。待用户终裁 B/C/D。
