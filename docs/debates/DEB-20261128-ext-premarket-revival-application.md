## 2. DA 针对性优化：诚实评估（第一性原理）

**结论先行：现有数据不支持「把 DA 调参调出盈利」。** 不是没努力，是物理量不够。

- **毛 edge ≈ 0**：§16 DA signal n581，gross **+4.35bps**、日聚类 **t0.51**、**MDE80≈21.38** ⇒ 效应 ≪ MDE，
  与 0 **不可分辨**；net **−5.42bps**（费拖 ~9.77bps 把毛≈0 压成净负）。
- **第一性原理**：净收益 = 毛 edge − 成本。毛 edge 本身 ≈0 ⇒ **任何出场/过滤/形态/仓位调参都无法凭空造出毛 edge**，
  只能重新分配噪声或削减成本（削成本不造 edge，且降频已被 §14.2 证为姑息）。
- **「针对性优化」菜单几乎全被终裁封闭**（不得重开）：
  | 想优化的方向 | 封闭轴 | 终裁要点 |
  |---|---|---|
  | 盘前跌幅/bear 否决门 | C8 | 高基率无区分度，净代价 −$446 |
  | 改 entry 定价/触发确认 | C9 | anchor 虚高 6×，纸面 edge 落地化一律不予受理 |
  | 放宽 SL / 补仓摊平 | C11 | 越放越差，补仓 100% 破单名帽 |
  | 切正子集 / 加深分析降死单 | C12 | 8/8 轴 eta²<5%，无判别力 |
  | EOD 减半隔夜 | C14 | 三时点一致为负 |
  | 组合偏斜硬拦 | C15 | 剔最大单笔后 ≈0，随机砍多头 |
  | 入场形态轴 | C16 | 月份翻转 |
  | 取消全部隔夜 | C17 | 隔夜是减损器非 alpha 源 |
  | 结构性移动止损（方案A） | §13 已测 | 7 笔武装 Δ−4.78bps，n7<30 **不可分辨** + 趋势出场配剥头皮入场**机制错配** |
- **OKR 硬约束**：§6.1/§7「不得给 DA 加新门当默认答案」「不新开 C1 之外入场假设」「主管线已冻结新仓」。
- **DA 剩下的合法杠杆（非新门、非封闭轴）**：
  1. **冻结本身 = 止血**：停止 −5.42bps/笔 的净出血（已冻结，§5 KR1 11-30 结算 formalize）。
  2. **DA 作参照基线 + scan_loop 供料**：它是 EXT 增量测量的分母（§16 重叠切分），保留运行有价值，但**不是利润引擎**。
  3. **成本/执行侧只读测量**（如本 DEB M2 类）：量化费拖/滑点，属修尺子，非加门。
- **「不浪费」的正确重构（关键，且不违反 §6.4）**：EXT-盘前是**同一 Playbook 系统的既有臂**，对 DA **97% 增量**
  （符号-日重叠仅 1/37）。复活 EXT = **给现有系统加一条统计支持的增量腿**，DA 保留作冻结基线/供料，**不抛弃任何东西**。
  这正是用户要的「不重新换、针对现有系统提升」。**但必须诚实**：这**不等于 DA 有 edge**——
  OKR §6.4 明禁「用整体组合（含 EXT 尾部）为正来宣称 DA 有 edge」。DA 自身仍无已证 edge；利润增量来自 EXT 这条**独立臂**。

## 3. EXT-盘前人群精化（M2 新发现，重塑撞车映射）

§16 把 EXT-盘前 n37 当一个「财报催化」人群；**M2 用 trade metadata 精化后发现它其实是两套机制**：

| 子臂 | n | 财报元数据 | 多空 | 机制 | 撞车家族 |
|---|---|---|---|---|---|
| strict（带 earnings_report_date） | **12** | 有（bmo7/amc5） | 混合 | 财报催化 + 盘前顺势 | **C10 财报方向 + C13** |
| strict（无财报元数据，SHEL/CMG） | 2 | 无 | SHORT | 大异动盘前顺势（ext_chg 4.4%/11.2%） | C13 |
| research_momentum | **23** | **全无** | **全 LONG 普通股** | 通用盘前动量（无财报门） | **C13（非 C10）** |

- **「财报催化」故事仅落在 12 笔**（<30，历史功效不足）⇒ C10 两对照即便做出来也只能是支持性证据，须前瞻攒样。
- **research_momentum 23 笔 = 通用盘前动量**，无财报门 ⇒ 它走 **C13 复活门**（不是 C10）。
  且它是**全 LONG 普通股**（ASML/PEP/NVDA/MSFT/AVGO/TSLA/AAPL/MCD/ABBV/MU/PLTR/MRNA/CRWV/GOOG/APP/DDOG/QCOM/MRVL），
  **不含 C13 当年独占正均值的杠杆/加密 ETF** ⇒ 与 C13「普通股干净窗 −0.122%、做多腿 −0.784%」形成**符号相反**的待裁区分点。
- **治理含义**：复活不是「一个 EXT 门」，是**两个子命题分别过门**（strict-财报 → C10+C13；research-动量 → C13），
  不得把 n37 的 t4.87 当成单一机制的 edge。

| SHORT 借券 | SHORT 9 笔；metadata **无借券可得性/费率字段** | **缺口**，须另测，本审计不下结论 |

**M2 诚实结论**：
1. **净 edge +32.72bps 是上界**：入场 0% 不利 + 出场偏有利 = SIM 乐观成交。实盘盘前宽点差/逆向选择会扣减；
   若实盘入场+出场各不利 10bps，净 edge 可能从 +32.72 缩到 ~+12bps 甚至更低。**转正前必做前瞻实盘 arrival-vs-fill 保真测量扣减。**
2. **流动性不是 $5000 票面的瓶颈**（参与率 <0.03%），所以「优化调整」的执行靶点**不是流动性，是成交真实性**（滑点/借券）。
3. **优化靶点（合法、非封闭轴、非新入场门）**：(a) 前瞻实盘滑点保真测量；(b) SHORT 借券可得性/费率测量；
   (c) 盘前瞬时点差（ext_turnover 是全盘前段成交额，非入场时刻瞬时流动性）测量。这些是**修尺子/执行侧**，不是给 DA 加门。
4. n37 小样本、历史非前瞻、fees_est≠live ⇒ **不宣称可复活/可转正/盈利**。

### 10.4 前瞻实盘执行保真规格 M3（冻结设计 · 待前瞻数据 · 「优化提升盈利」的合法执行靶点）

> **为什么需要 M3**：M2（§5）量的是 **SIM 自身成交记账**——入场 0% 不利 + 出场偏有利 = **乐观伪影**，
> 净 +32.72bps 是**上界**。用户要「优化调整提升盈利」，执行侧的合法靶点**不是流动性**（参与率 <0.03%，
> $5000 票面非约束）、**不是给 DA 加门**（封闭轴），而是**把 SIM 上界扣减成实盘可执行净 edge**。
> M3 在前瞻影子窗（RFC-149 新窗，SIM-only）采集真实盘前微观结构，冻结四轴口径（读数前写死，不得事后挑格子）。

| 轴 | 冻结口径 | 数据需求（前瞻） | 对照 M2 |
|---|---|---|---|
| **① 入场 arrival-vs-fill 滑点** | 决策时刻 t_decision 记瞬时中间价 arrival_ref + best bid/ask；成交 t_fill 记实际 fill。方向感知滑点=(fill−arrival_ref)/arrival_ref×1e4（SHORT 取反）。**arrival_ref 冻结为决策时刻市场中间价**（非 decision_px，后者本身可能偏移） | 前瞻 L1 报价快照（bid/ask/last）at t_decision + t_fill | M2 用 decision_px 得 0% 不利 ⇒ M3 测真实不利占比 + mean bps |
| **② 瞬时点差/深度** | t_decision 的 bid-ask spread（bps）+ 盘口可成交股数；参与率=票面股数/盘口可成交量 | 前瞻盘口快照（富途 LV2 摆盘/经纪商盘前报价） | M2 参与率用**全段** ext_turnover（非瞬时）⇒ M3 测入场时刻瞬时流动性 |
| **③ SHORT 借券** | t_decision 记可借股数 + 年化借券费率 ⇒ 折算持有期借券成本 bps | 借券 API（富途卖空池/经纪商借券）；不可得 ⇒ SHORT 腿单列「借券未测」 | M2 metadata 无字段 = 缺口（9 笔 SHORT） |
| **④ 净 edge 扣减** | net_live = net_SIM −（入场不利滑点 + 出场不利滑点 + 借券成本 + 点差跨越） | 由①②③实测合成 | M2 示意 ±10bps→~+12bps 是**占位**；M3 用实测替换 |

**M3 转正门（冻结，转正前必过）**：实测扣减后净 edge **≥0.30%**（C13 地板）∧ 日聚类 **|t|≥2** ∧
**n≥30 前瞻** ∧ 双窗同号。若实测净 <0.30% 或扣减后 ≈0 ⇒ **「EXT 盘前净 edge 是 SIM 乐观伪影」被证实，不转正**。
借券未测的 SHORT 腿单列，不得并入宣称。

**诚实边界**：M3 是**规格非执行**（前瞻数据尚不存在）；采集器加报价/盘口/借券快照字段 = **采集器增强（行为变更）**，
须影子先行 + DEB + 用户批 RFC-149 新窗 + KR4 腾位；**agent 不自动实施**。M3 与 M1 互补：M1 证「财报增量
是否真」（对照①/②），M3 证「净 edge 实盘是否还在」（执行扣减）；两者都过 + 前瞻攒样 + 用户终裁才谈转正。
