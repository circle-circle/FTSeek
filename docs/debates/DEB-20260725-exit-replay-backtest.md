## 三、工具验证 (fidelity anchors)

| 锚点 | 实测 | 判读 |
|---|---|---|
| 回放 MFE vs 记录 mfe_pct | median 差 **0.077%** | bar 峰值追踪忠实 |
| baseline vs 实盘退出价差 | median **0.136%**, p90 1.27% | 可接受 |
| 退出原因一致率 | 51% | 见偏差分解, 非随机 |
| 回放 vs 实盘净额 | +271~+324 (141笔) | **固有乐观偏差 +$1.9/笔**, 变体间共享 → 排序无偏 |

**偏差三分解 (逐笔直查, 无系统性 bug)**:
1. **bar 影线 > 实盘 60s 轮询采样**: 回放峰值≥实盘峰值 → 保本/锁利略早触发。双向案例:
   FCX (实盘TIME_EXIT -2.24% → 回放保本+0.12%) / AVGO (实盘EOD +2.68% → 回放保本+0.12%)。
   **推论: 紧dd/早保本类变体的回放收益是保守低估** (影线过触发惩罚了它们)。
2. 遗留路径不可复现: EXIT_MONITOR_CLOSE / BROKER_GHOST_CLOSE (7/3 前)。
3. 同 bar 内峰谷往返: 由 pess/opt 双序区间覆盖 (baseline 区间宽 $53/141笔)。

**口径纪律**: 结论一律用 **Δbaseline** (同机制变体相减), 不用 Δlive (混入上述偏差)。

## 五、结论 (候选假设, 非行动)

1. **退出调参是二阶杠杆**: 最优变体期望仍负 (-$1.4/笔), 单靠退出翻不正期望 — 与核心诊断一致。
2. **early_tight 的全史巨量收益 (+$1050) 是 6 月 regime 遗产, 近期仅 +$40~78** — 与 live shadow
   (07-20 起采集) 的小额正值互相印证。不支持仅凭本回放实单化。
3. **近期窗口 (n=62≥30, 宪章规则5过) 一致指向"更早保护"**: be_0.3 / dd_0.4 / tiered_0.4
   三变体同方向 (+$130~210/62笔), 且因影线偏差属保守低估。与 07-19 "放宽到 0.8" 处方张力明显
   — 但该处方依据 handoff n=61 实证, 本回放与其实测口径不同 (bar vs 轮询)。**裁决路径**:
   tiered_dd 变体 live shadow 已于 07-25 开始采集, 2 周后双源交叉, 一次一变量。
4. **dd=0.8 处于平台区**: 0.4/0.5/0.8 全史差异 ≤$315/141笔 (≈$2/笔), 非主矛盾。
