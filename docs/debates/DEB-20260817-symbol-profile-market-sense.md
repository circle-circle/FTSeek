## 背景

原始需求：通过记账、复盘、摸股性，对特定股票的持续操作形成个性化认知（"盘感"），
让 LLM 基于股票数据总结出针对性操作计划，并让计划与开盘后实际执行精准匹配。

现状缺口：
1. DA 每次分析一只票都"从零开始"，历史交互记忆零沉淀（第 45 次 QCOM 操作不站在前 44 次肩膀上）。
2. 退出/入场参数全池一套，参数不"认票"（TSM 9 笔止损中 8 笔回到入场价上方，仍用攻击性止损）。
3. 盘前 entry_zone 以昨收锚定，隔夜跳空后计划与开盘实际错位；现有 reanchor（4% 漂移容忍）
   只是宽容放行，不区分"该等回踩"还是"该追延续"。
4. "盘前预测 vs 盘后实际"的计划级误差从未被系统性测量（现有影子测的是滑点/时点，非计划质量）。

已落地（本轮 P0，全部只读、零 LLM、零 live 改动）：

- **L0-A 交互史画像** `scripts/symbol_profile_builder.py` → `data/symbol_profiles/*.json`
  （交互史 = 全引擎闭环交易，含旧引擎；路径行为 = 持仓路径湖分钟数据）
- **L0-B 股性画像** `scripts/market_profile_builder.py` → `data/market_profiles/*.json`
  （110 票 × 5 年日 K，条件切片特征 + 初步票型标签，全池无冷启动）
- 修复四类口径坑（详见 §数据与实证 坑清单）

## 目标

1. 回答：个股画像能否形成可信、可验证、可执行的个性化操作认知？
2. 回答：画像约束（时间窗/方向/出场风格/价格锚）如何在执行层真正落地且与现有门链不冲突？
3. 回答：盘前价格计划与开盘后实际如何匹配得更精准，且"精准度"本身可测量？
4. 交由多 Agent 辩论：本方案是否过拟合、安全边界是否足够、分阶段路线是否成立。

### 口径坑清单（已修复，供后续复用）

1. `source_type LIKE 'PLAYBOOK%'` 过滤会静默丢失旧引擎交易（QCOM 44 笔全在 MAIN_PIPELINE/SCALPING）
2. entry_time 时区三变种（核查轮补全）：a) MAIN_PIPELINE/SCALPING 全部北京时间；
   b) PLAYBOOK_SHADOW 23/23 与 PLAYBOOK_SIM 少数早期行为北京时（如 ORCL SHADOW 2026-06-23 21:31 = ET 09:31）；
   c) 7/8 月后 PLAYBOOK 系为带 -04:00 或 naive ET。当前 builder 的 9-15 点过滤对 b 类是静默排除（无污染有覆盖洞）
3. `pnl_pct` 存小数 vs `mfe_pct` 存百分数（捕获率直接相除差 100 倍）
4. 253 行 mfe_pct=0（旧引擎不回填），中位数必须过滤 >0
5. **regime 集群伪样本**（本 DEB 头号教训）：笔数 ≠ 独立样本数。方向/时点类指纹必须先过
   "distinct 交易日 × regime 分层"检查（同源教训：DEB-long-expectancy §2.10/§十四）
6. 附注：profit_capture=1.0（QCOM/ORCL）疑似 MFE_STALL 类退出 exit≈MFE 的结构性产物，L1 引用前查 exit_reason 构成；
   L0-B 日 K 窗口止于 2026-07-24，"近20日"指标均为 7/24 视角；"110 票×5 年"表述过强（MIN_BARS=120 允许半年票）

## 可选方案

### 方案 A：完整画像系统（L0→L1→DSL→双层门→锚定改造）

- 提出者：主线 Agent（本轮）
- 核心思路：五层递进，全部复用现有机制，零新执行路径
  1. **L0**（已落地）：交互史 + 股性，纯代码
  2. **L1 认知卡**：LLM 读 L0-A+L0-B，产出带 evidence 的条件化认知（`time_rhythm/drawdown_habit/gap_behavior/avoid/prefer`），schema 强校验，留出样本验证（前 70% 归纳、后 30% 验证）
  3. **DSL**：认知卡编译成有限枚举规则（`entry_window/gap_no_chase/direction_bias/min_extra_evidence/exit_profile_hint`），参数硬夹逼，LLM 不能发明类型或出价格数字（Track A 延伸）
  4. **执行双层**：软层 = 认知卡注入 DA prompt（计划生成时少产废单）；硬层 = profile gate（与 VWAP 门同构，按 symbol 查表，白名单制：无画像票零开销直通），shadow 模式陪跑 → 反事实对账达标 → 逐条转 live
  5. **锚定匹配**（见下）
- 优点：个性化白名单制零侵入；每条规则可溯源可回滚；影子先行与 VWAP 门路径完全一致
- 缺点：链路长（五层），L1 质量依赖 LLM；票型标签区分度未证实；小样本票的画像可能过拟合
- 适用条件：样本门槛（建议 ≥15 笔闭环或 ≥250 根日 K）；路径湖窗口继续积累

### 方案 B：仅软注入（不建 gate，只注入 DA prompt）

- 核心思路：只做 L0+L1，认知卡作为 context 注入 DA，靠 prompt 约束行为
- 优点：实施快，改动仅 prompt 层
- 缺点：**不可审计**——DA 是否照做无法保证（参考校准实证：信心未校准 U 型，prompt 约束的服从性未经验证）；持续产出注定被"应当拦截"的信号
- 适用条件：仅作为方案 A 的第一阶段，不应作为终态

### 方案 C：维持画像现状，只做盘前锚定匹配改造

- 核心思路：不做画像系统，仅落地"开盘区间重锚 + 计划质量报告"
- 优点：最小改动，直接回应"计划-实际匹配"痛点
- 缺点：锚定策略全池一套，不认票（gap_filler 型该等回踩、延续型该追，同一规则必错一半）；错失记忆复利
- 适用条件：若辩论裁定画像过拟合风险不可接受，退守此方案

### 盘前价格锚定匹配设计（方案 A/C 共用，独立可裁）

现状：盘前 entry_zone 昨收锚 → 隔夜跳空后错位 → reanchor 4% 宽容忍（不区分语义）。

- **A1 开盘区间重锚（gap-adaptive anchor）**：09:30-09:35 开盘中枢替代昨收锚，
  entry_zone/SL/TP 整体平移（`opening_range_ready` 特征已存在于 entry_timing_shadow）。
  **核查轮补充的交互约束（必须显式声明短路顺序）**：pipeline.py:4530-4548 还有
  thesis_drift_invalidate（漂移超限指令永久作废）与 extreme_gap>8% 拦截——重锚必须
  排在这两个机制**之后**判定（先判作废、再谈重锚），并继承 7/20 确立的不变式
  "质量门拦截不可被重锚绕过"（量能门/VWAP门同理）
- **A2 计划质量报告（plan-vs-actual）**：盘后用路径湖分钟数据计算——计划带中点 vs 实际
  最优入场点偏差、带触达率、假触达率（触达即反转）、SL/TP 相对日内高低点几何误差。
  把"预测准不准"从感觉变成每日指标。
  **核查轮裁定：全案价值/风险比最高——纯测量、零行为改变、直接回应痛点#4，
  无论画像辩论结果如何，从 P3 提级为 P1 独立先行**
- **A3 画像驱动跳空语义**：gap_filler 票小缺口 → 等回踩（昨收/日内 VWAP）；大缺口或延续型 →
  重锚追。画像决定"等 vs 追"的**语义**，reanchor 决定"漂移容忍"的**数值**，两者正交。
  **核查轮裁定：依赖的 gap_filler 标签已实证零区分度（基率 74.5%），本条冻结至标签池内
  相对化整改完成并通过留出验证后重启**
- **A4 全部先 observe**：影子记录"若重锚生效 entry 会是多少 vs 实际"，测量改善量再转 live

## 关键分歧（请辩论 Agent 重点攻击）

1. **小样本个性 vs 过拟合**：QCOM SHORT 胜率 0.244 (n=41) 统计显著，但 ORCL LONG 0/6、
   TSM 时段桶差异均不显著。画像规则的最小样本门槛该设多少？不显著但方向一致的线索是否有条件放行（如仅 shadow）？
   - 可验证方式：对每条候选规则做 70/30 留出验证 + 与全池基线对比（该规则是否只在个股上成立 vs 全池都成立）
2. **regime 混杂**：QCOM 41 笔 SHORT 是否集中于逼空段？TSM 假止损率 0.889 基于仅 3 周路径窗口，
   可能是 regime 产物而非股性。
   - 可验证方式：QCOM SHORT 按月分布检查；路径特征随窗口延长的稳定性跟踪
3. **票型标签区分度**：四只样本票全标 gap_filler，全池 0 平庸票（阈值 0.08 过低）。
   票型归纳是否伪命题（美股日 K 普遍高回补）？
   - 可验证方式：全池 gap_filler 占比 + 标签对留出样本规则的增益检验
4. **DSL 表达力 vs 参数冻结纪律**：画像规则（如 exit_profile_hint）是否构成对冻结参数的
   间接调优通道，绕过既有参数治理纪律？
5. **跳空重锚与现有门链冲突**：A1/A3 与 reanchor 4%、量能门、VWAP 门的交互顺序与短路关系？
6. **prompt 注入污染**：认知卡注入 DA prompt 是否影响 confidence 口径（校准实证：信心未校准，
   50-65% 桶胜率最低 17.1%）？注入内容是否必须显式标注"参考信息非评分依据"？
7. **股性漂移检测**：什么信号判定画像 stale（最近 N 笔与画像背离？票型标签翻转？）？
   失效后是降级到票型先验还是完全清除？

## 决策

- 选择方案：**方向采纳方案 A 骨架 + 核查轮整改**（2026-08-17 第 1 轮辩论后）：
  1. L0 保留（数据资产无争议），但所有个股级结论降级为"线索"，直到满足新门槛
  2. **样本门槛改章**：distinct 交易日 ≥N 且跨 ≥2 个 regime，替代纯笔数门槛；
     不满足的票（含 QCOM）只能产出全池级规则（"别逆月度动量做空"是市场规则，非股性）
  3. **留出验证改按日期切分**（70%/30% 天数），严禁按笔切分（同日多笔高度相关，QCOM 5/7 单日 19 笔即反例）
  4. **A2 提级 P1 独立先行**（纯测量零风险）；A3 冻结待票型标签池内相对化整改
  5. gap_filler 标签废除绝对阈值 0.55，改池内 z-score/分位相对化
- 决策依据：核查 Agent 三项关键指控（regime 集群、标签零区分度、时区第三变种）经主线
  独立复验全部属实（复验命令与结果见讨论记录第 2 轮）
- 保留空间：票型概念本身未死（死于绝对阈值而非概念）；A2 先行的测量结果可为票型相对化
  提供更干净的因变量
- 负责人：主线 Agent（落地）/ 核查 Agent（已出第 1 轮）/ 待续轮辩论
- 截止时间：A2 落地 + 票型相对化整改完成后进入下一轮辩论
