## 一、问题界定

五周窗按入场价分三层后，净期望呈**强分层**：≥$100 层独赚、<$100 两层全亏（一层亏在
信号毛额、一层亏在费用）。9/17 最低价门只堵了 <$5 仙股费洞，$5–20 带仍付 2–5 倍费率。
本 DEB 提问：**价格分层差是真实的供给质量轴，还是板块/时段/regime 混淆产物？**
答案只靠前向只读攒样，不动任何供给。

## 三、与 C8 的边界论证（本 DEB 最关键的反方问题）

C8 封的是**「以盘前跌幅/bear 强度/大盘 regime 否决方向信号」**；本 DEB 的轴是
**入场价×费用/毛期望**，与方向无关（同一 DA 信号在高低价层的方向准确率同测）。
先例支持：EXT_ENTRY_MIN_PRICE 本身就是价格轴供给门且已裁生效。**但**：若影子毕业
后提"供给配额"，其本质是软否决——届时必须另立 DEB + 用户裁 + 知情破例记录，本 DEB
不预支该结论。

## 四、影子设计（裁决后落地，每晚只读）

1. **分层**：<$5 / $5–20 / $20–100 / ≥$100 四层（$5 边界对齐既有 min-price 门）。
2. **每层周结算**：n、net、毛、费、net_bps、gross_bps、fee_bps（分母口径与 §二一致，
   单位=百分比×10000）。
3. **混淆控制强制列**：①周序（时间）②Top-3 符号净额占比（符号集中度）③方向构成
   （LONG/SHORT）④metadata regime 字段缺则如实标 `regime_unavailable`——**不许静默
   省略混淆列**（metadata 无 sector，板块混淆登记为已知未控项）。
4. **前向窗纪律**：判据只认 **10/1 起**的新增样本（§二历史窗只作立项动机，防同一批
   数据双花）。

## 五、反方观点

| # | 反方论据 | 回应 | 残余风险 |
|---|---|---|---|
| R1 | 分层差可能是板块混淆（≥$100 层=NVDA/AVGO 等科技权重） | 符号集中度列强制报告；无 sector 字段，登记为未控项 | 高 |
| R2 | 9 月上行期幸存偏差（高价科技股 beta 受益） | 前向窗跨 10 月验证；周序分层看持续性 | 中 |
| R3 | $20–100 层负毛利主要是 pre-9/17 旧样本（post 仅 5 笔 +$156） | 前向窗重新攒，不引用旧窗进判据 | 中 |
| R4 | C8 边界滑坡：配额=软否决 | §三正面论证 + 毕业后另立 DEB + 用户裁 | 低（治理设计内） |
| R5 | bps 口径混装风险（军规四案教训） | 分母、单位、$5 边界全部预注册写死（§四） | 低 |

## 六、预注册判据（前向窗 10/1 起，死线 2026-12-31）

```
supply_price_tier 影子毕业门 (仅前向窗, 周分层):
  ≥$100 层: n≥100 ∧ net_bps 按日/周聚类中位 > 0 ∧ MDE(80%) 报告
  ∧ ($5–100 合并层: n≥40 ∧ net_bps < 0 持续 ≥3 个独立周)
  ∧ Top-3 符号净额占比 < 50% (排除单一符号驱动)
  → 另立 DEB 提请供给配额方案 (用户裁, 影子不自动生效)
  否则维持现状结题 (分层差=混淆产物, 不动供给)。
禁改: 四层边界 / bps 分母 / 前向窗起点 — 改=重裁。
```

## 附：可复现命令

```bash
sqlite3 -header -column "file:data/ftseek_us.db?mode=ro" "
SELECT CASE WHEN entry_price<20 THEN 'a_<20' WHEN entry_price<100 THEN 'b_20-100'
ELSE 'c_>=100' END tier, COUNT(*) n, ROUND(SUM(pnl_net),2) net,
ROUND(SUM(realized_pnl),2) gross, ROUND(SUM(fees_est),2) fees,
ROUND(AVG(fees_est/(entry_price*quantity)*10000),2) fee_bps,
ROUND(AVG(realized_pnl/(entry_price*quantity)*10000),2) gross_bps
FROM trade_records WHERE date(entry_time)>='2026-08-25' AND exit_time IS NOT NULL
AND pnl_net IS NOT NULL GROUP BY tier ORDER BY tier;"
```
