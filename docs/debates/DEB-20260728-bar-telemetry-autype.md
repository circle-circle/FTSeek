## 二、F1 (实锤): bar 版峰谷遥测双重失真

`app/playbook/pipeline.py:4572-4640` (07-20 上线的 record-only "候补尺子", 用于周度对比
bar vs quote 后决定是否把 MFE 输入切换到 bar 版)。**实测这把候补尺子自身是断的**:

### 失真① — 分钟标签 off-by-one (口径错误)

- **铁证链**: SOLS 真实成交 09:35:54 @ **60.882**; 落库 peak_price_bar = **60.82** (低于成交价,
  物理不可能)。直拉 futu 真值 (AuType.NONE, 07-28 晨): bar `09:36` H=**60.882** = 成交价逐分吻合,
  bar `09:35` H=60.82。**即 futu K_1M time_key 是分钟末标签** (bar "09:36" 覆盖 09:35:00-09:35:59)。
- 代码 `_entry_key = entry.strftime("%H:%M:00")` (09:35:00) + 过滤 `_t < _entry_key` 按分钟首标签
  假设 → **把整个入场前一分钟 (真 09:34 窗) 算了进来**: trough_price_bar=60.777 正是入场前低点。
  头注释 "入场分钟的 bar 含入场前 tick, 可接受" 是基于首标签假设的误判 — 实际是整分钟错位。
- SLB 同款签名: bar 峰值 52.83 < 真实出场 52.84 (不可能), 两标的交叉确认。

### 失真② — 配额冻结 (静默降级)

- bar 峰值停在第一根 (60.82), 真实峰值 **61.695 (09:43 bar)** 全程未采到。
- 机制: 内存缓存 60s TTL → push 缓存 (持仓标的未订阅) → HTTP 配额门 `_wait_kline_quota`,
  开盘高波动期 10 仓 × 30s 轮询打爆配额 → `get_kline` 走 "配额满返回已有缓存(哪怕不足)"
  → **单调更新逻辑 (_new_pk > _old_pk) 把第一根的值永久锁死**, 无任何告警。
- 与静默退化族同款: 降级路径无声, 表面有数据。

### 危害定性

bar 版是**指定用来校准 quote 尺的尺子**: 若直接对比, 会系统性误判 "quote 尺高估 MFE"
(实际 quote 尺本次准确); 若周度对比据此裁决切换, 断尺上位直接污染退出决策输入。
且 07-20 起案的原始论据 ("MFE 1.48% 仅捕获一半") 也需在此口径修复后重估。

### 修法提案 (F1)

1. 标签对齐: `_entry_key` 按末标签口径 +1min (或过滤改 `>`), 消除入场前分钟混入;
2. 覆盖可观测: 落 metadata 时带 `bar_covered_until` (本次最大 bar time_key), 判分端可知冻结;
3. 冻结告警: 连续 N 轮 (如 5) bar 时间戳不前进 → WARNING 一次 (合静默退化军规);
4. (可选) 持仓标的进 push 订阅清单, 根除配额依赖。

## 三、F2 (潜伏): 复权口径三处不一致

futu `request_history_kline` **缺省 autype=QFQ (前复权)**, 而成交记录是原始价:

| 消费面 | 现状 | 风险 |
|---|---|---|
| `scripts/exit_replay_backtest.py:170` (L1 退出回放) | 未指定 → QFQ | 分红股在 交易日↔回放日 跨除息 → bar 移位 ~0.3-0.5%, 与原始成交错位, MFE/MAE/反事实结果带偏 |
| `scripts/entry_gate_replay.py` (L2) / `historical_robustness_check.py` (L3) | 未指定 → QFQ | L2 同 L1 风险; **L3 五年日K反而应该用 QFQ** (连续性), 写明即可 |
| `futu_lv3_provider.get_kline` (bar 遥测+技术指标) | 未指定 → QFQ | 与 quote/成交原始价混用, 除息日附近指标跳变 |
| `scripts/backfill_forward_returns.py` (fwd_return 判分锚) | **三路混用**: Futu K_DAY(QFQ) / backtest_cache CSV(原始) / TwelveData(原始?) | **同一台账不同指令尺子不同** — 分红股 fwd 收益是否含除息跳空取决于哪路供数, 切片判分被隐形分层 |

**修法提案 (F2)**: L1/L2 对齐原始成交 `autype=AuType.NONE`; L3 显式 QFQ + 注释说明;
fwd_return 统一口径 (建议: 全链路原始收盘, 除息影响作为已知噪声入判分指引, 或全 QFQ — 二选一, 关键是**单一**);
provider get_kline 显式化 autype 并落文档。
