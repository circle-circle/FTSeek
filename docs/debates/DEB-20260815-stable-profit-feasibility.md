## 三、天花板算术 (本 DEB 的核心)

**命题**: 即使入场门禁达到理想水平, 当前架构的收益天花板是**打平**, 不是盈利。

```
现状:          净 -2,147 (死胎 -4,161 + 存活 +2,014)
理想上界:      门禁拦下 50% 死胎且不杀任何赢家
              → -2,147 + 4,161×0.5 = -67  ≈ 零
```

推论:
1. **事后干预路径已死** (§2.3): 死胎亏损大头发生在识别之前, 早退只能捕获 ~14%。唯一可行的是**事前过滤**。
2. 事前过滤的期望收益 = 拦截的死胎亏损 − 误杀的赢家收益。按 2.2 均笔粗算: 拦 1 笔死胎省 $45, 误杀 1 笔赢家损 $12——**误杀率必须 <79% 才有正期望, 而要产生有意义的收益, 误杀率必须压到 30% 以下**。这是裁决器"误杀检查"判据的定量来源。
3. 费用是第二出血口: 频率减半机械性省 ~$600/7周, 不需要任何预测力。质量优先降频 (只做 gate 优质档) 同时改善死胎率与费用。
