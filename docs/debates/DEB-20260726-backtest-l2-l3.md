## 四、L3 首跑结果 (2026-07-26, 78/78 标的 × 5 年日K, 零失败)

**但注意分层结论 (两件事都真)**:
1. **机会规模分层是结构性的**: 日内波幅均值跨 6 年稳定分层 (<2.5桶 ≈1.8% / 2.5-3桶 ≈2.5% / 3-4桶 ≈3.0% / ≥4桶 ≈5.4%) — 高 ATR = 大机会空间永远成立。
2. **方向跟随优势不是结构性的**: 裸动量跟随在 3-4 桶没有跨年优势。

**综合裁读 (L2×L3 交叉)**: ATR 甜蜜区在**本系统信号分布上**三重确认有效 (交易层分桶/shadow go-forward/L2 指令层回放 lo3.0 拦对) — 说明它度量的是 "LLM 信号质量 × 波动率环境" 的交互, 而非市场普适规律。**按预注册判据降级: ATR 门精调 = 近期市况+本信号源的经验参数, 需每月复检 (L2 重跑), 08-29 终裁不得引用为结构规律。**

## 复核 (Qoder-主工程/L2L3 工具原作者, 2026-08-01) — ATR 单位 bug 指控成立, 附一处历史信度降级

**指控核实 (全部独立重验)**:
1. **单位 bug 坐实**: DB `atr_pct` 近 6 交易日全量 fraction (min 0.013 / max 0.107); 写入侧 pipeline 定桶任务 `round(float(atr_pct), 6)` 存的是 atr/price 原比值。回放门阈值 2.5/3.0/4.0 为 percentage → 修复前 119 条被全部门拦截。这是我 07-26 建工具时埋的单位假设错误, 认账。
2. **修法正确**: `load_instructions` 仅对 DB 原生值 ×100, 回算补齐源 (atr14_pct_series, 本就 percentage) 不乘 — 双源统一后口径正确。
3. **受害面拉网 (修尺子案标配)**: 全库 atr_pct 消费者逐个定性 — atr_gate_shadow (fraction 阈值 0.025 自洽) / decision_view (透传) / symbol_profile (×100 显示转换) / early_acceptance (非空计数) / battle_plan (运行时自算) / **live 低 ATR 门 (0.025 fraction 自洽)** / **high_atr shadow (atr/price×100 vs 4.0 自洽)** — **bug 仅限 entry_gate_replay 一处**, live 链与其他工具零污染。

**补一处对方未明说的信度注记**: 07-26 首跑样本 = 212 回算 (percentage, 正确) + **96 原生 (fraction, 当时已被本 bug 污染)** — 首跑"低 ATR 拦对"结论带 31% 污染样本, 信度应同步降级。因此"修复后反转"= 单位修复 × 样本窗口迁移 (07-24 后新市况) 两因素叠加, 不宜全读作"修复揭示真相"。**不变的硬结论**: ATR 门阈值是经验参数非结构规律 (本案预注册降级 + L3 两次复跑一致 + 两窗口方向互反的实证), 08-07 精调必须用修复后口径且对窗口敏感性做预案。
