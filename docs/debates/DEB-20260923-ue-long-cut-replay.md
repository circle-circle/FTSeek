## 2. 为什么不能落地（三条独立否证）

1. **均值由尾部主导，不是"系统性烂单"（T18）**: 中位 **+0.200$**、胜率 51% ⇒ 超过一半的单不亏；
   −521.70$ 主要是 3-5 笔大亏（QCOM −227.50 / USAR −158.05 / UBER −99.37 / PCG −74.67 / HPE −153.95…）扛下来的。
   砍这一类，砍的不是"特征群体"，是**尾部实现**。
2. **安慰剂 87.5 分位（T4/Gate4）**: 逐日配对随机砍**同样数量**的非 UE-LONG 单，有 87.5% 的重抽样能得到
   与真规则相当、甚至更大的 ΔB（CI97.5 = +788 > 真 +579）⇒ 规则**不特异**，改善来自"砍任意负尾"而非"UE LONG"这个轴。
3. **误杀比节省更贵（T17）**: 51% 被砍单是盈利单，其净利合计 **+822.17$ 超过留存池总净 +556.19$（1.48×）**
   ⇒ 砍掉的是利润引擎的一大块；净改善只在"合计口径"下成立。
4. 附加 **T17 残差衰减**: 9/5（上游禁追高/相关门落地）之后 UE LONG 转正（+6.205$/笔，n=12，仍是小样本）
   ⇒ 早期负值很可能已被上游吃掉，"现在再禁"的边际价值更薄。

## 3. 与前后两份记录的关系（防下游混引）

- §2.5 的「UE 源 90 天净 −285.03$」是**实测事实**，仍然成立；但**推论**「该来源只配做空」被本回放**修正**：
  UE LONG 的负值在成交层是尾部现象，不构成禁入理由（禁入经 5/8 门否证）。
- **影子层（候选层）的负 alpha（t −3.91/−3.28）与成交层的负期望不是同一命题**：影子测的是全部浮现候选的前瞻，
  成交层只看到**已通过现役入场栈**的子集 —— 现役过滤栈可能已把负 alpha 人群筛成了"中位为正、尾部为负"的残留
  （T14/T17 同族）。两层读数不得互相冒充。
- **"启用 SHORT" 本身不是待办**: UE SHORT 侧本来就在跑（n=31 笔已成交），且其 +7.635$/笔 **t=0.66 不显著（n<40）**
  ⇒ 现状已是"SHORT 可做"，没有需要"启用"的开关；同理也没有数据支持"SHORT 更优"。
