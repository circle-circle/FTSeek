## 2. 独立复算读数 (落地后实跑, 非引用前序 turn 的汇总)

### 2.1 段9 edge 门反事实 (口径: 键 = 唯一 (symbol, ET日); 笔数 = 该键 `trade_records` 行数)

| 窗口 | BLOCK 笔均 (n) | PASS 笔均 (n) | 差 | 读数 |
|------|---------------|--------------|-----|------|
| 近 7 天 | **+7.60$** (n=14) | **+8.28$** (n=24) | −0.68$ | BLOCK 更低 = 门在筛更差的单 |
| 近 30 天 | **+20.89$** (n=46) | **−0.83$** (n=136) | +21.72$ | BLOCK 更高 = 门拦的是更赚的单 |

⇒ **两窗方向相反 ⇒ edge 门对该拦的单无稳定区分力, 数据不支持实装**。
被替换的旧文案 (行尾硬写 `(BLOCK笔均≥PASS=门在筛更差的单)`) 是 8/26 那次读数的快照, 与现读数反向 —— 这类"结论写死在格式化字符串里"的读数会让裁决走反, 已改为一律由本窗实数推导。

口径更正附带: 旧实现按**候选行**逐行 join, 同 (symbol,ET日) 多候选行会把同一 `trade_records` 组重复计入 (30d PASS 被虚增到 154 笔, 实为 136 笔)。现按唯一键计一次, n 一并印出。

`SL 一致 64% 分歧中位 0.13% | TP 一致 72% 分歧中位 0.13%` (容差 SL 0.2% / TP 0.3%)
