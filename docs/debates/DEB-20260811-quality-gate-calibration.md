## 一、核心主张（两个观察点，均为实测发现，非推测）

**观察点 A：gate quality_score 当日与实际盈亏完美负相关（n=3，方向警示）**

gate 的 quality_score（0-100 综合分）是决定仓位档位（normal/tiny）与放行的核心输入。
8/10 执行的 3 笔里，score 与实际净 PnL 排序完全相反：

| 标的 | quality_score | 档位 | 当日净 PnL | 结果 |
|---|---|---|---|---|
| US.CRM | **15**（执行组最低） | tiny | **+$93.51** | 当日最大赢家 |
| US.TSM | 30 | tiny | +$19.68 | 盈利 |
| US.GS | **45**（执行组最高） | tiny | **-$21.90** | 唯一亏损 |

这与 DEB-20260808 已确认的"LLM 分析分（x/10）无区分度"是**两套不同的分数**：
- LLM 分析分（x/10，reasons 里的"分析结论排序"）：8/7 已确认 IC≈-0.02（n=242），Fisher p≈0.3
- gate quality_score（0-100，综合 RR/pattern/历史/溯源）：本次首次拿到日内配对样本，方向为负

**若两套分数都无预测力，则质量门当前的"质量"测量本身失效**——gate 在做无信息量的分档。

**观察点 B：LLM 论据数字大面积无法溯源，30/30 份分析全部命中幻觉警告**

8/10 全部 30 份 gate 决策的 reasons 均含"来源验证: N个数字未在输入数据中溯源 (幻觉风险)"：

| 统计 | 数值 |

| 命中幻觉警告的分析数 | **30/30（100%）** |
| 未溯源数字总数 | ≈1083 个 |
| 平均/份 | ≈36 个 |
| 区间 | 19（PLTR）~ 58（SNDK） |

当前该警告**只记录、不拦截、不降权**。风险路径：编造的财报/目标价数字 → 推高分析分 →
影响 quality_score 与仓位档位 → 真实亏损。8/10 尚未出现"幻觉论据→实亏"的配对实例
（GS 亏损归因是 DEAD_SIGNAL 方向未兑现，非论据错误），但防线缺位是结构性事实。

## 四、辩论点（供对抗模型攻击/辩护）

1. **score 重构方向之争**：
   - 方案α：gate score 只保留可验证成分（历史 WR/pattern/claim-IC/RR），删除 LLM 自评分
   - 方案β：保留 LLM 分但强制 rubric 化（每个维度给锚定样本），重建后验证 IC>0 再进门禁
   - 方案γ（做减法）：score 降级为纯记录字段，分档只按波动率桶 + 历史 WR，等 rubric 成熟
   - 反方必须回答：n=3 的 ρ=-1.0 是否足以行动？还是统计噪声？（8/7 教训：短窗口命中率骗人）
2. **LLY 型错失是否要右侧补位机制**：唯一 PASS 级机会因 runaway_up 全程无回踩入场点而错过
   （+$242）。"突破追买"与现行"不追涨"哲学直接冲突——引入需给出追涨组的历史 WR 证据，
   否则继续 shadow 攒样（预注册：runaway 组样本 ≥30 后裁决）。
3. **幻觉拦截的度**：100% 分析命中溯源警告 → 若直接拦截等于关闭 DA 管线。
   - 最小实验：对"未溯源数字 > 中位数"的半区 vs 低半区，对比后续盈亏（B-1）
   - 反方质询：溯源失败是否只是"输入数据未包含该数字"（如 LLM 引用了盘前新闻而溯源器只看结构化输入）——即警告本身可能是测量工具缺陷而非 LLM 幻觉？需先审计溯源器的覆盖率再定性。
4. **溯源器可信度**（对观察点 B 的元质疑）：30/30 全中的警告，更像检测器召回过宽，
   而非 LLM 集体幻觉。先修测量，再谈拦截。

## 六、O5 审计结果与修复记录（2026-08-11 深度检查，立案当日闭环）

### 6.1 结论：不是 LLM 集体幻觉，是溯源器口径性错配（误报率 ≈100%）

溯源链路在 `llm_synth.py`：prompt 注入"论据溯源清单"→ LLM 输出后
`_verify_sourced_numbers()` 把 bull/bear/constraints 里的数字逐一比对白名单。

**三个结构性错配（代码审计实锤）**：

1. **白名单只覆盖输入的 4/12 类数据**：LLM 实际收到 snapshot、K线、资金流、
   技术异动、**新闻10条、研报5条、社区帖子、行业peer、大盘SPY/QQQ/VIX、财报日历、
   板块上下文、内部人**共 12 类；验证器白名单（L944-967）只提取
   snapshot/fundamentals/insider_sentiment/analyst_consensus 4 个 dict 的数字
   → LLM 引用其余 8 类输入的任何数字必判"未溯源"。**这是 30/30 全中的机制性解释。**
2. **派生算术判为编造**：均值/比率/单位换算（$89.01M←89010000、2.5倍←21.37/8.54）
   字面不存在于输入 → 判幻觉。
3. **验证器自我矛盾**：execution_plan（入场/止损/止盈价）不检查（设计者知道是派生值），
   但 bull_case 里同样的派生逻辑却在被检查。
