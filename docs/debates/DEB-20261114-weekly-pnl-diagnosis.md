## 4. 可选方案（治理合规；均不含已关闭轴）

### 方案 A（推荐）— 纪律路径：裁决/结算 + 守住红线，不加门
- 核心：按 OKR KR4 做**每周一次批量裁决** + 过期观测项当日结算入注册表；把本周读数按 A9 双口径 + 日聚类 CI/MDE 如实归档；**不新增门、不改阈值、不取消隔夜**。
- 优点：零行为风险、完全合规；直接服务主 KR（DA-only 净 bps>0）的证据积累；避免「再加第 95 个影子」。
- 缺点：不产生「立即减亏」的动作（但本周本就无统计可分辨的失血，且朴素修法已全禁）。
- 适用：当前默认。

### 方案 B — 修复唯一开放数据源：EXT 财报判据影子恢复（须用户裁 + 先修 429）
- 核心：按 DEB-20261023 把 surprise 主源迁富途日历 `eps_actual`（或 legacy 臂加 (票,日) 缓存 + ≤50/分令牌桶），恢复 `ext_entry_earnings_criterion_shadow` 写方，攒 EXT 成交至 n≥20 再按 RFC-097 预注册判据裁。
- 优点：直击 NVDA 型「盘后动量追高、无财报数据可滤」的左尾；是注册表内**唯一未关闭**的同轴杠杆。
- 缺点：属行为相邻变更（重启写方），须先解 429、须用户批准；样本门 5<20 短期不可裁；**不承诺收益**。
- 适用：用户愿意推进「补数据面」时；仍走影子先行，不自动转硬闸。

### 方案 C — 维持现状继续攒样（不作为）
