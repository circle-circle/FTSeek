# DEB-20260930 — 财报前后方向性规律回放裁决（先涨后跌 / 先跌后涨）

> 缘起：用户问"财报期前后或当天有无先涨后跌/先跌后涨规律，可否基于历史数据做多或做空"。
> 方法：按用户 8/14 方法论（历史可回放 → **直接回测裁决**，不默认攒样）+ backtest-rule-replay 四关门+安慰剂。
> 结论：**用户的两个形态假设全部证伪；挖到的"过门"臂经决定性对照证明与财报无关**。
> 数据：富途财报日历 65,441 事件 / 4,489 票（2022-01~2026-09）+ 521 只市值≥10B 票日K + SPY 基准。
> 状态：**已裁决，不落地**。脚本 `/root/.hermes/cache/scratch/earnings_dir_*.py`（只读回放，零生产改动）。

## 一、命题拆解（T16：口语命题必须先拆再回放）

用户的一段话含 5 条独立可测命题，逐条定事件与出场窗：

| 编号 | 命题 | 事件定义 | 出场 |
|---|---|---|---|
| P-A | 财报前存在漂移 | pre5 = D-5收→D-1收（入场前可知） | 描述 |
| P-B | surprise 决定反应日方向 | EPS surprise 分组 → 反应日 | d0 |
| P-C | PEAD 盈余公告后漂移 | surprise 分组 → 持5日 | d5 |
| **P-D** | **先涨后跌**（用户假设①） | pre5≥+2% → 反应日**做空** | d0/d1 |
| **P-E** | **先跌后涨**（用户假设②） | pre5≤−2% → 反应日**做多** | d0/d1/d5 |

**可实现时点（防 T1/T9 前视）**：相位决定入场日 —
BMO（盘前发）→ surprise 于 D 日盘前已知 → 入场 = **D 日开盘**；
AMC（盘后发）→ 入场 = **D+1 日开盘**。pre5 条件两相位都在入场前可知。
出口一律从**入场开盘价**计价（不用收盘价近似），扣往返费 20bps。

判据（预注册，读数前锁定）：n≥40 ∧ 日聚类|t|≥2.0 ∧ IS/OOS 同号 ∧ 方向敏感安慰剂 pct≥97.5 ∧ **净 mean≥+0.30%**（多头要 mean≥+floor，空头要 short_ret≥+floor）。

## 三、意外发现：两条"过五关"的臂 —— 但都被决定性对照击穿

扩池后 **E1b** 与 **C1** 表面上全过五关。这正是 backtest-rule-replay T8/T13-2 要防的形状，逐条剥离：

### 3.1 C1 PEAD（小超 0~5% 做多持5日）—— 增量低于地板

| 检验 | 读数 |
|---|---|
| n / 净 mean / median | 893 / **+0.865%** / +0.774% |
| 日聚类 t | **+3.88**（过） |
| IS/OOS | +1.203% / +0.579% 同号（过） |
| 安慰剂 pct | 99.2%（过） |
| T18 尾部 | 剔最强3票 +0.711% 同号；剔最强单日 +0.813%（稳健） |
| 逐年 | 5/5 年全正（2022 +1.33 → 2026 +0.74） |
| 相位分层 | BMO +0.864% / AMC +0.866%（两相位都有） |
| 持有窗单调 | d0 −0.038% → d1 +0.142% → d5 +0.865%（符合漂移累积机制） |

**但三层基线剥离（决定性）**：

```
① 全部财报事件 无条件基线 d5      = +0.649%  (n=7,183)
② 同基线市场调整后(SPY)           = +0.069%   ⇒ 市场漂移占 +0.580pp
③ C1 raw = +0.865% | 市场调整 = +0.317%

★ C1 相对无条件基线的增量 = 0.865 − 0.649 = +0.216pp
★ 市场调整后增量          = 0.317 − 0.069 = +0.248pp
★ 效应量地板 0.30% ⇒ 不过
```

**surprise 全网格 d5：8/8 档全部为正**（大miss<−10% +0.433%、−5~0% +0.788%、0~2% +0.977%、5~10% +0.400%、>25% +1.010%），**无单调性**；按"增量 vs 基线"算只有 2/8 档过地板，且不是相邻档（0~2% 与 >25%）⇒ **T13-2 判定：d5 的正收益是"财报日买入持5日"的无条件市场漂移，surprise 轴不是驱动因子**。C1 的"过门"是把基线当成了自己的 alpha。

### 3.2 E1b（pre5≤−2% 做多持5日）—— 与财报无关，是通用均值回归

E1b 过五关（n=1,733、+0.990%、日聚类 t=+2.60、IS/OOS 同号、安慰剂 98.3%、剔3票 +0.851% 同号），增量 vs 无条件基线 **+0.341pp 过地板**。所以做了最后一刀决定性对照：**同票池、同 pre5≤−2% 条件、同 d5 出口，但取非财报日**（排除财报日±6 日）：

| 组 | n | 净 mean | 日聚类 t | 市场调整后 |
|---|---|---|---|---|
| 财报日 E1b（事件组） | 1,733 | +0.990% | +2.60 | +0.248% |
| **非财报日（对照组）** | **130,265** | **+0.489%** | +4.15 | **+0.165%** |

```
★ 财报日 − 非财报日 增量 = 0.990 − 0.489 = +0.501pp (raw)
★ 市场调整后增量          = 0.248 − 0.165 = +0.083pp   ⇒ 噪声级
```

**⇒ 对照组自己就有 +0.489%（n=13 万，日聚类 t=+4.15）。"跌多了买入持5日"在任何日子都赚钱，财报只额外贡献 +0.083pp（市场调整后）。用户的"财报规律"命题在这一臂上同样证伪 —— 它量到的是通用均值回归，不是财报效应。**

（若仍想做这条通用均值回归，它是**另一个命题**，须独立预注册、独立裁决，且 +0.165% 市场调整净收益已低于 0.30% 地板；另注意它需持 5 日，与系统现役 0.70h 中位持有的追踪锁利利润引擎结构冲突 — T21"与现役退出结构互斥"。）

## 四、AMC 假信号的教训（T18 尾部诊断救了一次误判）

16 票池那轮，`AMC（盘后发）做多 d0` 出现 t=−2.16、安慰剂 **pct_rank=0.0%**、IS/OOS 同号 [−1,−1] —— 看着像"做空 AMC 有肉"的强信号。T18 尾部诊断击穿它：

```
AMC n=351  d0 mean=−0.349%  Σ=−122.4
逐票最负3: US.MU −1.263%(n30) / US.LCID −1.079%(n19) / US.META −0.949%(n31)
最负3票贡献 Σ 的 77% → 剔除后 mean = −0.107% (归零)
做空净 = +0.149% < 0.30% 地板
```

**⇒ `pct_rank=0.0%` 只说明"做多显著跑输随机入场"，不等于"做空可交易"。** 尾部单票主导的桶均值不得单独作判据（T18），且扩池后 AMC/BMO 分层差异消失（BMO +0.143% / AMC −0.549% d0 在 521 票池上不再是同一形状）。

## 五、数据基建结论（T0/T5补2：这三条决定同类研究未来怎么做）

### 5.1 富途财报日历有 7 年历史，不受配额限制 —— **这是本轮最大收获**

`ctx.get_earnings_calendar(market="US", begin_date=..., end_date=...)` 实测可拉到 **2019 年**（203 条/周），字段含 `eps_actual`/`eps_predict`/`pub_type`(BEFORE/AFTER)/`market_cap`/`price`/`iv`/`iv_rank`/`period_text`/`earnings_timestamp`。硬限制仅"每段 ≤7 天"（`earnings_calendar.py:361` 注释已载）。

⇒ 拉 2022-2026 全市场 **65,441 事件 / 4,489 票只花 2.3 分钟、零配额成本**，相位可辨 54,100 条、surprise 可算 53,041 条、市值非空 63,405 条、零空段（248/248）。

### 5.2 Alpha Vantage 免费版已降到 **25 requests/day**（memory 里"500次/天"过时）

实测超限响应：`{"Information": "...standard API rate limit is 25 requests per day..."}`。这直接废掉"用 AV 批量取历史财报"的路线（70 只票 → 只有 16 只拿到数据，54 只被限流）。

⚠️ **脚本 bug 已修**：初版把限流响应的空结果写进磁盘缓存 → 会永久锁死重试（后续跑会一直读缓存的空数组）。修法：`if not q and ("Information" in d or "Note" in d or "Error Message" in d): return [], "rate_limited"` 不落缓存。**教训：任何"失败也写缓存"的取数脚本必须区分"真空数据"与"限流/错误响应"。**

### 5.3 富途历史K线额度 = **1000 只正股 / 7 天硬上限**（不可扩，与 memory T39补 的"额度语义可扩"不同）

实测错误：`ret=-1 历史K线额度不足，请求失败（已用正股额度：1000/1000，期权额度：0/200）。额度会在7天后全部释放。`

⇒ 本轮票池 902 只（市值≥10B）只取到 **521 只（58%）**，且因按字母序取数撞上额度墙，构成**非随机选择偏差**：

| | 取到 521 只 | 缺失 381 只 | 比值 |
|---|---|---|---|
| 市值中位 | **42B** | **23B** | 1.86（不同构） |
| 每股事件数均值 | 13.9 | 13.4 | 1.03（同构） |
| C1 事件覆盖 | 895 | 690 | 56% |

**偏差方向声明**：取到的是**偏大盘子集**。结论"用户两假设证伪"对此稳健（失效模式是 OOS 符号翻转 + 跑不赢随机入场，属轴无判别力，不是样本不够）；但**具体幅度不得外推到中小盘**。若要终裁中小盘，须等额度释放（7 天）或换票池优先级（先取市值 10-30B 段，那段 C1 读数 +1.010% 最高）。

**为什么不留个影子攒样**：两假设的失效模式是**轴无判别力**（安慰剂跑不赢随机 + surprise 全网格同号非单调 + 决定性对照组自带同等收益），扩样只会继续稀释，不会恢复（T17-2 同律）。这属"已按门槛窗口跑过 ⇒ 关闭该轴"，不是"冻结等未来"。

**唯一留存的可用副产品**（非交易信号）：`财报日买入持5日`的无条件漂移 raw +0.649%，但市场调整后仅 **+0.069%** ⇒ 是 β 不是 α，不可用。

## 七、方法论登记（本轮新增/强化的三条）

1. **"过五关"的臂必须再做一次决定性对照**：E1b/C1 都过了 n、日聚类 t、IS/OOS、安慰剂、尾部五关，但 ①减无条件事件基线（C1 现形）②同条件非事件日对照组（E1b 现形）两刀下去都没了。**安慰剂只随机化入场时刻，不减事件基线，也不对照"同条件的普通日子"** —— 这两个对照是安慰剂抓不到的盲区。配方已固化在 `earnings_dir_gates_10b.py`。
2. **值域错配再次实锤**（同 DEB-20260929 §14.1 死字段）：AV `reportTime` 与富途 `timeOfTheDay` 返回的都是 `'pre-market'/'post-market'`，**不是** `'BMO'/'AMC'`。本轮取数脚本初版按 `("BMO","AMC")` 判填充率得 **0%**，与 §14.1 同一根因。⇒ 全仓凡比较财报相位的代码都应走 `EXEC._parse_earnings_phase` 同口径归一。
3. **取数额度语义要实测，两类结论相反**：富途财报日历"7 年历史可拉"（T39补 那种"能扩就当场扩"）vs 富途日K"1000只/7天硬上限"（不可扩，只能声明偏差）。不实测就会误判成"只能攒样"或"随便扩"。
