## 二、关键修正：昨日口头估算错误（诚实记录）

昨日我给出"死单过滤 65% 捕获率 → 情景净 -$0.45/笔，差一口气过线"。**该估算错误**：

- "65%"是死单**识别率**（规则命中组中 69%/64% 是死单，DEB-20260811 §2.3），不是亏损**捕获率**。
- 今日用 replay_bars（191 笔 100% 覆盖）逐笔回放"30min 时点按市价砍出"的真实干预结局，实测亏损捕获率 = $390/$1,300 = **30%**。
- 与 DEB-20260811 §2.4 预注册估算（$400-500/月 = 亏损的 30-40%）一致——当时声明了"幅度不可靠"，昨日引用时丢了这个限定。

**教训入库**：识别精度 ≠ 干预收益。引用估算必须带原口径限定词。

## 五、杠杆候选（供辩论）

### L1 死单 30min 提前砍 — 已在轨
- 转正条件已预注册（DEB-20260811-dead-order §三）：≥30 命中、双窗口死单率≥55%、与 60min DEAD_SIGNAL 差集为负。
- 不加速：shadow 攒样节奏由市场决定，人为加速=违反 record-only 纪律。

### L2 入场侧死单预判 — 本 DEB 主推新工作项
- 思路：死单在入场时刻是否有可观测前兆（entry_session / 开盘 gap / 距 VWAP / 前5根bar动量 / DA 因子快照）？若有分离度，在入场前拦截 = 全量避免 -$1,300/月，远优于 30min 砍出的 -$390。
- 与 gate 的区别：gate score 是 LLM 主观分（已证无区分度）；L2 只用**入场时刻的客观市场特征**，回放可证伪。
- 风险：特征可能无分离度（死单是入场后才知道的）→ 回放一天出结果，成本可控。
- 纪律：一次一变量 → L2 只做回放分析，不改任何代码；有分离度再立 DEB 走 shadow。

#### L2 回放实测（2026-08-11，191 笔，双窗口）

**方法**：9 个入场时刻客观特征（无未来函数），标签=30min MFE<0.2% 命中组（45 笔）。
W1(7/12-8/1, n≈122) / W2(8/2-8/10, n≈46)。防代理检查：day_range 非"入场时间晚"代理
（81% 交易 9 点档入场，该特征=早段波幅）。

**特征分离度（双窗口方向一致性）**：

| 特征 | 分离 | 判定 |
|---|---|---|
| **vix** | 高 vix→高死单风险，W1/W2 方向一致 | ✅ 唯一一致 |
| strength / confidence | 无分离（60% 样本=35，中位数全等） | ❌ 无信号 |
| off_high / range_pos | W1 正、W2 负 | ❌ 方向不一致，否决 |
| vs_open / gap / mom5 / day_range | 双窗口混杂 | ❌ 无稳定方向 |

**阻断模拟**（拦"最像死单"的前 X% 不入场，净收益=捕获亏损−误杀）：

vix 是唯一双窗口净收益为正的特征：
- 拦 15%：W1 +$311（死单 2/16）· W2 +$210（死单 1/7）
- 拦 25%：W1 +$357（死单 6/28）· W2 +$257（死单 4/11）

但 vix 分离度极小（W1 命中组中位 18.19 vs 未命中 17.92，差 0.27），
净收益主要由 W1 的 2 笔大额亏损单贡献，**统计显著性弱**。

**判定**：L2 入场侧预判**方向可行——vix 是最强先验信号**（高波动=高死单风险，
与开盘失血/regime 翻转结论互证），但 W2 仅 46 笔、拦后剩 7-11 笔，**不满足 n≥30
双窗口判据，8-29 前无法落地**。建议开 vix-先验 record-only shadow 攒样。

**旁证（重要）**：strength/confidence 对死单零分离 → DA 分数无入场侧先验预测力，
与 DEB-quality-gate（gate score 无区分度）互证。入场侧预判不能靠 LLM 分，只能靠客观市场特征。

## 六、关键分歧（供其他模型攻击）

1. **L2 值不值得本周跑？** 反方：入场时刻特征大概率无分离度（否则 DA 早该有 edge），一天回放是浪费变更预算。正方：成本一天、上限 +$6.8/笔，是四个杠杆里唯一未验证且上限够补完缺口的。

3. **采集期 vs 冲刺期**：8-29 前是否维持"数据量优先"？若 L4 降频，样本积累减速，与 G1-2 SHORT 边缘桶（n=42）冲突。
