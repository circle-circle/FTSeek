## 三、推导链与判别

1. P1 成立 (零毛edge+费拖累) → "优化信号"前先承认: **频率本身是负贡献**。降频是唯一无需
   edge 假设就能改善净值的动作 — 但降频会拖长样本积累, 与校准目标冲突, 需权衡。
2. P2 (MAE>MFE) 若为主因 → 修入场时机 (regime/时段/锚), 与 regime-entry-gate、
   no-trigger 反事实案天然衔接。
3. P3 (时间类退出) 若为主因 → 修/隔离 MFE_STALL 与 TIME_EXIT, 引用 DEB-20260723-time-exit-censoring
   (删失偏差) 与 20260805-mfe-capture (毕业判据), 避免"删规则=把亏损转移到别的腿"的假修复
   (W_WEEK §39 的教训: 名义5日窗口实际2日)。
4. H-L1/H-L2 判别 = L-E1 台账分桶 + no-trigger 案 open 基准反事实互补
   (已执行单用真实成交价, 无 anchor 折价问题)。

## 四、实验设计 (全部只读/影子, 零执行风险)

### L-E1 期望值台账 (主实验)
- 维度: 月 × 方向 × source × entry_session × market_regime × exit_reason × (decision_conf 桶, 攒满后加入)
- 指标: n / 毛 / 净(pnl_net) / 胜率 / avg MFE / avg MAE / t 值; 双周刷新, 输出
  `data/long_expectancy_ledger_latest.json`
- **预注册判据** (写于任何数据再收集之前):
  - 触发"多头供给调整预案"辩论: 现役 LONG 累计 n≥300 且净期望 95%CI 上界 < 0
  - 保护条款: 任一桶 n≥60 且 t≥1.5 → 该桶豁免于无差别削减
  - 现役 n=214, 预计 9 月上旬达 n=300

### L-E2 费用感知准入 (影子)
- 对每条候选指令: 估算 fee+spread ÷ 历史同桶 avg MFE, 比例 >50% 打 shadow 标签 (不拦截)
- 攒 30 天后裁决是否升为 SKIP 门; 与 P1 (费=净亏全部来源) 直接对证

### L-E3 时间类退出规则复查
- 对象: MFE_STALL / TIME_EXIT / PATIENT_STOP+PATIENT_EOD (现役合计 67笔/毛-$2,326/净-$2,610)
- 工具: 刷新 exit_calibration.json (现 stale 于 2026-06-06) + 删失校正重放
- 产出: 每规则的 n/净/删失比例/删除后亏损转移仿真, 供后续辩论

### L-E4 入场伸展度影子 (2026-08-16 预注册, 依据 §2.10)
- 动机: never_up (MFE<0.2%) 组独担现役 LONG 全部亏损, 需要一个**下单时点可观测**的
  前置变量来分离"追高入场"。候选 = 入场伸展度 (当日已走的路):
  - `vwap_dev = |entry - vwap| / atr` (偏离当日均价几个 ATR)
  - `day_move = (entry - 当日open) / atr` (开盘后已涨/跌多少 ATR, 方向带符号)
  - 数据源: playbook_service 已有 `_ts_ctx_snap` (get_full_market_context 捕获 vwap/atr/price),
    在 save_trade 时随 factor_detail 落库 — **需一次小改 (加 3 个字段), 只写影子列, 不动门**
- 设计: 影子 jsonl (trace_id, vwap_dev, day_move, 方向, 后验 never_up/净); 攒 n≥200 后
  按伸展度三分位分桶 → 各桶 never_up 率 + 净/笔
- **预注册判据**: 高伸展桶 never_up 率 ≥40% 且 净/笔 ≤ -$25 (n≥50), 同时低伸展桶
  never_up ≤20% → 提案"高伸展半仓或限价-only"门进辩论 (仍需 DEB 裁决才生效)
- 红线①对齐: 本实验零拦截, 判据触发只产辩论材料

### L-E5 DOA 快断影子 (2026-08-16 预注册, 依据 §2.10 持仓指纹)
- 动机: never_up 组平均持仓 4.2h — 死资本在时间类退出里等死; 若入场后 2h 即可识别 DOA
  (Dead On Arrival), 早断可省时间与深度亏损
- 规则 (影子): 入场 +2h 时 MFE<0.2% 且浮亏 >1×atr → 记"DOA 命中", 反事实 =
  立即按 2h 价平仓 vs 实际结局 (工具: position-path-lake 回放, 参考 DEB-20260729)
- **预注册判据**: 平均省下 ≥$15/笔 (n≥60) 且误杀率 (被早断后实际反转为盈利的比例) ≤15%
  → 提案"DOA+2h 快断"进辩论; 未达标则只留档
- 与 L-E3 的边界: L-E3 修"活仓何时退", L-E5 修"死仓早认错"; 互不抢占证据

1. **红线①**: 不改任何生效阈值/门/供给量, 除非对应 L-E 判据预注册并触发 (镜像 short-funnel)

3. **红线③**: 不重审已裁决项 (crash-day-long-bias / asymmetric-exit / W_WEEK), 仅引用其结论
4. **红线④**: 与 regime-entry-gate 的边界: 披露日事件门属彼案, 本案不做事件门;
   两案证据 (regime 桶) 互惠共享
