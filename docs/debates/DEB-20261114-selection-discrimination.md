## §零 结论（TL;DR）

1. **"做多比做空多"是生成偏置，不是识别力证据。** DA 面板 23 天 679 条 verdict：**BUY 433 / SKIP 134 / SELL_SHORT 112 = 3.9 : 1**；指令层 95 天 1819 条：BUY 1048 / SKIP 464 / SHORT 307 = **3.4 : 1**；A10 成交 683 : 177 = **3.9 : 1**。三层同比例 ⇒ 不对称来自"逐票绝对打分"的生成方式本身，不来自判别。
2. **选择力实测 ≈ 0（长侧）到略负（短侧）。**
   - 指令层（1409 条 / 95 天，open 基准可成交口径，逐日去均值）：**BUY −12.4bps**（t=−0.98，日聚类 −1.30）、**SHORT +23.4bps**（t=0.80）。
   - 成交层固定窗口（610 笔，30m/1h/2h，不看实际退出）：全部 **+0.5 / −4.7 / −8.6bps**；LONG **+2.4 / −1.3 / −5.7bps**；SHORT **−6.0 / −16.6 / −18.3bps**。
3. **"高胜率+正 PnL"来自退出机制与市场 beta，不是选股。** A10：毛 PnL **+$2,605**、费用估算 **$4,643**、**净 −$2,037**（860 笔，$3.03 毛利/笔 vs $5.40 费/笔）。WR 72.9%/75.7% 是 BE 阶梯（大量 0.4% 小赢 + 少量满 SL）的产物。
4. **模型的绝对评分没有横截面信息。** DA 面板 score → 方向调整超额的逐日 rank IC = **−0.006 / +0.015 / +0.010**（intraday/t1/t3，t<0.3）；18 个结构化子信号（bull/bear 强度计数、challenger score、gaps、price_in、archetype 等）|IC| ≤ 0.11 且 t<2 —— 54 次检验下无一可采信。
5. **唯一正点估计出现在"被机械降级"的那批长单上，且不显著。** 偏斜门 6/30–10/7 降级 65 条 BUY：T+1 open 基准 **+1.39%**（t=2.23）、当日 intraday_open **+1.06%**（t=2.43），同日保留 BUY 为 −0.07% / −0.31%；但**逐日配对差 +0.80%（t=1.01，16 天 9 胜）不显著**。方向提示：配额砍掉的是当日高置信簇，不是垃圾单。
6. **可重复的结构性负判别只有两处**（均未过强显著线）：`risk_on` regime 内选中名 30m/1h/2h 超额 **−11.5 / −13.8 / −18.3bps**（t≈−2.0，270 笔/45 天）；盘中相对强度最强五分位 **−20.1bps**（t=−1.87/−2.04）。两者同向：**开盘后追强 = 负**。
7. **测量基础设施有洞**：518 条 SKIP 指令中 **426 条（82%）从未回填前向收益**，DA checkpoint 679 条 verdict **回填 0 条** ⇒ "不买"的决策至今不可测。这是本议题最大的结构性盲区，也是任何"让模型更有判别力"的前置条件。

## §一 问题拆解

用户观察两点，实为两个独立命题：
- (a) 数量不对称（long ≫ short）**是否构成**识别力证据 → 需排除"生成偏置/配额/账面偏斜"。
- (b) 是否**可能**有真正的识别力、并让模型给出有判别力的指令 → 需要 (i) 一个不依赖退出路径的选择力度量；(ii) 一个能让模型区分高低的输出契约。

## §四 对前一份 DEB 的两处更正

1. **"成交层 +15.5bps t=3.59 反映选择力"——撤回该读法。** 该数字用实际持有窗口度量，被退出机制条件化（§3.4）。同批数据在固定窗口是 −4.7bps。选择力只能用固定窗口 + 同日同窗口宇宙基准。
2. **"盘内动量对齐（DEB §六 A 建议）"——成立范围收窄。** 前一份 DEB 的 +10.0bps（t=2.14）是**全宇宙 11:00 决策时刻 × 2h 前向**的横截面 IC；本系统实际入场 74% 落在 09:30–10:00，在这段"方向=盘内动量"的超额是 **−8.4bps**，不对齐反而 +7.4bps（皆不显著）。⇒ A 建议不能按"对齐即加分"直接落地，须先影子按实际入场时段验证。

其余结论（日线趋势门无效、1h 动量 3–5 日反转、short 臂期限错配）不受影响。

## §五 诚实边界

- DA 面板仅 **23 个交易日**（checkpoint 自 10-14 起），跨 regime 代表性有限；指令层面板 95 天但只有 T+1/intraday 两个 1 日窗口。
- 1m bar 宇宙 **219 只**（187 有效横截面），成交 250 笔（29%）无法固定窗口对齐（盘前/盘后入场或票不在宇宙）。
- 超额为 close-to-close，不含滑点/点差；`fees_est` 为估算（`fees_source='est'`）。
- 所有 t 为跨日聚合的朴素 t 与日聚类 t 并列；未做多重检验校正 ⇒ 3.6 的 |t|≈2 切片按"待验证提示"而非结论。
- 无法测"模型本可以选但没选的票"（未进入候选池的符号无 verdict）⇒ 本 DEB 只测"选中 vs 同池/同宇宙"，不测"池子本身是否漏掉 alpha"。

## §六 建议（按证据强度/成本排序）

**P0【基础设施·免费·先做】反事实台账**
把**所有** verdict（含 SKIP/未执行/DA checkpoint）按固定期（30m/1h/2h/EOD/T+1/T+3）回填方向调整超额，落一张 `verdict_outcomes` 表 + 日更 IC 面板。当前 426 条 SKIP 与 679 条 DA verdict 零回填，等于"不买的决策"完全没被测量。没有这一步，任何"让模型更有判别力"的改动都不可裁决。

**P1【评估换轴·免费】把 KPI 从 WR/PnL 换成选择力**
报表口径改为：`同日同窗口宇宙超额 + rank IC + 校准斜率`，按方向 × 期限分列。理由：WR 72%/毛 PnL 正的表象掩盖了"选择力 0 + 费用 −$2,037"的真相（§3.3/3.8）。

**P2【契约改造·shadow 先行】绝对打分 → 相对排序 + bps 预测 + 成本门槛 + 期限绑定**
- 输出改为：日内候选**强制排序** + 每票 `expected_excess_bps` + `horizon ∈ {30m, 2h, EOD, 3d}` + `reason_type`（事件未定价/资金流/基本面错价/技术结构）。
- 落地门槛：|expected_excess_bps| ≥ 20bps 才出指令；horizon 只允许 ≤2h 或 ≥3d（禁 2h–3d 灰区，§3.4/前 DEB：>6.5h 拖累）。
- 裁决判据（预注册）：预测 bps 的逐日 rank IC > 0.05 且 ≥20bps 桶实测超额 ≥ +20bps，连续 10 个交易日。
- 为什么可能有效：绝对打分没有区分度（score IC≈0、HIGH band 更差），而**相对排序+数值预测本身可被 IC/校准直接打分**，且强制把底部票分配给空方，顺带解 3.9:1 单边（对应用户 8/16「核心=真正有空头产出」）。

**P3【空头/配对·低成本】sector-neutral 配对单**
短侧是唯一正点估计（+23～25bps，t<1.2，95 天）。用"排序 top 做多 / bottom 做空（同 sector）"构成市场中性组合：既对齐用户"要真空头产出"，又天然可测 IC，且不受 long-only beta 污染。

**不做**
- **不要叠新门**（置信度门/趋势门/动量门）：置信度与收益关系在子集间**反号**（全体高置信 −19bps、已执行子集低置信 −31bps），无稳定方向；前 DEB 已证日线趋势门 IC≈0。
- **不要恢复 80% 偏斜配额**：唯一正点估计（65 条 +1.39%）正是被它砍掉的那批，但配对不显著（t=1.01）⇒ 只能留作 P2 影子，不恢复实盘配额。
