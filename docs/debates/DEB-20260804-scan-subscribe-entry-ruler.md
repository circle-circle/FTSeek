## 一、主张与辩论

### S1 · 扫描频率 5min → 1min 能救入场吗?
- **正方**: 触发条件 (突破/回踩入场区) 最多滞后 5 分钟才被发现, 日内信号衰减快, 1min 扫描能抓到更优入场价。
- **反方**: ①入场滑点实测 avg/p50 ~3bps (n=115, 尾部 p99 61bps 属 ~1/100 单), 成交质量证明当前节奏没吃大亏; ②指令级回放 5 个入场时点均值全负且差距 <0.13% — 时点敏感度本身不高; ③CPU 盘中已 ~30%, 1min 循环 × 41 只池 × 指标重算有回归 ADR-013 的风险; ④验证期纪律: P1/P2 观察期内禁止叠改。
- **判决**: **不改**。缺的不是频率, 是"触发条件首次为真时刻 vs 实际成交时刻"的延迟尺子 — 没有它, 频率之争是空对空 (见 F-S1)。
- **证伪方式**: 若延迟尺子显示中位延迟 >2min 且延迟与 PnL 负相关 (n≥30), 重启本议。

### S2 · 恢复 ORDER_BOOK/TICKER 订阅提升指标精度?
- **正方**: F2 已把 order_flow_imbalance 列入 ts_ctx 快照; claim 层大量使用"买盘/卖盘比、超大单净流入", 深度数据能让这些因子从"日志文字"变成可算数值。
- **反方**: ①ADR-013 明文: 全量订阅时接收线程满载一核, 是性能事故不是优化空间; ②当前 OFI/资金流从 QUOTE 派生已够快照用, 没有任何消费端被证明因数据粒度受损; ③F2 样本未满 2 周, 连"OFI 有没有 IC"都还不知道, 先扩数据是典型的尺子没校好先买更贵的尺子。
- **判决**: **不加**。门径: F2 攒满样本后若 OFI/盘口类因子 intraday IC 显著且方向稳定, 再评估"仅对候选执行中的 3-5 只标的临时订阅 ORDER_BOOK"的窄方案。
- **证伪方式**: F2 样本 (≥2 周) 显示盘口类因子 IC≈0 → 本议关闭。

### S3 · K_1M 精度不够, 上秒级/tick?
- **判决**: **否, 快速否决**。决策周期是 5 分钟, 退出检查点最小粒度是分钟级; VWAP 尺子 (任务#3) 与回放器都以 K_1M 为准且复现良好; 秒级数据只增加存储/CPU, 不改变任何现有决策。除非未来开 HFT 式入场 (无此计划), 本议关闭。

### S4 · 指标层: 真数值因子评估的缺口
- **现状**: C1 断言"真数值因子算了就扔"已被 F2 (ts_ctx 落库) + F3 (intraday IC 孪生列) 修好数路, 但**样本从 08-04 才开始攒**。
- **新发现缺口 (本辩实测, 第3轮修订)**: ①`anchor_dev_pct` 系 07-31 新字段 (当前覆盖率 84% 且自增, 详见 §三勘误③) — "追价入场"维度**2 周后可评**, 无需回填; ②触发时刻的 bar 时间戳未落库 (ts_ctx 只有值没有"条件何时首次为真"), S1 的延迟尺子因此缺原料。
- **判决**: 不再新增指标种类, 核心缺口只剩 F-S1 触发延迟尺子 (F-S2 已降格, §三勘误③), 指标"算而可评"比"算得更多"优先。

### S5 · 入场时机: 该不该躲开开盘 30 分钟?
- **正方**: 开盘30min 占 era 入场 **84%** (127/151) 且净 -911.8; 暴跌日全部集中在此窗口 — 开盘是隔夜信息+缺口+流动性混沌的三重风险区。
- **反方**: ①剔除 3 个暴跌日后开盘30min ≈ 打平 (净 -67.4, WR 51.3%) — 亏损是 **regime 集中**不是时段本身; ②回放显示推迟入场 MFE 从 1.67% 缩到 1.12% — 躲开盘 = 同时躲掉当日最大机会段; ③"跌多躲开盘"本质是 regime/缺口过滤, 不是时钟规则 — 按钟点一刀切会在正常日白白损失 MFE。
- **判决**: **不设时钟硬规则**。真命题"缺口日开盘保护"**已实跑并否决** (F-S3, §三: gap≥1.5% 桶点估计差一倍但 bootstrap p=0.25~0.30 未过预注册门径) — 时钟规则与缺口过滤双双不立案, 探针攒样至 n 翻倍再开。
- **证伪方式 (已完成)**: 缺口日分拆 → 门径未过, 议题关闭 (见 §三)。

### S6 · 市价入场 → 限价入场区 (entry_low/high)?
- **正方**: entry_low/entry_high 已落库, 限价能避免追价, C2 的 entry 锚定纸面 edge (+1.0%) 暗示限价"看起来"更好。
- **反方**: ①C2 已定性: entry 锚定 edge 是**未成交限价的纸面优势** — 限价单的真实问题是成交率下降, 会系统性漏掉走得快的真赢家 (幸存者偏差反向); ②市价滑点实测 avg ~3bps (p99 61bps 为 ~1/100 尾部), 限价省下的钱远小于漏单的机会成本; ③动入场订单类型 = 断 config_version 窗口, 违反验证期纪律。
- **判决**: **维持市价**。除非滑点报告显示特定标的 p90 >15bps, 本议关闭。

### 5.3 结构性问题② · 预注册门径缺功效分析, "攒样"实际等于无限期搁置

F-S3 被 bootstrap 挡下, 纪律正确; 但**从未算过该门径需要多少样本才可能被通过**:

- gap 桶效应量 diff = **$11.2/笔**, pooled sd = **$37.7**
- 80% power / α=0.05 双侧 → **每组 n≈176, 合计 n≈352**
- gap≥1.5% 占比 17% → 需总样本 **~1,035 笔**
- 当前节奏 98 笔 / 9 个交易日 ≈ 11 笔/日 → **约 94 个交易日 ≈ 4.5 个月**

原文证伪条件"n 翻倍后 p<0.05 再开" → n 翻倍即 hi 桶 34, 功效约 **20%**: 即使效应真实存在, 也有 80% 概率再次不显著, 然后再次判"不立案"。**该门径在设定上就是永远说不。**

→ 推论: **六议题全部否决不是六次独立的证据判断, 而是同一个功效不足在六个位置的重复投影。** 修正方向 (二选一): (a) 改用可达成的判据 (贝叶斯后验区间 / 效应量阈值 + 单边 α=0.10 / 序贯检验); (b) 显式写明"入场侧假设在当前日均笔数下不可检验, 议题冻结至交易量提升 N 倍", 不再以"攒样"措辞掩盖不可达。

### 5.4 结构性问题③ · 范围切割让最重要的结论无家可归

事实#7 是本辩最重量级证据却被当配角: **指令级裸持有回放 (无费无滑点), 09:35~11:00 每个时点均值全负 (-0.08~-0.21%)**。

无费、无滑点、任意入场时刻皆负 → **指令的方向性期望本身 ≤ 0**。这一条同时把 S1/S5/S6 全部降格为二阶问题, 并指向"瓶颈在信号生成侧"。但本辩范围是"只审尺子与入场", 于是该推论被推给 factor audit; 而 factor audit 的结论是"数路修好了, 08-04 才开始攒样"。

→ **两份辩论各自把最关键的举证责任推给了对方, 无人承接"指令方向性 edge ≈ 0"这个观察。** §四 元判决应明确写入并正式移交, 而非止步于"成交质量非瓶颈"。

### 5.5 逐议题门径漏洞 (不改判决, 但证伪条件需重写)

**⚠ S2 证伪门径存在循环依赖 (attenuation 陷阱)**: 门径为"F2 攒满样本后若 OFI 类因子 IC≈0 → 本议关闭"。但当前 OFI 系从 QUOTE 派生的**低保真代理**, 测量误差会系统性把 IC 向 0 衰减。**用劣质代理的零结果去关闭获取优质数据的门, 逻辑上不成立。** 正方提到的"窄订阅 3-5 只"是唯一能打破循环的设计 (校准代理 vs 真值相关性), 却被放在了这道无法通过的门之后 → 门径顺序应互换。

**⚠ S6 核心反驳未量化**: "限价省下的钱 < 漏单机会成本"是断言。而 `entry_shadow v3` (07-15 起) 已落库 VWAP/量能/大盘门影子, `entry_low`/`entry_high` 全部落库 — **限价反事实回放 (成交率 × 成交子集后续 PnL) 是零 live 风险读题, 数据齐备却未进落地清单**。本辩唯一"能算而没算"的议题。

**⚠ S5 可能是误诊**: 开盘30min 占 84% (127/151) 被当"时机选择"辩, 但触发规则是"突破当日高/低点 + 5min 轮询" — **开盘30分钟正是日内高低点最易被首次突破的时段, 该集中度是触发机制的机械必然, 不是选择**。真命题不是"要不要躲开盘", 而是"当日高低点突破在开盘30分钟内是否退化为对开盘噪声的随机抽样" — 与事实#7"各时点均值全负"高度自洽。

### 5.6 缺席的议题 + 两处 hygiene

**⚠ 缺席议题 S7 · 突破触发条件本身的有效性**: 本辩审了频率、数据源、精度、订单类型、时钟, 却**从未审触发条件本身** (06-29 从 MA20 突破改为当日高低点突破, 此后无有效性评估)。这是入场侧唯一可能有一阶量级影响的变量, 也是唯一完全缺席的。建议立案: 触发 vs 未触发指令的后续收益对比 — `trigger_miss_telemetry.jsonl` (07-11 起) **天然对照组已存在**。

**① pnl 口径必须固化进事实底座**: 实测同一批数据改用 `realized_pnl` (不含费), 剔暴跌日 open30 从"净 -67.4 / WR 51.3%"变为"**净 +310.2 / WR 63.7%**" — **结论完全反转**。原文一致使用 `pnl_net` 是正确选择但未写明, 后续任何复算都可能翻车 → 应写入 §〇。

**② anchor_dev 0.0 歧义**: 08-03 有 3 行值为 0.0, 无法区分"真零偏离"与"默认零"。84% 按非空算无误, 但 2 周后评估须剔 0.0 或加 sentinel。

**③ 勘误④ 时区混存无修复项**: "个别 pre-era 行疑似 CST 落库"意味着写入路径存在双口径, 记 caveat 不解决问题 → 应定位写入点并统一, 属 hygiene 任务而非 caveat。

### 5.7 第 4 轮结论

**判决全部维持, 门径设计返修。** 本辩的证据纪律 (三轮自查 / 预注册 bootstrap / 不为好看的点估计放行) 质量很高, 六个否决在"现有证据不支持"这个意义上都站得住。

### 6.2 bootstrap p 值分歧根因 (答 5.8⑥) — 两种实现都跑了, 分歧=方法选择非 MC 噪声

同数据同 seed=42 B=10000, ALL 切法:

|---|---|---|

### 6.3 对 5.8 六项的裁定

1. **5.2 量级论证 — 成立, 采纳降级, 两处返修**。(a) 对方 5.7⑤ 称 F-S1 "测的是那个 $0.92" 张冠李戴: $0.92 是 arrival→fill 段, F-S1 测的是 anchor→arrival 延迟段; 正确的降级理由是事实#7 回放显示**入场时点敏感度 <0.13% (<$4/笔)**, 延迟尺子的可解释上限被封顶。(b) 同一量级透镜照出对方也漏掉的更大项 — **费用 $4.48/笔 = 14.6bps round-trip = era 净亏的 65%**, 是滑点 (3bps) 的 5 倍, 且把剔暴跌毛盈 +272.5 打成净亏 -192.0 (事实#10)。"入场成本维度整体降级"正确, 但省下的资源应投向费用结构而非简单砍掉。
2. **5.3 功效计算 — 数值正确 (1,027~1,035 笔 / 94 日), "20%" 修正为 ~35-38%; 路线选 (b) 显式冻结**。理由: 见数后放宽判据 (单边 α=0.10 / 效应量阈值) 是 criteria-shopping, 恰是预注册要防的; 且量级论证自身给出答案 — gap 效应即使为真, 期望值 = 17% 占比 × $11.2 ≈ **$1.9/笔 < 费用 $4.5/笔**, 优先级排序独立支持冻结。**采纳对方④的通用版: 未来一切门径注册时必须带 MDE/功效标注, 不可达的显式写"冻结至 X 条件"。**
3. **5.4 移交 — 成立不越界, 但推论必须三分版** (裸持 edge≈0 / 退出栈毛贡献为正 / 净亏=费用+regime), 已写入 §四附; 接收地 = factor-system-audit 任务清单, 无需新开 DEB/ADR。

5. **S7 归属 — 信号侧, 移交 factor-audit 立案**。触发规则 (当日高低点突破+量确认) 是入场政策不是尺子, 本辩责任止于"遥测存在" (trigger_miss_telemetry 07-11 起 ✓)。**附混杂警告**: 触发 vs 未触发非随机分组 (未触发者 setup 本身不同), 必须按 miss 原因码分层或倾向得分匹配, 裸比会产生选择偏差假阳性。
