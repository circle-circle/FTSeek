# Multi-Agent Debate Protocol (MADP)

FTSeek-US 用于处理技术/策略分歧的标准决策流程。

## 目标

- 把多 Agent 讨论从「聊天记录」升级为「可追溯的决策文档」
- 每个决策都有：背景、证据、分歧、决策、执行项、验证项
- 避免同一议题反复重开

## 状态说明

| 状态 | 含义 |
|---|---|
| 进行中 | 正在收集观点和证据 |
| 待决策 | 证据已充分，等待裁决 |
| 已决策 | 已选择方案，进入执行 |
| 已验证 | 决策假设已被数据验证或证伪 |
| 已关闭 | 决策已落地，无需再讨论 |

## 规则速览

1. **不覆盖对方内容**：每个 Agent 只能追加/修改自己的章节。
2. **证据绑定**：所有观点必须有数据、代码、文献或逻辑推导支持。
3. **明确分歧**：必须有「关键分歧」章节，列出不可调和的分歧点。
4. **决策可执行**：每个决策必须包含代码/配置改动 + 验证方式 + 截止时间。
5. **关闭前验证**：状态改为「已关闭」前，必须完成验证项。

## 预注册门径规范 (2026-08-04, DEB-ruler §六裁定, 全部 DEB 通用)

1. **检验实现按设计分族** (2026-08-05 DEB-20260805 R2 修订; 原文"一律 null-pooled"导致门A 配对数据套两样本模板、门B 等价性断言套差异检验框架): ①**两独立样本** → 双侧 **null-pooled bootstrap** (置换式, 池化重抽模拟 H0), B≥10,000; ②**配对/同单反事实** → 对差值做**符号置换检验** (B≥10,000, 双侧), 费用在配对内消去用毛差; ③**非劣/等价断言** → **单侧非劣检验** (预注册界), 仅当"真差=0"本身是决策目标且样本量可达时才用 TOST (注意 TOST 在效应实际有利时会误判 FAIL)。三族共同要求: 报告必须 效应量 + bootstrap CI + p 三列并列; 单边检验仅在见数前预注册方向时可用; two-sample 未中心化 |d| 变体无效 (备择下天然 p≈0.5), 禁用。**选样恒等式警示**: 若抽样框本身蕴含 H0 被否 (如"保本单"队列必然 d>0), 该检验无零假设内容, 须改锚更高保真数据 (如 1-min 重放)。
2. **MDE/功效强制标注**: 门径注册时必须写明最小可检测效应 (MDE) 与达到 80% 功效所需样本量/时间; 按当前节奏不可达的门径, 显式写"**冻结至 X 条件**", 禁止用"攒样"措辞掩盖不可达 (反例: gap 门径实际需 ~1,027 笔/94 交易日, "n翻倍再开"功效仅 ~35-38%)。
3. **见数后禁止放宽判据**: 点估计被预注册门径挡下后, 改用单边 α/效应量阈值等更松判据 = criteria-shopping, 不予立案 (F4、F-S3 两案先例)。
4. **pnl 口径双列**: 一切盈亏分析必须毛 (realized_pnl) / 净 (pnl_net) 双列 — 费用 era 均值 $4.48/笔=名义 14.6bps, 口径翻转可逆转结论 (剔暴跌开盘30min: 净 -67.4 → 毛 +310.2)。
5. **代理零结果不能关高保真之门**: 用低保真代理测得 IC≈0 来否决获取高保真数据 = errors-in-variables 循环; 正确顺序是先做窄校准实验 (代理 vs 真值秩相关) 再定门 (S2 案先例)。
