## 一、第一性拆解：亏损到底从哪来（484 笔全样本，可复现）


### 原子事实 1：利润极度依赖极值，剔除后策略不赚钱

- 总样本 484 笔，总盈亏 **+$19,262**，中位数 **-$6.7**（一半交易亏钱），均值 +$39.8。
- 盈利单 189 笔共 $69,672，**Top10 占 69%、Top20 占 79%**。
- **中位数为负 + 利润集中在极少数极值** = 这不是一个"稳定产生正期望"的策略，而是"多数小亏 + 极少数大赢"的形态。剔除 Top3 即转亏（崩盘 DEB 已证）。

### 原子事实 2：98% 的亏损来自"从未浮盈过"的单子（决定性）

MFE（最大浮盈）分桶，全样本单调关系：

| MFE 分桶 | 笔数 | 胜率 | 净盈亏 | 均值 |
|---|---|---|---|---|
| **MFE=0（从未浮盈）** | **244（50%）** | **0%** | **-$49,412** | -$202.5 |
| 0–0.3% | 71 | 68% | +$2,096 | +29.5 |
| 0.3–0.5% | 27 | 56% | +$1,562 | +57.8 |
| 0.5–1% | 58 | 81% | +$3,905 | +67.3 |
| >1% | 84 | 94% | +$61,112 | +727.5 |

- **MFE=0 的 244 笔 = 全部亏损的 98%**（-$49,412 / 总亏损 -$50,410），胜率 **0/244 零例外**。
- **一旦浮盈超过 1%，胜率跳到 94%。**
- 这是整个系统**最强、最干净的第一性信号**：**"进场后价格有没有站上过入场价"几乎单独决定了盈亏。**

### 原子事实 3：MFE=0 的单子在出场时 MAE 中位数=0

- MFE=0 的 244 笔，出场时 MAE 均值仅 0.12%、**中位数 0.00%**、持仓中位 0.0h（大量瞬时保本/秒平）。
- 含义：这些单子不是"大亏"，而是**大面积的微亏/平推磨损**——进场即错，靠止损/时间兜底小额出血，累积成 98% 的总亏损。**杀死我们的不是几笔大亏，是几百笔"本就不该进"的小亏。**

### 原子事实 4：入场时点数据不可用（工程债，需先修）

- `entry_time` 时区存储混杂（00–23 时全覆盖，21–23 时段占大量样本），无法可靠按 ET 交易时段归因。→ 择时分析的地基缺失，列为链路层修复项。

## 二、第一性结论：问题的本质是什么

把四条原子事实合起来，得到一个**与"崩盘日""单向做多"都不同**的根本诊断：

> **系统的核心亏损机制 = 大量"进场即错"的单子（MFE=0），靠下游出场规则被动兜底小亏，累积成结构性慢出血；而利润完全依赖极少数走出大趋势的单子。这是一个"入场质量不足 + 依赖极值续命"的策略。**

由此，三层问题各自归位：
- **源头层（选股/入场）**：真正的病灶。50% 的单子从进场起就没对过。score 坍缩（全 6~7）使系统无法在入场前区分"会浮盈的"和"不会浮盈的"。
- **规则层（出场/风控）**：目前是"事后兜底"，用时间/保本止损处理已经进错的单——治标。真正的杠杆是**尽早识别 MFE=0 并止损**，把 -$202/笔压到更小。
- **链路层（数据/反馈）**：入场时点不可归因、regime 45% 未落库、审计曾断两月——**度量地基残缺，导致上面两层都在盲飞**。

## 三、解决方案：源头 → 规则 → 链路 三层

### 【源头层】S1：把"预测 MFE>0 的能力"作为选股的第一目标（治本）

- **第一性依据**：既然 MFE>0 vs MFE=0 几乎单独决定盈亏，选股的唯一有效目标就应该是**提高入选单子"进场后能浮盈"的比例**，而不是现在的"score 打分"（已坍缩为 6~7 无区分度）。
- **动作**：
  1. 离线建立"入场后 30/60min 达到 MFE>0.3% 的概率"标签，回测现有各因子/维度对该标签的**边际增量预测力**（正交性审计，呼应方法论 DEB 方向A）。
  2. 保留有预测力的维度，**砍掉无区分度的（含坍缩的 analyst score）**——Ponytail 删除优先。
  3. 用挑战者 score（已证有区分度）或 MFE 概率模型替代 analyst score 做 tier 分档（走 shadow）。
- **代价/风险**：涉及选股核心，须全程 shadow 回测，不直接改 live。这是最慢但唯一治本的一层。

### 【规则层】R1：MFE=0 早止损（止血，最高即时 ROI）

- **第一性依据**：MFE=0 的 244 笔零胜率、贡献 98% 亏损、MAE 中位 0。既然它们**从不翻正**，持有它们没有任何期望收益，只有出血。
- **动作**（承接崩盘 DEB 缺陷C，已达成走 shadow 共识）：
  1. shadow 落库："MFE=0 且持有 >T 分钟 → 若当时平仓的反事实 PnL"，跨日验证误杀率。
  2. T 的标定用回测（防砍掉 0–0.3% 桶那 68% 会回正的单——**边界是 MFE 严格=0，不是 MFE<某正阈值**）。
- **代价/风险**：低。局部出场逻辑，record-only 先行。**这是三层中最快见效的止血带。**

### 【规则层】R2：MFE=0 跨日封禁（承接缺陷D修正版）

- **第一性依据**：同标的以 MFE=0 形态连续亏损（如 CRM 三连 TIME_EXIT），说明该标的当前不具备"进场能浮盈"的条件，重复进场是重复交同一份学费。
- **动作**：与 R1 共用 shadow 字段，验证"同标的 N 日内 MFE=0 连败≥2 → 暂停新指令 M 日"。**必须叠加 MFE=0 过滤**（纯连亏封禁会误伤 MRK/EOG/LLY 等重复盈利标的，崩盘 DEB 第4轮已否决）。
- **代价/风险**：低，并入 R1 shadow。

### 【规则层】R3：让利润端跑得更久（对称问题，谨慎）

- **第一性依据**：利润 79% 来自 Top20 大赢单（MFE>1% 桶 94% 胜率）。**既然极值单是利润命脉，任何"过早止盈"都在杀死利润端。**
- **动作**：审视是否有规则在过早了结 MFE>1% 的单（如固定止盈、过紧 trailing）。**方向是"让赢单跑"，与 R1"快砍不浮盈的单"形成不对称出场**——这正是正期望策略的核心结构（截断亏损、让利润奔跑）。
- **风险**：与 time-exit DEB "4h 持有更优"结论存在张力，须区分子集：R1 作用于 MFE=0 子集（早砍），R3 作用于 MFE>1% 子集（晚放），两者不重叠不矛盾。

### 【链路层】L1：补齐度量地基（前置，无争议）

- **第一性依据**：上面每一层的验证都依赖数据，而当前地基有三个洞：
  1. `entry_time` 时区混杂 → 择时不可归因（原子事实4）。
  2. regime/VIX/SPY 45% 未落库 → regime 相关分析盲飞（崩盘 DEB 缺陷A）。
  3. LLM 审计曾断两月（已修 `model_call.py` 参数名 bug）。
- **动作**：统一 entry_time 存 UTC + ET 双字段；playbook 生成时落 regime/VIX/SPY；新鲜度看门狗已上线防复发。
- **代价/风险**：低，纯工程。**是 S1/R1/R2 一切回测的前提。**

### 【链路层】L2：修复评测尺子（承接方法论 DEB 方向C）

- **第一性依据**：当前用已实现 PnL 评价选股，被出场规则和极值污染（中位 -$6.7 但均值 +$39.8 的巨大背离即证据）。
- **动作**：改用"入场后前向收益分布 / MFE 达成率"评价选股质量（与出场解耦）；小样本用 bootstrap 置信区间而非点估计。
- **代价/风险**：中，评测脚本重构。

## 四、优先级与依赖（第一性排序）

```
L1 补度量地基 (前置, 无争议, 立即)
     │
     ├──> R1 MFE=0 早止损 shadow (最高即时ROI, 止血)
     │        └──> R2 MFE=0 跨日封禁 (并入R1 shadow)
     │
     ├──> L2 修评测尺子 (S1的前提)
     │        └──> S1 选股改以"预测MFE>0"为目标 (治本, 最慢)
     │
     └──> R3 让利润端跑久 (对称改造, 与R1配对)
```

- **止血序（周级见效）**：L1 → R1 → R2。
- **治本序（月级见效）**：L1 → L2 → S1。
- **R3** 与 R1 配对，构成"截断亏损 + 让利润奔跑"的完整不对称出场。

**核心判断**：R1（MFE=0 早止损）是唯一"低风险 + 高即时 ROI + 数据铁证（98%亏损/0%胜率）"的一刀，应最先落 shadow。但它是**止血不是治愈**——真正的病在源头 S1（50% 单子进场即错）。若只做 R1 不做 S1，系统会从"进错+慢出血"变成"进错+快止损"，减亏但仍不产生 alpha。**必须两条线并行：R 线止血，S 线造血。**

## 五、关键分歧（供辩论方逐条攻击）

1. **MFE=0 早止损会不会破坏利润端？** 反方可能主张：某些最终大赢的单也曾短暂 MFE=0。需回测：MFE>1% 的 84 笔大赢单里，有多少在生命早期有过"持续 T 分钟 MFE=0"的阶段？若比例高，R1 的时间阈值 T 必须足够大。（这是 R1 能否成立的命门）
   - **作者自验（诚实交出）**：尝试用 `position_snapshots`（290行 tick 级 unrealized_pnl）验证此命门，**失败**——该表时区混乱、跨交易日混叠、含异常值（UVXY 出现 -2490% pnl_pct）。**结论：现有数据无法验证 R1 命门。** 这不是小事：它意味着 **R1 在 shadow 落库产出干净的 MFE 时序之前，其时间阈值 T 无法标定**。→ 直接强化"L1（补度量地基）必须严格前置于 R1"的结论；R1 的第一步不是改出场，而是**先落库每笔单子的 MFE 时间演化**。
2. **中位数为负是否意味着策略根本无效？** 还是说这是"高盈亏比策略"的正常形态（靠少数大赢覆盖多数小亏），只要期望为正就可接受？
3. **S1 用"预测 MFE>0"当选股目标，会不会过拟合到 MFE 这个特定指标？** MFE 是出场质量的果，用它当入场目标是否倒因为果？
4. **R3 让利润跑久，与 time-exit DEB "4h 持有更优" 是否冲突？** 需明确 MFE>1% 子集是否适用不同的持有逻辑。
5. **三层同时动会不会互相干扰验证？**（如同时改入场和出场，无法归因是谁的功劳）——是否应严格串行 shadow。
