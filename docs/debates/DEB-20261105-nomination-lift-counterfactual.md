## 3. 数据裁决 (主代理复算, 不是投票)

用裁定后的口径实跑 (`scripts/non_nominated_counterfactual.py`, 2026-07-01..10-30, 81% 覆盖):

| 口径 | 未提名 n / 均值 | 提名 n / 均值 | 差 (提名−未提名) 日聚类 95% CI | 裁决 |
|---|---|---|---|---|
| T+1 | 2205 / −0.12% | 1498 / −0.11% | **+0.15pp** [−0.33, +0.65] | 含 0 |
| T+3 | 2089 / −0.27% | 1433 / −0.13% | −0.09pp [−0.61, +0.50] | 含 0 |
| T+5 | 1983 / −0.38% | 1399 / −0.33% | **−0.60pp** [−1.22, +0.03] | 含 0 (贴近 0 下界) |

分期看更清楚: 10 月提名 BUY 的 T+5 方向调整后 −3.65% (胜率 29%), SELL_SHORT +3.12% (59%) ——
**当月问题是多头选股, 不是"没提名更多标的"**; 而 7-9 月两组都在 ±1% 内打平。

**裁决: 不认定"提名"具备选择性** (按预注册: CI 含 0 ⇒ 不认定)。注意这是**无证据**,
不是"证明无选择性": 两方都指出的"未提名流动性折价"未建模, 一旦把折价计入, 差值会向正方向移动,
所以正负都还不能锁死。
