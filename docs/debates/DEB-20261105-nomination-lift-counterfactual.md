## 3. 数据裁决 (主代理复算, 不是投票)

用裁定后的口径实跑 (`scripts/non_nominated_counterfactual.py`, 2026-07-01..10-30, 81% 覆盖):

| 口径 | 未提名 n / 均值 | 提名 n / 均值 | 差 (提名−未提名) 日聚类 95% CI | 裁决 |
|---|---|---|---|---|
| T+1 | 2205 / −0.12% | 1498 / −0.11% | **+0.15pp** [−0.33, +0.65] | 含 0 |
| T+3 | 2089 / −0.27% | 1433 / −0.13% | −0.09pp [−0.61, +0.50] | 含 0 |
| T+5 | 1983 / −0.38% | 1399 / −0.33% | **−0.60pp** [−1.22, +0.03] | 含 0 (贴近 0 下界) |

分期看更清楚: 10 月提名 BUY 的 T+5 方向调整后 −3.65% (胜率 29%), SELL_SHORT +3.12% (59%) ——
**当月问题是多头选股, 不是"没提名更多标的"**; 而 7-9 月两组都在 ±1% 内打平。

**裁决: 不认定"提名"具备选择性** (按预注册: CI 含 0 ⇒ 不认定)。注意这是**无证据**,
不是"证明无选择性": 两方都指出的"未提名流动性折价"未建模, 一旦把折价计入, 差值会向正方向移动,
所以正负都还不能锁死。

**金丝雀 (C1) 实测**: 已成交提名行 n=717, 前瞻收益与已实现 `pnl_pct` 的相关
**+0.325 (T+1) → +0.258 (T+3) → +0.210 (T+5)** —— 方向正确、随 horizon 单调衰减 ⇒
join 没有符号/日期错位; 相关性弱是"盘中 SL/TP 退出 vs 裸持有"的口径差, **不作废读数**。

### 3.1 三臂对照 (GLM R2 攻击①的处置: 占位行盘中被发现 ⇒ 开盘入场是前视)

| 入场臂 | 含义 | T+5 未提名 | T+5 提名 | 差 (提名−未提名) CI | 读数 |
|---|---|---|---|---|---|
| open | 两侧都开盘 (占位组有前视) | −0.38% | −0.33% | −0.60pp [−1.25, **+0.02**] | 含 0 |
| close | 两侧都收盘 (同尺但抹掉提名合法隔夜) | −0.31% | −0.23% | −0.59pp [−1.18, −0.03] | 排除 0 |
| **mixed** | **提名=开盘 / 占位=收盘** (唯一对齐信息时点) | −0.31% | −0.33% | **−0.68pp [−1.28, −0.08]** | **排除 0** |

**读数 (按预注册口径与诚实边界)**:
- mixed 臂 T+5 差值排除 0 ⇒ 按代码判据输出"**提名为负选择**"。
- 但**不能当裁决用**: ①T+1/T+3 三臂全部含 0; ②本批共比较 3 臂 × 3 horizon = 9 组,
  未做多重比较校正; ③单一窗口 (7-10 月)、5 日裸持有、不含费用。
- 因此正确表述是: **"在该窗口、信息时点对齐的口径下, 被提名组的 5 日前瞻比未提名组低约 0.7pp,
  方向偏负; 证据强度不足以支持'提名有害', 更不足以支持'提名率低是瓶颈'。"**
- 前视修正的方向也值得记录: 用收盘价消除占位组前视后, 占位组均值反而**变好**
  (−0.38% → −0.31%) —— 因为该窗口不少 mover 开盘后回落, 收盘入场躲掉了这段下跌。
  ⇒ "开盘入场=高估机会" 的直觉在本窗口**不成立**, 该攻击成立但方向相反, 已如实保留。

## 6. 这套东西**不能**回答什么 (随读数一起披露)

1. **不是策略 PnL**: 裸持有, 不含 SL/TP/费用/盘中退出 ⇒ 不得与 `trade_records` 净额混用。
2. **未提名无方向**: 只能问"多头口径上是否被落下", 不能问"若按 correct side 做会不会赚"。
3. **流动性折价未建模**: 见 §3 裁决的限定。
4. **不能证明"提名该扩/该缩"**: 它只能证明"提名是否带来了可测的选择性"; 扩不扩是另一个决策 (需 DA 侧改 prompt + 预注册)。
5. **人群是混合的 (C3 指出, 已核实)**: `playbook_instructions` 没有任何字段能区分
   "DA 看过并拒绝" 与 "盘前 Finnhub mover、DA 根本没见" ⇒ 本批 Lift 是混合口径。
   拆开需要 pipeline 落 `universe_source` 标签 (下一版), 在此之前不得用本读数单独支持"提高提名率"。
6. **金丝雀只验证 join, 不验证结论**: 它排除"符号/日期错位", 不排除"人群混杂/流动性折价"。
