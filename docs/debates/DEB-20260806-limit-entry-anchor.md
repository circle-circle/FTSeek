## 二、主张

### 主张1: 带边缘限价 (cap_near) 不值得做 — 测量证伪
- Δ=+$6.39/163 笔, 162/163 触发时已市价化。触发=价格已穿越带边缘, 挂带边缘限价≈市价帽。
- S6 原判"维持市价"在带边缘口径下**成立**, 但仅在此口径。

### 主张2: 锚定价限价 + 追单上限 — 进影子验证 (核心主张)
- 实测上界 +$229/33 交易日 (≈+$7/天), 零漏单, 延迟 P50 0.6min。
- 机制借鉴 freqtrade: 默认限价入场 + `unfilledtimeout` 撤单 + `adjust_entry_price` 回调重挂 (追单上限模式) — 映射为: **触发时挂 anchor 限价, T+N min 未成交则改挂带边缘 (价格帽), 再 N min 未成交转市价或撤单**。
- 影子设计 (record-only, 预注册): 触发时刻落 `data/limit_entry_shadow.jsonl` (anchor 限价/带边缘/触发价/假想成交判定所需字段), 次日用 1-min bar 重放判定成交/延迟/改善;
  - 主门: n≥60 真被动触发, 净改善 >0 单侧 α=0.025 (σ 用影子实测);
  - 停止规则: 脏 bar 贡献 >30% 剔除后净效应翻负 / 漏单率 >10% / 漏单赢家成本 >改善 50%;
  - hedge: 影子期后毕业只用裁决后新数据 (out-of-time), 禁见数后换边 (anchor/deep_far 二选一已在立案锁定 anchor)。
- 不触碰执行路径, 零风险。

### 主张3: deep_far 深被动 — 不立案
- 成交率 8.6% = 变成另一个策略; 漏单子集实际净 -$497.55 (避开的全是输家) 是典型 4 格挑最优选择偏差, 立案即违规 (预注册规范§选择偏差条)。

### 4.2 反方 (五攻击)

1. **触价=成交乐观偏差 — 成立但微弱**: 恰好触价 (penetration≤1tick) 仅 2 笔 (GS/NIO, ~$9, 4%); 剔除后 +$220。修正: 影子对 pen≤1tick 标记, 主门含/剔两切。
2. **跳空按 bar open — 成立, 比立案自查严重一个量级**: fill 优于限价 >0.1% 共 **12 笔/$105.46**, 按限价仅值 $16.54; 且全部落在触发 bar 内 (bar open 是触发前印价 → **物理不可能成交**)。haircut -$88.92 (39%)。
3. **脏 bar 叙事 — 定性错误但剔除直觉正确**: MSFT 那根 bar 本身连续 (+0.02%), "脏"实为攻击2的标签伪影; top5=48% 集中属实; **且样本内符号检验退化** (机械非负 → 41/41 全非负是构造产物, 无检验力) — 唯一证伪途径是影子前向。
4. **延迟成交→退出路径失真 — 成立, 杀伤力最强**: 退出逻辑全部入场价/时间锚定 (breakeven 0.5% 臂/MFE_STALL/TIME_EXIT)。通道① COIN δ=20.6min 时移后退出恶化 $38.5 (吃掉所计改善 76%); 通道② 9/46 笔 CF 保本臂化翻转 (MA/PDD 恰坐 0.5% 阈值翻转区), 净上界 $86.6。**方向系统性偏乐观**。
5. **选择偏差残余 — 成立 (变体)**: ≥12 cell 里挑 anchor = pick-best 变体; 胜者诅咒: 修正后设计效应量 **+$39~64/33天 ≈ $1.2~1.9/天** (立案隐含 $7/天, 高估 2.8~5.8×); 影子 α=0.025 在配置全冻结下仍有效, 但功效设计禁用 +$229 先验。

### 4.3 方法论 (门径修正条文, 已并入§五终裁候选)

1. **检验族错误 → 改配对反事实 sign-flip 置换** (规范§1族②), B=10,000, 单侧 α=0.025; **δ 定义必须完整**: 限价成交按限价 (≥0) / 追单成交按追单价 (可负) / 撤单漏单 δ=−实际净 (可负) — 否则 H0 被构造否证 (选样恒等式, 门A 同型)。
2. **功效**: 163 笔重放 δ̄=$4.21/σ=$4.29 (5min 追单口径真被动子集) → n=60 功效 >99% (MDE=$2 需 n=39); 供给 2.56 真被动/活跃日 → n=60 ≈ 23 活跃日 (~5 周)。**诚实声明**: 功效系恒等式域上界, 毕业须双条件 (均值 δ≥$1/笔 **且** bootstrap CI95 下界>0)。
3. **零膨胀**: 117 个市价化恒等零**不得池入**主检验 (人群=真被动); 设符号检验共门 (对 top5 幅度集中免疫), **双门同过才毕业**。
4. **停止规则**: 现行三条含选择性停止通道 → 改"只降级不重置": 触发任一 → 降级为观察 (n 继续累积, 参数回炉须重新预注册); 判定限每周五 scorecard 固定检视点机械执行; 脏 bar 事前定义 (成交 bar 跳空>2×ATR14 且按 open 成交)。
5. **毕业→实仓二阶段门**: 灰度 50% 仓位, n≥40 真被动实仓触发 (MDE@80%=$1.95/笔 ≈16 活跃日); 三闸全过才全量: ①确认闸 (同影子主门口径) ②保真闸 (5min 成交率较影子降 ≤15pp 且追单笔均 δ_live≥0) ③伤害闸 (非劣检验拒 H0: δ≤−$1 即回滚)。
