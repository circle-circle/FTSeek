# DEB-20260729-reanchor-knife-window: 入场重锚 (Lever A) 定性 — 文档语义 vs 实际行为矛盾

> **状态**: 🔶 新起案 (作者 Qoder) · 待辩论方证伪 → 待用户裁决
> **分类自评**: 做减法 (O1) 或信号行为变更 (O2, 需 shadow) — 视裁决方向定; 当前 record-only 取证零 live 变更
> **预注册判据**: §五 · **辩论方任务**: §六

## 一、发现 (几何实锤 + 遥测实锤)

**机制链**: 盘前锚定 entry_price + 非对称入场带 (LONG [锚-3%刀口, 锚+5%追高] / SHORT 镜像)
→ 盘中 30min 轮询触发 → 带外时 reanchor (Lever A): 漂移 ≤4% 则重锚触发, 下游 reprice 重算 SL/TP。

**几何事实**: LONG 追方向带边 +5% > reanchor 上限 4% → **顺方向 (追高) 救援几何上不可达**;
唯一可触达窗口 = 逆向跌破刀口 3% 但未过 4% → **reanchor 物理上只能在"接飞刀方向"触发**。

**遥测实锤** (`data/trigger_miss_telemetry.jsonl` 全量):
- reanchored 事件 99 次, **99/99 全在逆方向 (刀口), 顺方向 0 次**;
- 非测试事件 27 次: NVDA×22 (同一指令轮询重复触发) + INTC/NTES/AMZN/MU/TSM 各 1;
- **全史 184 笔成交 entry_path 全部 normal — reanchor 实弹命中零** (有记录以来从未转化为成交)。

**语义矛盾 (核心指控)**:
1. **文档与行为相反**: 代码注释称 reanchor 用于 "带内未触发但漂移在上限内, 用盘中价重锚触发"
   (语义=追方向救援) — 该语义是**死代码**; 实际行为 (刀口救援) 无任何文档声明;
2. **与刀口层打架**: knife floor 3% 的存在意义 = "逆向 3% 即 thesis 可疑, 不入场";
   reanchor 说 "逆向 3-4% = 重新锚定, 入场" — 同一管线两个保护层语义直接冲突;
3. **绕过前科 + 检查豁免**: 07-20 刚修过 reanchor 绕过量能门; 且 reanchored 单**跳过
   "SL 已穿越不入场"检查** (设计上因 SL 将 reprice) — 原始止损是 thesis 的一部分,
   跌穿原 SL 的 LONG 换更低 SL 照样进场;
4. **三来源共享暴露** (管线层机制, 来源无差别): UE 最危险 (逆向漂移=事件 thesis 当场证伪,
   reanchor 买"已失败的事件") > DA (慢性漂移, NVDA 22 次实证) > topup (技术破位, 较低)。
   对照: 顺方向大 gap 保护完好 (07-28 UE SHORT 低开 9-19% 被 4% 上限正确拒绝)。

## 二、选项

- **O1 删除 reanchor (做减法, 作者倾向)**: 实弹零命中 + 语义矛盾 + 有前科。
  路径 = 军规做减法三步: 证零消费 (T3) → `entry_reanchor_enabled: false` (开关已存在, 一行)
  → 观察一周 → 代码退役。触发分布改变 → 虽实弹为零, 仍按纪律 shadow/对照一周;
- **O2 承认刀口语义 + 补护栏**: 文档改诚实 (这是"逆向 3-4% 捞回机制") + 加恢复确认
  (reanchor 后须价格重新站回新锚某确认位才放行, 而非跌到哪里买到哪里) + 补回 SL 穿越检查
  (以 reprice 后新 SL 计)。行为变更, 须 shadow 先行, 工作量明显大于 O1;
- **O3 对齐文档 (做真·追方向救援)**: 上限抬到 >5% — 等于允许追 6-7%, 与 runaway 防护
  直接冲突。**明确不建议**, 列出仅为完备。

**作者立场**: O1。一个零实弹、文档说谎、语义与保护层打架的机制, 举证责任应在"保留方"。
O2 的护栏语义等价于"逆向漂移后等恢复确认" — 那正是**不带 reanchor 的原生带逻辑本身**
(价格回带内自然触发), 所以 O2 修复后的 reanchor ≈ 没有 reanchor。

## 六、辩论方任务清单 (证伪式)

## 七、诚实边界 (作者自陈)

1. **实弹零 = 紧迫性低**: 本案是"趁没咬人定性", 不是事故响应; 若辩论期发现更高优先级事项, 本案可挂起不烂尾 (状态栏保持);
2. **E1 表可能样本不足**: 27 事件去重后可能 <20, 且集中于少数交易日 → 证据强度可能只够"倾向"不够"定论", 届时按"证据不足但零实弹机制举证责任在保留方"处理, 不强行收敛;
3. **entry_path 字段存疑**: 全史 normal 可能因 reanchored 未落入 trade metadata (埋点缺失) 而非真零命中 — T1 辩论方须一并验证此埋点链路 (reanchored → execute → metadata 是否透传)。
