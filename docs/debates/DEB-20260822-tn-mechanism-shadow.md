## 背景

2026-08-22 用户提问："目前统计 T+1/T+3/T+5 的长持收益是按收盘价还是 peak？因为存在波动性，
按照锁利机制这个差异是否会很大？"

**审计发现**：
1. `ic_tracker.py` 的 `backfill_forward_returns` 100% 用收盘价（L298: `close = bars_by_date[check_str].get("close")`），
   无任何 peak/机制调整口径。
2. 这导致 T+N 统计是"傻等到收盘"的**悲观下界**——而真实机制（锁利 peak回撤0.8% / 净保本+0.4% / SL−5%）
   在盘中就截断亏损、锁定利润，实际收益系统性高于收盘价口径。
3. 实弹量化（8月127笔已平仓）：T+1 close − 机制模拟 = **−0.66pp/笔**（机制实际比收盘价多拿 0.66 个点）。

**结论**：需要一个"机制调整后"的 T+N 影子口径，与 raw 收盘价口径并行——raw 测方向预测力（IC 用），
影子测机制执行后的真实收益（收益报告/参数优化用）。用户裁决："落 T+N 影子字段"。

## 目标

1. 落地 `fwd_return_t1_adj / t3_adj / t5_adj` 三个影子字段（record-only，零消费方）。
2. 用日K OHLC 回放模拟真实退出机制（保本武装→锁利→SL→收盘兜底），参数读 config 实值不硬编码。
3. 首轮量化：机制到底值多少？回答"锁利/保本机制是否真在赚钱"这个此前只能定性回答的问题。

## 实现（已落地）

### 改动清单

| 文件 | 改动 | 性质 |
|---|---|---|
| `app/playbook/db.py` | 迁移表新增 3 列 `fwd_return_t{1,3,5}_adj` REAL + `_TRACKING_FIELDS` 白名单 | 列迁移（幂等） |
| `app/playbook/ic_tracker.py` | 新增 `_sim_mechanism_adjusted_return()` + backfill 循环内影子回填 | 只读回填 |

### 机制模拟逻辑（与 `_compute_dynamic_effective_sl` 同源参数）

统一浮盈坐标系（LONG/SHORT 完全对称）：`profit(px) = sign*(px-entry)/entry*100`

每日逐根日K回放（entry 日 → T+N 日）：
1. **峰值更新**：当日最有利点（LONG 用 high / SHORT 用 low）
2. **保本武装**：峰值 ≥ `breakeven_at_pct`(0.4) → SL 抬到 `fee_pad`(0.4费用+0.2滑点=0.6)
3. **锁利**：`trailing_enabled` 时 SL = peak×(1−0.8%)，不低于保本线
4. **profit_override**：无 trailing 且峰值 ≥1.5% → SL = peak×(1−0.5%)
5. **SL 判定**：当日最不利点（LONG 用 low / SHORT 用 high）击穿 effective_sl → 按 SL 价成交
6. **兜底**：无触发 → T+N 收盘价

参数全部从 `get_playbook_config()` 读实值，与生产 `_compute_dynamic_effective_sl` 同源。
回滚：删 3 列 + 删函数 + 删 backfill 注入块即可，零下游依赖。

### SHORT 方向修复（首轮发现的 bug）

初版 SHORT 逻辑不对称：用 low 判 SL 导致方向反了（SHORT 的 low 是"更赚"不是"更亏"）。
修复为统一浮盈坐标系后，SHORT 用 high 判 SL（价格反弹破上方止损）。
验证：MRK SHORT −1.33% → adj +1.34%（+2.67pp），GS SHORT −2.52% → adj +1.18%（+3.70pp）。

## ⚠️ 勘误（2026-08-22 同日，用户三问触发验证）

**首轮结论"+1.59pp/笔、WR 92.5%"作废。** 验证方法：adj 模拟 vs 127 笔真实成交逐笔对撞
（同 symbol+date join，真实值含费含滑点）。

| 口径 | 平均每笔 | 真相 |
|---|---|---|
| adj 模拟（毛利） | +1.53% | 我报的数字 |
| adj 模拟（扣费净） | +1.40% | 扣双边费用 ~10bps |
| **真实成交净利** | **−0.22%** | **8 月净 −$631** |
| **模拟 − 真实** | **+1.6pp 乐观偏差** | **WR 92.5% 是假的** |

### 三个失真源（按量级排序）

1. **日K路径不明（最大）**：日内 high/low 顺序未知，模拟假设"先涨后跌"（乐观）。
   隔夜跳空时灾难性失真——8/18 MU/FIX/CAT 日K low 未破 −5%，模拟判"持有"，
   实际开盘跳空 −5% 以下止损，4 笔各高估 6-9pp。
2. **未模拟其他出场**：MFE_STALL/DEAD_SIGNAL/PATIENT_EXIT 等，只模拟了 SL/锁利/保本。
3. **毛利非净利**：费用 ~10bps/笔，8 月费用 $646 是毛利 $15 的 42 倍。

### 修正后的真相

- **机制真实价值 ≈ 0**（不是 +1.59pp）。
- 机制确实在"减少亏损"（毛利从深亏救到≈0），但**救不回费用**。
- 保本线 0.6% 毛利 − 费用 ≈ 0 或微亏，"保本救命 124 笔"是毛口径幻觉。

### 用户原假设检验

> "方向预测无法精准，但执行策略和纪律是可以保证的"

**数据证伪**：执行纪律确实减少亏损，但在当前交易频率（140 笔 × 10bps）下，
**方向 edge 太薄（毛利≈0），连费用都覆盖不了**。执行纪律再好也只是在"少亏"层面打转，
不是"保证不亏"。真问题不是"锁利参数调多少"，而是"毛利 edge 能否覆盖费用"。

### 本字段的正确定位

adj 影子字段本身仍有价值（close vs 机制的路径差异量化），但：
- **必须扣费解读**（净口径）
- **必须标注路径局限**（日K顺序不明 + 隔夜跳空失真）
- **不能作为"机制价值"的证据**（首轮误用已勘误）

## 首轮量化结果（378 条指令，8/21 截点）

### 整体对比

| 口径 | 平均收益 | 胜率（不亏钱） | 样本 |
|---|---|---|---|
| `fwd_return_t1`（raw 收盘价） | +1.35% | 58.2% | 359 |
| `fwd_return_t1_adj`（机制调整） | **+2.94%** | **92.5%** | 359 |
| **差值** | **+1.59pp** | **+34.3pp** | — |

T+3 / T+5 同方向：+1.56pp / +1.13pp。

### 收益分布迁移（机制到底做了什么）

| 收益桶 | raw 笔数 | adj 笔数 | 迁移 |
|---|---|---|---|
| 深亏 <−2% | 77 | **17** | **−60** ← SL 兜底 + 保本救命 |
| 浅亏 −2%~0% | 73 | **10** | **−63** ← 保本线截断 |
| 微利 0%~0.4% | 11 | 0 | −11 ← 被锁利抬走 |
| 中盈 0.4%~2% | 65 | **169** | **+104** ← 保本+锁利集中区 |
| 大盈 >2% | 133 | 163 | +30 ← 锁利后仍保住 |

**核心发现**：124 笔（34.5%）raw<0 的亏损单被机制救成不亏或微利；
60 笔深亏被 SL/保本砍到只剩 17 笔。机制把"方向 58% 胜率"转化为"92.5% 不亏钱"。

### 典型案例

| 标的 | 方向 | raw T+1 | adj T+1 | 机制动作 |
|---|---|---|---|---|
| BULL | LONG | −8.25% | +3.94% | 盘中冲高触发锁利，回落前已锁住 |
| GS | SHORT | −2.52% | +1.18% | 空头浮盈后反弹，保本线截断 |
| UBER | LONG | −0.78% | +0.91% | 保本武装后回落，+0.6% 出场 |
| LLY | LONG | +0.61% | +2.59% | 锁利在峰值附近出场 |
| RIVN | LONG | +7.81% | +2.77% | 锁利 0.8% 回撤截断（左上利润 −5pp） |

最后一行是关键：**RIVN 这类大赢家会被锁利截断左上利润（−5pp）**——这是机制的代价，
但被救的 124 笔亏损单（+1.59pp 平均）远远覆盖这个成本。

## 口径使用纪律（防误用）

| 口径 | 测什么 | 用在哪 | **不能用在哪** |
|---|---|---|---|
| `fwd_return_t{N}`（raw） | 信号方向预测力 | IC 计算、毕业门禁、方向决策 | 收益报告（偏悲观） |
| `fwd_return_t{N}_adj`（影子） | 机制执行后真实收益 | 收益报告、锁利参数优化、实盘预期 | **IC/毕业判定**（测的是机制不是信号） |

**铁律**：adj 口径不能进 IC——它把"机制好"和"信号准"混在一起，
会让一个 58% 胜率的信号看起来像 92.5%，这是对信号预测力的系统性高估。

## 复现方法

```bash
cd /opt/ftseek/FTSeek-US && python3 -c "
import sqlite3
c = sqlite3.connect('data/ftseek_us.db')
rows = c.execute('''
    SELECT fwd_return_t1, fwd_return_t1_adj FROM playbook_instructions
    WHERE fwd_return_t1 IS NOT NULL AND fwd_return_t1_adj IS NOT NULL
''').fetchall()
n = len(rows)
raw_avg = sum(r[0] for r in rows)/n*100
adj_avg = sum(r[1] for r in rows)/n*100
raw_wr = sum(1 for r in rows if r[0]>0)/n*100
adj_wr = sum(1 for r in rows if r[1]>0)/n*100
print(f'n={n} raw={raw_avg:+.2f}%(WR{raw_wr:.0f}%) adj={adj_avg:+.2f}%(WR{adj_wr:.0f}%) diff={adj_avg-raw_avg:+.2f}pp')
"
```

## 附：毛利 Edge 拆解裁决报告（2026-08-22，用户裁"需要"）

> 数据来源：`data/ftseek_us.db` `trade_records` 表，8 月已平仓 140 笔（含费含滑点真实成交）。
> 口径：毛利=realized_pnl，净利=COALESCE(pnl_net, gross−fees)，费用线=10bps（双边实测均值）。

### 一、生死分层：净利贡献排名（谁在赚钱谁在烧钱）

| 出场类型 | n | 净利合计 | 定性 |
|---|---|---|---|
| **SL_TRAIL_LOCK（锁利）** | 34 | **+$1,927** | 🟢 **唯一利润引擎** |
| **PRE_CLOSE_EXIT** | 10 | **+$390** | 🟢 次要利润 |
| SL_BREAKEVEN（保本） | 49 | −$120 | 🟡 打平偏亏 |
| TIME_EXIT | 3 | −$44 | 🔴 |
| PATIENT_EXIT_EOD | 4 | −$198 | 🔴 |
| DEAD_SIGNAL_EXIT | 15 | −$343 | 🔴 |
| PATIENT_EXIT_STOP | 3 | −$287 | 🔴 |
| MFE_STALL_EXIT | 14 | **−$606** | 🔴 大失血 |
| **SL_INITIAL（止损）** | 6 | **−$1,346** | 🔴 **最大单笔失血** |

**结构**：锁利+PRE_CLOSE 赚 +$2,317，其余 8 类全亏 −$2,948。利润极度集中在"拿住赢家"的两条路径。

### 二、能覆盖费用线（10bps）的细分（仅三类）

| 细分 | n | 毛利avg | 净利avg | 净利WR |
|---|---|---|---|---|
| LONG 锁利 | 30 | +1.18% | +1.04% | 90% |
| LONG PRE_CLOSE | 8 | +1.62% | +1.48% | 75% |
| SHORT 锁利 | 4 | +1.45% | +1.32% | 100%（n小） |

其余全部在费用线以下。保本出场（n=49，毛利仅 +0.07%）印证勘误：0.6% 毛利垫被费用吃到净亏。

### 三、方向维度：SHORT 被严重低估

| 方向 | n | 总毛利 | 总净利 | 毛利WR |
|---|---|---|---|---|
| LONG | 120 | −$156 | −$709 | 56.7% |
| **SHORT** | 20 | **+$171** | **+$78** | **70%** |

SHORT 是唯一净利为正的方向（占比仅 14%）。直接命中 8/16 用户核心要求"真正有空头产出"——
数据证明 SHORT edge 强于 LONG，但供给枯竭。

### 四、锁利机制的对价：平均左上 0.90pp

34 笔锁利：实现中位数 +1.07%，MFE 峰值中位数 +1.85%，平均每笔少拿 0.90pp。
- 最痛：TSM 锁利 −1.15%（MFE 曾 +1.33%）、ALAB −0.51%（MFE +1.08%）——锁利后被甩下车
- 但这是用 0.9pp 左上换确定性的对价，34 笔净 +$1,927 证明值得

### 五、系统真实盈利公式

```
锁利(+1,927) + PRE_CLOSE(+390) − 止损/挂起/DEAD_SIGNAL(−2,948) − 费用(646) = −631
```

### 六、8/29 终裁输入：三个可执行方向（按 ROI 排序）

1. **砍 MFE_STALL_EXIT**（−$606，14 笔毛利全负）：8/15 已回放否决（config `mfe_stall_exit_enabled: false`），
   但 14 笔是历史残留 + shallow_hold 变体。**需核查为何仍在触发**。
2. **SHORT 供给扩容**：唯一净利为正方向仅 20 笔。提到 40 笔且保持 edge，8 月可直接转正。
   8/16"空头真产出"裁决的数据背书。
3. **锁利参数勿动**：0.8% 回撤换 +$1,927，左上 0.9pp 是合理对价。勿因 TSM/ALAB 锁早案例收紧。

**核心结论**：系统不是"全都不行"，而是一个利润引擎（锁利）在养八个亏损出血点。
8/29 终裁关键不是"有没有 edge"（锁利证明有），而是**能否把亏损出血点砍掉一半以上**。
