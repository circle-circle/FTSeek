# 十月裁决窗口统计功效前置计算

- 日期: 2026-08-24 (OKR-2026-09 Day 1, 冻结期起点)
- 关联: DEB-20260823-zero-gross-edge (E2 延期十月), 宪章第9律 (日聚类+MDE), OKR-2026-09 KR1
- 工具: `scripts/october_power_analysis.py` (只读DB, 可随时重跑; JSON 落 data/october_power_report.json)

## 一、为何前置

8月末局教训: n=321 攒够了仍分不清噪声。十月 E2 若不提前反推"能分辨多小的效应",
大概率重演空手而归。本计算回答三个问题: 十月窗口的 MDE 是多少 / 分辨 δ* 需多少天 /
攒笔数能否替代拉长时间。

## 二、口径

与 ic_tracker/signal_ic_tracker 完全一致 (宪章第9律):
每日值=当日平仓单 pnl_net 均值, t=mean/(sd/√n), **MDE(n)=2.8×sd/√n** (双侧α=0.05+功效80%);
双臂对比保守上界 MDE_2arm=2.8×sd×√(2/n)。
样本: 330 笔平仓 PLAYBOOK_SIM/LIVE · 40 个交易日 (2026-06-24→08-21) · 名义额中位 $3,853。

## 四、战略结论

1. **十月窗口在"净PnL/笔 vs 0"判据下功效≈零**: 只能分辨 ≥$94/笔 (243bps) 的效应,
   而 8 月实测毛期望仅 +$0.10/笔 —— 现实中不存在能被它分辨的 edge。这不是攒数据能解决的,
   是判据与窗口的匹配问题。
2. **同日加仓无增益**: 98% 方差来自日间效应, 供给侧任何优化 (提高信号量/放开帽) 对
   功效改善 ≤1%。宪章第9律的直觉被定量证实。
3. **裁决设计必须换轨**, 候选 (按可行性排序):
   - **换尺子**: 用信号级 T+5 日聚类 IC 作主判据 (周报已实跑: pooled 0.1447/日聚类
     0.1385, t=2.63, 距可分辨一步之遥) —— 信号 IC 的日间波动远小于逐笔 PnL;
   - **换设计**: 同标的同信号配对 (如 tripwire-on/off 对照组按日配对), 以配对差值
     sd 重算功效, 通常大幅收窄;
   - **换窗口**: 判据不变则预注册为季度窗 (60日 MDE=$57/笔, 仍不低) 并接受高不确定性。
4. **对 E2 预注册的直接要求**: 无论选哪条, 预注册文档必须写明 [判据口径, 窗口长度,
   预计 MDE] 三元组, 且 MDE 必须 < 预期能分辨的现实效应 —— 否则该预注册自始无效。
