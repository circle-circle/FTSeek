- 日期: 2026-10-17
- 缘起: 用户问「OVERNIGHT_GAP_STOP 导致亏损的标的/指令有何共性？溯源产出和过程，能否减亏甚至反转盈利？」

  `data/shadow/eod_depth_gate_shadow.jsonl` (RFC-079 影子 52 行, 50 可结算)
- 关联: RFC-141 §5.8 (地平线错配首诊) / RFC-079 (EOD 深水闸影子) / DEB §47 (gap_dive_halve) /
  8-20 裁决 (loser_overnight_max_depth 99=禁用) / early_tight_sl (9-1 毕业)

## 1. 家族画像 (11 笔, 2026-08-28 ~ 10-14, 合计 **−$3,472.13**)

| 共性 | 读数 | 判别力 |
|---|---|---|
| 方向 | **11/11 LONG** (零 SHORT) | 必要不充分 (同期 LONG 大多数不亏) |
| 叙事 | 全部「低吸/回调/错杀修复」(盘前微跌低吸、回踩 MA10/VWAP、趋势延续回踩) | **无** — 恢复者同叙事 (§4) |
| 波动桶 | 9/11 vol_bucket=high, ATR 3.3~6.2% | 无 — 恢复者 4/5 同桶 |
| 入场窗 | 9/11 在 09:35-09:49 开盘窗 (例外: 再入场 13:29 / AMD 10:31) | 弱 |
| anchor_dev | 10/11 ≤0 (执行价已低于生成锚 = 边跌边接) | 无 — 恢复者 3/5 同负 |
| 当日 MFE | **全部 <0.5%** (0~0.474%, 从未真正盈利) | **强** (§3 决定性) |
| MAE | 4.6~6.7% (收盘前未被任何止损触及的浅跌 + 隔夜跳空) | 事后量, 不可门前 |
| 环境 | VIX 13.6-15.0 窄带, spy 全 above_ma20 | 低波温盘 ⇒ 个股 4-6% 跳空是特异风险 |
| 计划 SL | 全部 ≈-5%, **全部被隔夜跳空跳过** (次日 09:30-09:49 才成交) | 结构性缺口 |
| fwd_return_t1 | 全负 (-1.8%~-8.4%) | 事后量 |

**机制链 (完整病灶路径)**:
低吸叙事 LONG → 开盘窗触发成交 → 日内阴跌 -1~-2.5% (MFE<0.5% = 方向从未被证实;
early_tight_sl 的 ATR 收紧档 0.5×ATR≈2-2.5% 对高 ATR 标的日内够不着) →
EOD `loser_overnight` 豁免持夜 (8/15 裁决, W_WEEK 修复窗) → 隔夜 gap -4~-6.7%
**直接跳过 -5% SL** → 次日开盘 OVERNIGHT_GAP_STOP。
止损对隔夜跳空结构性无效: SL 距离 (5%) ≈ 标的 1×ATR (4-6%), 跳空幅度同量级。

| 防线 | 状态 | 为何没接住 |

| RFC-141 2min 门 | 生产中 | §5.8 已判: 地平线错配, 只接到 4/8 |

## 3. 决定性发现: 当日 MFE 把灾难和恢复者干净分开

RFC-079 影子 52 行 (50 可结算) join 交易 MFE:

| 桶 | MFE | 结局 |
|---|---|---|
| 灾难 (4 笔 OGS, 影子深度≥2.5% 行) | 0.0000 / 0.2161 / 0.2910 / 0.4744 | 全 <0.5% |
| 恢复者 (5 笔) | 0.4715 / 0.6029 / 0.6071 / 0.8128 / 1.3209 | 4/5 ≥0.6% |

机制自洽: **「当日从未盈利 0.5%」= 论点从未被市场证实**, 不配占用隔夜跳空敞口。
与 early_tight_sl (30min MFE<0.3%) 同一哲学在不同时点的延续, 非新造因子。

**反事实回放** (EOD 以 decision_price 平仓 vs 实际持有结局, 首触发日记账):

| 规则变体 | 捕获 OGS | ΣΔ | 误杀 |
|---|---:|---:|---|
| MFE<0.5% ∧ depth≤-2.5% | 4 笔 | **+$493** | 1 (US.M −$104) |
| MFE<0.5% ∧ depth≤-1.5% | **8/8 在影灾难全捕** | **≈+$1,436** /5周 | 2-3 (多为刮痕单, 真赢家误杀≈MU +$15.67 一笔) |
| MFE<0.5% ∧ depth≤0 (任何水下) | 13 行 | +$2,199 | 10 (−$519) — 面太宽 |
| MFE<0.7% (放宽) | 4 | **−$30** | 4 — 阈值上挪即失效 |

⚠️ **刀尖警告**: US.M (恢复, MFE 0.4715) vs QCOM (灾难, MFE 0.4744) 只差 0.003pp。
0.5% 阈值恰好落在两者之间是运气; 判别力真实 (恢复者集中 ≥0.6%) 但精确切点不可信,
需要影子前瞻攒样 (与 8/20「1.5% 刀尖拟合弃用」同一纪律)。

## 4. 入场侧过滤: 被数据否决

恢复者 5 笔的生成侧画像: vb=high 4/5、anchor_dev≤0 3/5、thesis 同样含「盘前微跌错杀/回踩低吸/
趋势回调低风险机会」(AVGO/COIN/SPCX 逐字同族)。**入场侧无任何事前特征可分** ⇒
过滤会连恢复者一起杀 (COIN +21 / ALK +27 / SPCX +13)。判别器 (MFE) 只在入场后才可观测 —
这正是正确答案在**退出侧**而非入场侧的原因 (T19 纪律同向: 不拿事后族特征做门前置)。

## 6. 治理路径

> **2026-10-17 用户裁决: 不做双轨影子, 当前策略先观察运行一段时间再看效果。**
> ⇒ S1 不落地; RFC-079 影子维持现状 (2.5% 单因子 record-only) 继续攒样;
> 本报告 §3 的 MFE 分离读数作为**观察期复跑基准**冻结 (恢复者 ≥0.6% vs 灾难 <0.5%,
> 刀尖对 M 0.4715/QCOM 0.4744), 每隔 1-2 周用同一回放复跑验证分离是否保持。
> 观察期内执行侧零改动 (与 RFC-141 v2 裁决窗冻结纪律一致, 窗 ~10/29 到期)。

1. 本报告作为 RFC-079 修正案的动机证据呈用户裁决: 是否给 eod_depth_gate 影子加 MFE 双轨臂;
2. 影子攒样达标 (判据字典 B19 形态) 后再裁转硬闸; 转硬闸前 zero 行为变更;
3. 注意口径: RFC-079 现判据在 2.5% 单因子下 FAIL (ΣΔ−$299), 本发现是「加 MFE 条件」而非「放宽深度」,
   阈值 0.5%/1.5% 都须在影子期冻结, 禁止攒样期调参。
